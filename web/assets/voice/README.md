# 看板娘语音包

把下面 9 句台词用任意 AI 配音工具生成 mp3，按对应文件名放进本目录即可。
网站会自动播放；**文件不存在时只显示气泡、不出声**，所以缺几个也不影响使用。

## 生成建议（想要甜美可爱音色）

- **剪映（推荐，免费）**：文本朗读 → 音色选「小萌萌」「甜美女生」或「软萌萝莉」→ 导出 mp3
- **魔音工坊 / 搜狗配音**：选「萝莉」「甜妹」类音色
- **Azure TTS 试听**（效果最自然）：音色 `zh-CN-XiaoyiNeural`（甜美少女），style 用 `affectionate`
- 参数建议：语速 0.9~1.0（稍慢更可爱），音调 +10~20%

## 技术说明

- 每个文件建议 3~10 秒、mp3 格式、44.1kHz 单声道即可
- `live2d.js` 点击看板娘时随机播放 p1~p8，开场播放 p0
- 换台词 = 重新生成对应 mp3 覆盖原文件，无需改代码（台词顺序在 `live2d.js` 的 `PHRASES` 数组里）
