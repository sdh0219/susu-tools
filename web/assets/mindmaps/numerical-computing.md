### 一、预备知识：误差、有效数字、范数与条件数

#### 1. 课程定位 ★
- **数值分析（数值计算方法）**：研究用计算机求解数学问题的数值方法及其理论，是计算数学的主体部分。
- **两类问题**：方程求解（非线性方程、线性/非线性方程组），关注"是否收敛、收敛多快"；函数近似（插值、数值积分、微分方程数值解），关注"误差多大、精度多少"。
- **三套数学工具**：微积分（导数、泰勒展开、中值定理）；线性代数（矩阵分解、特征值、范数）；误差理论（衡量精度的统一语言）。

#### 2. 误差四类 ★★★（选择/判断常考归类）
| 类别 | 含义 | 别称/说明 |
|---|---|---|
| 模型误差 | 数学模型与实际问题之间的偏差 | 对实际问题抽象、简化带来 |
| 观测误差 | 仪器测量得到的原始数据（温度、长度、电压等）所含误差 | 原始数据本身的误差 |
| 截断误差 | 用有限过程代替无限过程产生的误差 | **又称方法误差**，计算方法本身带来 |
| 舍入误差 | 计算机字长有限，对数据取有限位数字运算引起的误差 | 四舍五入累积 |

- 本课程主要研究**截断误差**与**舍入误差**。

#### 3. 误差度量与有效数字 ★★★
- **绝对误差**：e = x* − x（x* 真值，x 近似值）；可正可负，其上界称绝对误差限。
- **相对误差**：er = e / x*；实际计算常用近似值 x 代替真值作分母；其上界称相对误差限。判断精度时**相对误差更有意义**（同一绝对误差在 10⁶ 与 10⁻³ 量级含义不同）。
- **有效数字定义**：若近似值的绝对误差限不超过其某一数位的**半个单位**，且从左起第一个非零数字到该数位共有 n 位，则称有 n 位有效数字。
- 相对误差限与有效数字位数可互相换算（er ≤ 0.5×10^{1−n}/|x|）。
- 经典例题口径：3.1416 作 π 近似有 **5 位**有效数字，3.141 有 **3 位**；0.6931 作 ln2≈0.693147… 的近似有 **4 位**，0.693 有 **3 位**（均按误差限落在哪个数位判断）。

#### 4. 数值算法设计五原则 ★★（判断题常客）
1. **简化计算步骤、减少运算次数**（省时且减少舍入误差积累）。
2. **避免两个相近数相减**——会丢失有效数字、放大相对误差；应做等价变形（如 1−cos x 在 x 很小时改写成 2sin²(x/2)）。
3. **防止大数"吃掉"小数**——数量级悬殊的数直接累加，小数不起作用；可调整求和次序或补偿求和。
4. **避免绝对值很小的数作除数**——商易溢出，或商过大反过来吃掉小数、放大绝对误差。
5. **采用数值稳定性好的算法**——输入误差在计算过程中不迅速增长而失控。
- **秦九韶算法**：南宋秦九韶 1247 年提出，国外称 Horner 算法（1819），晚 500 多年；多项式求值只需 n 次乘法、n 次加法，是计算多项式值最好的算法。

#### 5. 范数 ★★
- **向量范数**：1-范数（分量绝对值之和）、2-范数（欧氏长度）、∞-范数（分量绝对值最大者）。
- **矩阵范数**（须与向量范数相容，常用从属范数）：
  - 1-范数（列范数）：各列绝对值之和的最大值；
  - ∞-范数（行范数）：各行绝对值之和的最大值；
  - 2-范数（谱范数）：最大奇异值；
  - F-范数：与向量 2-范数相容，但**不是从属范数**。
- **范数等价**：若向量序列在一种范数意义下收敛，则在任意一种范数意义下都收敛。

#### 6. 条件数与病态 ★★★（辨析高频）
- **定义**：cond(A) = ‖A‖·‖A⁻¹‖；对称正定时 = λmax/λmin。
- cond(A) ≥ 1；**正交矩阵条件数为 1（最稳定）**；经验上 cond(A) > 10⁴ 即视为病态。
- **条件数就是误差放大倍数**：右端 b 的微小扰动被 cond(A) 放大后影响解；cond 越大越病态。
- **病态是问题（矩阵）本身的性质**，任何算法都无法消除，只能提高精度或改写问题；**算法不稳定是算法的性质**，必须更换算法——二者不可混为一谈。
- **残差 ≠ 误差**：残差 r = b − Ax̃，误差 e = x* − x̃，且 r = Ae；病态矩阵下**残差可以很小而误差很大**，不能把残差小当作解准确。
- 病态辅助识别：消元中主元突然变得极小；对角元相对原矩阵元素相差悬殊；行列式很小而元素并不小。

### 二、非线性方程求根（牛顿迭代法为计算考点，其余为概念考点）

#### 1. 基本概念 ★★
- **根（零点）**：使 f(x*) = 0 的 x*。
- **单根**：f(x*) = 0 且 f′(x*) ≠ 0；**m 重根**：f 及前 m−1 阶导数在 x* 处为零，第 m 阶导数非零。
- **根的隔离**：方程可能有多个实根，求根前先用扫描/逐步搜索找出各根所在的变号区间。

#### 2. 停机判据三类 ★★
- 相邻两次迭代之差 |x_{k+1} − x_k| < ε；
- 残差 |f(x_k)| < ε；
- 有根区间长度 |b − a| < ε。
- **单用残差不可靠**：f 在根附近很平坦时，残差可以很小而离根仍很远。

#### 3. 收敛阶 ★★★（选择/判断必考）
- 设误差 e_k = x_k − x*，若存在 p ≥ 1 与常数 C > 0，使 e_{k+1}/e_k^p → C（k→∞），称序列为 **p 阶收敛**。
- p = 1：**线性收敛**；p = 2：**平方收敛**；1 < p < 2：**超线性收敛**。
- 对照：二分法 p=1；不动点迭代 p=1；牛顿法（单根）p=2；弦截法 p≈1.618。

#### 4. 全局收敛与局部收敛 ★★
- **全局收敛**：对任意初值都收敛；**局部收敛**：只在根的某个邻域内收敛。
- 牛顿法、弦截法等快速方法都是**局部收敛**，初值选取直接决定成败。

#### 5. 二分法 ★★
- **条件**：f 在 [a,b] 上连续，且 f(a)·f(b) < 0（零点定理，区间内至少一个根）。
- **误差界**：|x_k − x*| ≤ (b−a)/2^{k+1}；要求区间长度小于 ε 时，迭代次数 k ≥ log₂((b−a)/ε) − 1，向上取整。
- **优点**：只要连续、端点变号就一定收敛，迭代次数可事先预估；常为其他方法提供较好初值。
- **缺点**：线性收敛（误差每步减半）速度慢；只能求实根，无法求复根；**不能求偶重根**（偶重根两侧 f 不变号）。
- 二分法收敛速度只依赖初始区间与迭代次数，与初值选取无关。

#### 6. 不动点迭代法 ★★
- **构造**：把 f(x)=0 等价改写为 x = φ(x)，迭代 x_{k+1} = φ(x_k)；等价改写方式不唯一，**φ 的构造是核心**。
- **全局收敛（压缩映射定理）**：φ 在 [a,b] 上连续可导，存在 L < 1 使 |φ′(x)| ≤ L 对一切 x 成立，且 φ 把 [a,b] 映入自身，则对任意 x₀ ∈ [a,b]，迭代收敛到唯一不动点 x*。
  - 先验估计：|x_k − x*| ≤ L^k/(1−L)·|x₁ − x₀|（迭代前预估步数）；
  - 事后估计：|x_k − x*| ≤ L/(1−L)·|x_k − x_{k−1}|（用于停机判断）；L 越小收敛越快。
- **局部收敛**：若 φ′(x*) 存在且 |φ′(x*)| < 1，则存在 x* 邻域，邻域内任取初值都收敛；若 |φ′(x*)| ≥ 1 则发散（初值恰为根除外）。
- **收敛阶**：φ′(x*) ≠ 0 时线性收敛，收敛因子为 |φ′(x*)|；若 φ′(x*) = 0 且 φ″(x*) ≠ 0，则为平方收敛。构造 φ 时应设法让 φ′(x*) 尽量小。
- 迭代发散时，先检查 |φ′(x*)| 是否大于 1、φ 是否超出定义域，再考虑换构造方式，而不是盲目换初值。

#### 7. 牛顿法（计算题考点）概念要点 ★★★
- **几何意义**：以 (x_k, f(x_k)) 处的切线代替曲线，取切线与 x 轴交点作下一次近似，故又称**切线法**；相当于取 φ(x) = x − f(x)/f′(x)。
- **收敛性**：f 二阶连续可导、x* 为单根（f′(x*) ≠ 0）时，存在邻域，初值取在邻域内则**局部平方收敛**。
- **重根情形**：x* 是 m 重根时，标准牛顿法退化为**线性收敛**，收敛因子 1 − 1/m，m 越大越慢。
  - 修正一（已知重数 m）：x_{k+1} = x_k − m·f(x_k)/f′(x_k)，恢复平方收敛；
  - 修正二（重数未知）：对 φ(x) = f(x)/f′(x) 用牛顿法（其根为单根）。
- **下山法（阻尼牛顿法）**：加因子 λ，x_{k+1} = x_k − λ·f(x_k)/f′(x_k)，λ 从 1 起逐步折半并要求 |f_{k+1}| 下降，可显著扩大收敛范围。
- **计算量口径（选择题干扰项）**：每步需同时计算函数值 f(x_k) 与导数值 f′(x_k) 两个量，**不是**只算一次函数值；这也是牛顿法每步代价高于弦截法的原因。
- **缺点**：每步需计算 f 与 f′；f′(x) 接近 0 时步长过大可能冲出定义域；初值必须足够靠近根，否则可能发散或循环。

#### 8. 弦截法（割线法）★★
- 用差商 (f(x_k)−f(x_{k−1}))/(x_k−x_{k−1}) 代替导数，**免求 f′**。
- 单根附近收敛阶 p = (1+√5)/2 ≈ **1.618**，属超线性，速度介于线性与平方之间；需**两个初值**，每步只计算一次新的函数值，稳定性略差。
- **单点弦截法**：固定一个端点（如 x₀），每步用 (x_k, f(x_k)) 与固定端点连线交 x 轴，只线性收敛，但每步计算量更省，适合 f 计算昂贵的场合。

#### 9. 加速技术 ★
- **Aitken Δ² 加速**：对线性收敛序列做外推，把线性收敛加速为二阶收敛；只利用 3 个迭代值。
- **Steffensen 法**：把 Aitken 加速嵌入不动点迭代，得到无需导数即达平方收敛的方法，可视为"用加速代替导数"的牛顿法。

#### 10. 方法对照（选择/判断速查）
| 方法 | 收敛阶 | 主要条件 | 优点 | 缺点 |
|---|---|---|---|---|
| 二分法 | 1（线性） | f 连续、端点变号 | 必定收敛、次数可预估 | 慢、不能求复根与偶重根 |
| 不动点迭代 | 1 | \|φ′\| < 1（局部） | 形式简单易编程 | 收敛性依赖 φ 的构造 |
| 牛顿法 | 2（单根）；重根为 1 | f′≠0、初值靠近根 | 单根时收敛最快 | 需导数、初值敏感、可能发散 |
| 弦截法 | ≈1.618 | 两个较好初值 | 不用导数、超线性 | 需两初值、稳定性略差 |
| Aitken/Steffensen | 加速后可达 2 | 原序列线性收敛 | 提速明显、免导数 | 计算量增加、受舍入误差影响 |

### 三、线性方程组求解（LU 分解法为计算考点，其余为概念考点）

#### 1. 直接法与迭代法 ★★
- **直接法**：不计舍入误差时，经有限步运算得到精确解（高斯消去、三角分解）。
- **迭代法**：从初值出发逐步逼近，适合**大型稀疏**方程组，可保持稀疏性、省内存。
- 选择：中小规模或病态问题用直接法；大型稀疏用迭代法。

#### 2. 高斯消去法 ★★
- 两步：**消元**把系数矩阵化为上三角，**回代**自下而上求出各未知量。
- 运算量：n 阶方程组消元约 n³/3 次乘除法，回代约 n²/2 次。
- 顺序消去要求各步主元 a_{kk} ≠ 0；**A 可逆 ⇔ det(A) ≠ 0 ⇔ 各阶顺序主子式全不为零**。
- 注意：**"有唯一解" ≠ "消元可进行到底"**；行列式不为零也不代表顺序消元不出现小主元、误差一定小。

#### 3. 主元策略 ★★★
- 主元过小会放大舍入误差：用 10⁻⁸ 作除数会把系数和右端的误差放大约 10⁸ 倍，结果失真。
- **列主元消去**：在第 k 列的第 k 行及其下方元素中取绝对值最大者，交换到主元位置再消元；稳定性好、交换开销小，是**标准做法**。
- **目的辨析（选择题干扰项）**：选主元只为**抑制小主元导致的误差放大**；它**不减少乘除次数、不把矩阵变对称、也不提高条件数**。
- **全主元消去**：在整个右下角子块中选绝对值最大者，同时交换行与列（需记录列交换以还原未知量次序）；稳定性最好，但每次要搜索整个子块，开销大。
- 实际计算多用列主元。

#### 4. 矩阵三角分解 ★★
- **Doolittle 分解**：A = LU，L 为单位下三角（元素即各步乘数），U 为上三角；存在且唯一当且仅当 A 的各阶顺序主子式均不为零。（计算题考点）**选择题干扰项**：矩阵对称、元素全为正、为单位矩阵的倍数，都不是 LU 分解存在的判据。
- **Crout 分解**：U 为单位上三角，L 为一般下三角；与 Doolittle 只是单位三角的分配方式不同。
- **Cholesky 平方根法**：A 对称正定时分解为 A = LLᵀ，L 对角元为正；计算量约 n³/6，只需存半个矩阵，是解对称正定方程组（正规方程、有限元刚度矩阵）的首选。
- **改进平方根法**：分解为 A = LDLᵀ（D 为对角阵），避免开方运算，适合手算与编程。
- **追赶法**：A 为三对角且严格对角占优时，LU 分解化为两组简单递推（"追"与"赶"），运算量 O(n)，是三次样条插值与差分方程的标准解法。
- **复用优势**：A 不变而右端 b 有多组时，只需分解一次，之后每组右端做一次前代与回代，运算量由 n³ 降为 n²。

#### 5. 残差、误差与条件数（呼应预备知识）★★★
- 残差 r = b − Ax̃，误差 e = x* − x̃，满足 r = Ae。
- 相对误差估计：‖e‖/‖x*‖ ≤ cond(A)·‖δb‖/‖b‖，条件数即误差放大倍数。
- 病态时残差可以很小而误差很大；病态是矩阵本性，与算法无关。

#### 6. 迭代法及其分裂 ★★
- 把 A 分裂为 A = D − L − U（D 为对角部分，L、U 分别为严格下、上三角部分），把 Ax = b 改写为 x = Bx + f 再迭代。
- **Jacobi 迭代**：x^{(k+1)}_i = (b_i − Σ_{j≠i} a_{ij}x^{(k)}_j)/a_{ii}，只用上一轮旧值，各分量**可并行**；迭代矩阵 B_J = D⁻¹(L+U)。
- **Gauss-Seidel 迭代**：计算新分量时直接使用本步已更新的前面分量，属**串行**计算；一般收敛更快；迭代矩阵 B_GS = (D−L)⁻¹U。
- **SOR（逐次超松弛）**：x^{(k+1)} = x^{(k)} + ω·(GS 算出的值)；ω 为松弛因子。ω=1 即 GS；0 < ω < 1 为低松弛，1 < ω < 2 为超松弛；迭代矩阵 B_ω = (D−ωL)⁻¹[(1−ω)D+ωU]。

#### 7. 收敛判据 ★★★（判断题高频）
- **充要条件**：迭代矩阵谱半径 ρ(B) < 1，且收敛性与初值无关；ρ(B) 越小收敛越快，收敛速度可用 −ln ρ(B) 衡量。
- **充分条件**：
  - A 严格对角占优 ⇒ Jacobi 与 GS 都收敛；
  - A 对称正定 ⇒ GS 收敛；
  - A 对称正定且 0 < ω < 2 ⇒ SOR 收敛。
- **易错**：Jacobi 收敛**不蕴含** GS 收敛，二者互不蕴含；GS 通常比 Jacobi 快，但存在反例，结论要看谱半径 ρ(B)。
- **选择题干扰项口径**：对称正定只是 **GS** 的充分条件，**不能**据此判 Jacobi 收敛；行列式非零、三对角、元素全为正、矩阵对称，都不是迭代收敛的充分条件。
- SOR 的最优 ω 需估计或试算，选得合适可大幅加速。

#### 8. 非线性方程组求解 ★
- **形式**：n 个未知量、n 个方程的 F(X) = 0；**雅可比矩阵** J(X) = (∂f_i/∂x_j)_{n×n}，一元情形即导数，是所有方法的构造基础。
- **不动点迭代**：Φ 在解域内连续可微，且 ‖Φ′(X)‖ < 1（压缩条件）则收敛到唯一解；较弱的局部判据是 ρ(J(X*)) < 1。
- **牛顿法**：X^{(k+1)} = X^{(k)} − J(X^{(k)})⁻¹F(X^{(k)})；实际不写求逆，每步解一个线性方程组 JΔX = −F(X)（可用 LU 分解）。F 连续可微、J(X*) 非奇异、初值足够靠近解时**局部平方收敛**。
- **简化牛顿法**：把 J 固定为 J(X⁰) 或每 m 步更新一次，牺牲收敛阶（退化为线性或超线性）换取计算量下降。
- **差商近似导数**：用 [f(x+h)−f(x)]/h 代替偏导数，避免解析求导。
- **Broyden 拟牛顿法**：用秩一修正逐步逼近雅可比矩阵的逆，不重新计算 J，具有超线性收敛，是实际求解非线性方程组的常用算法。
- **初值是最大难点**：常用延拓法（同伦法）引入参数 t 把易解方程的解逐步过渡到目标方程；也可用网格试探多个初值，取收敛者。

### 五、数据插值（牛顿插值法为计算考点，其余为概念考点）

#### 1. 插值问题与存在唯一性 ★★★
- 给定 n+1 个互异节点 x₀ < x₁ < ⋯ < x_n 及函数值 y_i = f(x_i)，求次数不超过 n 的多项式 p_n(x)，使 p_n(x_i) = y_i。
- 插值条件写成线性方程组，系数行列式为**范德蒙德行列式** ∏_{i<j}(x_j−x_i) ≠ 0，故插值多项式**存在且唯一**。
- **唯一性范围**：唯一的是"次数不超过 n 的插值多项式"；若允许多项式次数高于 n，则满足条件的多项式有无穷多个。
- **节点必须互异**：节点重合（不互异）时范德蒙德行列式为零，不能保证存在唯一的 ≤n 次多项式。

#### 2. 拉格朗日插值 ★★
- 基函数 l_i(x) = ∏_{j≠i}(x−x_j)/(x_i−x_j)，满足 l_i(x_j) = δ_{ij}（节点处取 1，其余节点取 0），故插值条件自动成立。
- p_n(x) = Σ y_i l_i(x)。
- **优点**：公式对称、结构清晰，便于理论推导（推导求积公式、证明余项、估计误差都用它）。
- **缺点**：增加一个节点要全部重算；节点多时计算量大；高次时数值不稳定。
- **余项**：R_n(x) = f^{(n+1)}(ξ)/(n+1)! · ω_{n+1}(x)，ξ 介于 x 与诸节点之间；误差由 f 的 n+1 阶导数（函数越"弯曲"误差越大）与节点分布 ω_{n+1}(x) 共同决定。
- 必会写出 n=1 线性插值、n=2 抛物插值的具体表达式。

#### 3. 牛顿插值（差商）（计算题考点）概念要点 ★★★
- **差商定义**：一阶 f[x_i, x_j] = (f(x_j)−f(x_i))/(x_j−x_i)；k 阶 f[x₀,…,x_k] = (f[x₁,…,x_k] − f[x₀,…,x_{k−1}])/(x_k−x₀)。
- **差商对称性**：差商与节点排列次序无关。
- **差商表**：按差商表逐列计算，表中**对角线元素**就是牛顿公式各项系数。
- **承袭性**：增加节点只需在末尾追加一项，前面系数不变，适合逐次加密。
- **差商与导数**：f[x₀,…,x_k] = f^{(k)}(ξ)/k!，ξ 位于所含节点之间（与泰勒公式形式相似的原因）。
- 余项与拉格朗日插值同形。

#### 4. 埃尔米特插值 ★★
- 条件中同时给出**函数值与一阶导数值**：给定 n+1 个节点的函数值与一阶导数，可构造次数不超过 **2n+1** 的多项式。
- 余项：R(x) = f^{(2n+2)}(ξ)/(2n+2)! · ω_{n+1}²(x)。
- 能保持曲线的切线方向，适用于外形设计、机构运动轨迹等要求光滑的场合。
- **易错**：两点三次 Hermite 插值在两个互异节点上同时匹配函数值与一阶导数，共四条约束，得到的是**三次**多项式（次数 ≤2n+1=3），不是四次。

#### 5. 分段插值与三次样条 ★★
- **分段线性插值**：每段一次多项式；函数连续但节点处导数一般不连续（出现折角）；误差 O(h²)。
- **分段三次埃尔米特插值**：给节点函数值与导数，得到一阶导数连续的分段三次多项式；误差 O(h⁴)。
- **三次样条插值**：每个子区间上为三次多项式，且在整个区间上函数、一阶导数、二阶导数都连续（**C² 连续、二阶光滑**）；由**三弯矩方程**确定，系数矩阵为三对角严格对角占优，用追赶法 O(n) 求解。
- **样条需补充两个边界条件**：
  - 自然边界：两端二阶导数为 0（对应力学上"两端简支的细梁"）；
  - 固定边界（转角边界）：给定两端一阶导数；
  - 周期边界：周期函数时两端各阶导数相等。
- 边界条件不同，样条曲线不同，但都唯一存在。

#### 6. 龙格现象与节点选择 ★★★
- **龙格现象**：在等距节点上用高次多项式插值时，节点加密并不保证收敛，反而在区间边缘出现剧烈振荡。典型例子 f(x) = 1/(1+25x²) 在 [−1,1] 上等距插值，n 增大时边缘误差反而发散。
- **结论**：不要用高次等距插值；应改用分段低次插值（分段线性、分段三次、样条），既稳定又灵活。
- **切比雪夫节点**：若必须做整体高次插值，选切比雪夫节点，使 ω_{n+1}(x) 的最大绝对值最小，可有效抑制边缘振荡。

#### 7. 插值与拟合的区别 ★★★（辨析题高频）
- **插值**：要求曲线**严格通过所有数据点**。
- **最小二乘拟合**：只要求残差平方和最小，**不要求过点**。
- 数据含观测误差或节点很多时，应做**拟合**而不是插值。

#### 8. 插值方法对照
| 方法 | 构造要点 | 余项/误差 | 适用场合 |
|---|---|---|---|
| 拉格朗日 | 基函数组合 | f^{(n+1)}(ξ)/(n+1)!·ω | 理论推导、节点少 |
| 牛顿 | 差商逐项累加 | 与拉格朗日同形 | 逐次加密节点 |
| 埃尔米特 | 同时用函数值与导数 | f^{(2n+2)}(ξ)/(2n+2)!·ω² | 外形设计、轨迹 |
| 分段三次 | 低次拼接 | O(h⁴) | 数据多、要求稳定 |
| 三次样条 | 三弯矩方程+追赶法 | O(h⁴)，二阶光滑 | 曲线拟合、工程制图 |

### 六、数值积分（复化辛普森方法为计算考点，其余为概念考点）

#### 1. 求积公式原理 ★★
- 基本思想：用插值多项式近似 f，再对多项式积分，得到 ∫_a^b f(x)dx ≈ Σ A_k f(x_k)。
- x_k 为求积节点，A_k 为求积系数；**系数只与节点和区间有关，与具体函数无关**。

#### 2. 代数精度 ★★★（选择/判断必考）
- **定义**：若公式对所有次数不超过 m 的多项式都精确成立，而对 m+1 次多项式不精确，则称代数精度为 m。
- **判定**：依次取 1, x, x², ⋯ 逐项检验，第一次不精确的幂次减一即为代数精度；等价地，公式对 x^k（k=1,…,m）精确成立。
- 由 n+1 个节点构造的插值型求积公式，代数精度**至少为 n**。
- 代数精度越高，公式对函数的"模拟能力"越强；但实际精度还取决于 f 的光滑性与步长。
- **对称公式的代数精度常为奇数**（如辛普森为 3），对称性使高一次的误差项自动抵消。

#### 3. Newton-Cotes 公式 ★★
- 取等距节点 x_k = a + kh，h = (b−a)/n，对插值多项式积分。
- **梯形公式**（n=1）：精度 **1**，系数比 1:1，余项 −(b−a)³/12·f″(ξ)。
- **辛普森公式**（n=2）：精度 **3**，系数比 1:4:1，余项 −(b−a)⁵/2880·f⁽⁴⁾(ξ)；只用 3 个点却对三次多项式精确。
- **柯特斯公式**（n=4）：精度 **5**。
- **n ≥ 8 时系数出现负值**，数值不稳定，故高阶 Newton-Cotes 不实用，实际多用低阶复合公式。

#### 4. 复合（复化）求积公式 ★★
- 把 [a,b] 分成 n 等份，步长 h = (b−a)/n，在每个子区间上用低阶公式再求和。
- **复合梯形**：余项 −(b−a)/12·h² f″(ξ)，误差阶 **O(h²)**；步长减半时误差约降为 **1/4**。
- **复合辛普森**：余项 −(b−a)/180·h⁴ f⁽⁴⁾(ξ)，误差阶 **O(h⁴)**；步长减半时误差约降为 **1/16**。
- **易错**：复合辛普森要求把 [a,b] 分成**偶数等份**（共 2n+1 个节点），否则公式不成立——最常见失分点。
- 被积函数有奇点或高阶导数不存在时，余项估计失效，应改用变步长、分段处理或高斯公式。
- 实用技巧：用步长折半前后两次结果之差估计误差并判断是否达到精度，比用高阶导数估计余项更省事。

#### 5. 龙贝格（Romberg）积分 ★
- 思路：对复合梯形序列做**理查森外推**，消去误差中的低阶项，逐次得到更高阶近似。
- 每外推一次阶数提高两阶；依次得到梯形、辛普森、柯特斯、龙贝格序列。
- 优点：只用梯形公式，靠外推即得高阶精度，程序简单、精度高；缺点：要求 f 足够光滑，否则外推效果差。
- 实际按行计算，直到相邻两次结果之差满足精度；它也是自适应积分的基础。

#### 6. 高斯求积公式 ★★
- 思路：让**节点与系数一起**按"代数精度最高"的原则确定；**n 个节点可达 2n−1 次代数精度**，这是 n 个节点的理论极限。
- **高斯-勒让德公式**：节点取勒让德多项式 P_n(x) 在 [−1,1] 上的零点，求积系数全部为正；任意区间 [a,b] 需先做线性变换 x = (b+a)/2 + (b−a)/2·t，再套用标准公式。
- **优点**：节点少、精度高，同样精度下函数计算次数最少，适合 f 计算代价高的场合。
- **缺点**：节点与系数需查表或预先计算；节点不固定，不便像复合公式那样随意加密，自适应用起来麻烦；对 f 光滑性要求高。
- **带权积分** ∫f(x)ρ(x)dx 用相应正交多项式零点作节点：权 1/√(1−x²) 用切比雪夫多项式；半无限区间用拉盖尔多项式；全实轴用埃尔米特多项式。

#### 7. 概念辨析 ★
- **并非所有求积公式都是插值型**求积公式；只有节点固定、系数由插值多项式积分导出的才是插值型。
- 方法选用：复合辛普森简单可靠、缺省首选；龙贝格需要高精度且函数光滑；高斯适合函数求值昂贵或要求极少节点。

### 七、常微分方程数值解（改进欧拉法为计算考点，其余为概念考点）

#### 1. 问题形式与适定性 ★★
- **初值问题标准形式**：y′ = f(x, y)，y(x₀) = y₀。数值方法只处理**一阶显式**方程；高阶方程要先降阶为一阶方程组（令 y₁ = y, y₂ = y′, …）。
- **存在唯一性**：若 f 连续且关于 y 满足 Lipschitz 条件（|f(x,y₁)−f(x,y₂)| ≤ L|y₁−y₂|），则初值问题的解存在且唯一；常数 L 同时也是误差增长与稳定性的度量。
- **解析解局限**：只有少数类型方程能求出解析解，工程与科研中绝大多数必须数值求解。
- **刚性方程**：若 y′/y 的特征值实部全为负且绝对值相差数个数量级，解中含极快衰减分量；显式方法为保持稳定只能取极小步长，必须用隐式方法。

#### 2. 单步法与多步法 ★★★
- **单步法**：y_{n+1} 只由 y_n 及 f 在 (x_n, y_n) 处的信息决定（欧拉法、龙格-库塔法）。
- **多步法**：用到前面若干个 y 值（Adams 方法）。

#### 3. 局部与整体截断误差 ★★★（最易混，判断题常客）
- **局部截断误差**：假定第 n 步结果精确（y_n = y(x_n)）时，这一步计算公式产生的误差。
- **整体截断误差**：从初始步累积到第 n 步的总误差。
- **阶的关系**：若局部截断误差为 O(h^{p+1})，称该方法为 **p 阶方法**；p 阶方法的**整体误差为 O(h^p)**，比局部误差**低一阶**。
- **相容性**：局部截断误差除以 h，当 h→0 时趋于 0，即数值格式在极限意义下逼近原微分方程。**相容且稳定，则收敛**。

#### 4. 稳定性与绝对稳定域 ★★
- **稳定性**：误差在后续计算中不被无限放大。
- **绝对稳定**：对试验方程 y′ = λy，有 |f(hλ)| < 1；满足该条件的 hλ 集合称为**绝对稳定域**。
- 显式欧拉的稳定域是以 (−1,0) 为圆心、半径为 1 的圆盘，非常小。

#### 5. 欧拉家族 ★★
- **显式欧拉**：y_{n+1} = y_n + h·f(x_n, y_n)。一阶方法，局部截断误差 O(h²)，整体 O(h)；几何上用切线代替曲线，精度低、稳定性差，但它是一切单步法的基础和推导出发点。
- **隐式（后退）欧拉**：y_{n+1} = y_n + h·f(x_{n+1}, y_{n+1})。一阶方法，隐式，**A 稳定**，适合刚性方程；每步需解方程（不动点迭代或牛顿法），计算量较大。
- **梯形法**：y_{n+1} = y_n + h/2·[f(x_n,y_n)+f(x_{n+1},y_{n+1})]。二阶方法，隐式，A 稳定，精度与稳定性都好，但仍需迭代求解。
- **改进欧拉（预测-校正）**（计算题考点）：先用显式公式预测 ȳ_{n+1}，再用梯形思想校正；二阶方法，显式，只需两次函数计算，是成本最低的常用二阶格式，也是"预测-校正"思想的入门例子。

#### 6. 龙格-库塔（RK）法 ★★
- **思想**：在 [x_n, x_{n+1}] 内取若干点，用这些点处斜率的加权平均作为平均斜率，在不计算高阶导数的前提下提高局部截断误差的阶；**p 级方法每步需算 p 次 f**。
- **经典四阶龙格-库塔（RK4）**：四阶方法，局部截断误差 O(h⁵)，整体误差 O(h⁴)，每步 4 次函数计算，不需导数，精度与稳定性均衡，是通用计算的默认选择。
- 阶数与计算量存在权衡：高阶 RK 每步函数值多，实际很少超过四阶。
- RK 属单步法，**变步长方便**（可用步长折半比较结果调整步长并估计误差），这是它相对多步法的优势。

#### 7. 线性多步法 ★
- **Adams-Bashforth（显式）**：用 y_n, y_{n−1}, ⋯ 处的 f 值外推，四阶格式每步只算 1 次 f，效率高于 RK4，但前几步需用单步法"开机"。
- **Adams-Moulton（隐式）**：公式中含 y_{n+1}，同阶精度更高、稳定域更大，通常作**校正公式**使用。
- **Adams 预测-校正**：先用显式公式预测，再用隐式公式校正，兼顾效率与精度，是求解非刚性问题的常用组合。
- **多步法不足**：需要历史值，**不能自启动**；变步长时系数要重算；稳定性分析比单步法复杂。

#### 8. 刚性与步长选择 ★★★
- 刚性方程解中同时含变化极快与变化极慢的分量，特征值实部相差数个数量级；显式方法为保持稳定必须取极小步长，计算量急剧增大。
- 刚性问题应改用 **A 稳定或 L 稳定**的隐式方法（后退欧拉、梯形法、Gear 法）。
- 步长选择：既满足截断误差要求（精度），又落在稳定域内（稳定）；**刚性问题的步长往往由稳定性而非精度决定**，这是刚性问题难算的根源。

#### 9. 方法阶与稳定性对照
| 方法 | 阶 | 局部误差 | 显/隐式 | 稳定性 | 备注 |
|---|---|---|---|---|---|
| 显式欧拉 | 1 | O(h²) | 显式 | 稳定域很小 | 最简单，教学基准 |
| 后退欧拉 | 1 | O(h²) | 隐式 | A 稳定 | 刚性方程可用 |
| 梯形法 | 2 | O(h³) | 隐式 | A 稳定 | 精度稳定性都好 |
| 改进欧拉 | 2 | O(h³) | 显式（预测-校正） | 稳定域较小 | 低成本二阶格式 |
| RK4 | 4 | O(h⁵) | 显式 | 稳定域中等 | 通用首选 |
| Adams-Bashforth 四阶 | 4 | O(h⁵) | 显式多步 | 稳定域较小 | 每步 1 次 f，需开机 |
| Adams-Moulton 四阶 | 4 | O(h⁵) | 隐式多步 | 稳定域较大 | 常作校正公式 |

### 八、算法与代码常识（纠错题准备）

#### 1. Python / NumPy 要点
- `np.linalg.solve(A, b)` 解线性方程组，比先求逆再乘更准也更快；`np.linalg.inv` 尽量不用。
- 浮点数比较不要写 `x == y`，应写 `abs(x − y) < tol`（3/2=1.5，3//2=1 为整除）。
- 每个迭代必须设最大步数 `max_iter` 上限并输出迭代次数，防止死循环。
- `try/except` 捕获除零与溢出；调试先打印前几步的值，判断是发散、震荡还是收敛太慢。
- 变量名与方法对应（tol 表精度、max_iter 表最大步数、err 表误差），不写魔法数字。

#### 2. 常见代码缺陷类型
- **牛顿法代码（真题三处缺陷）**：
  1. **近零判断位置错误**：先做了 `fx/dfx` 除法、之后才判断 `|dfx|` 近零；应先判断导数是否近零，近零则停止/报错，再做除法；
  2. **近零时 `continue` 跳过更新**：导数近零不修正却继续循环，x 不更新会空转到 `max_iter`；近零应终止迭代并提示，而不是 `continue`；
  3. **判据与健壮性不足**：只以 `|fx|<tol` 判收敛，缺相邻迭代差 `|x_{k+1}−x_k|` 判据、缺发散保护与迭代次数返回。
- **复化辛普森代码（真题三处缺陷）**：
  1. **奇偶系数写反**：内部奇数点系数为 **4**、偶数点系数为 **2**，循环里 `k%2==0` 对应加 2、否则加 4；
  2. **求积系数错误**：总和应乘 **h/3**，不是 h/6；
  3. **求和范围混入端点**：内部点循环应到 `2m−1`，端点 f(a)、f(b) 单独计入；若循环到 `2m`，f(b) 会被内部求和与末尾 `s += f(b)` 重复计入；节点必须为偶数等份。

#### 3. 课件各方法代码纠错点对照（按算法，对照课件 Python 范文）

> 纠错题套路：给一段能跑但有逻辑缺陷的代码，标出缺陷行号、说明原因、写出修正。先认方法，再对照下面的"标准写法要点"找错位。

**通用健壮性缺陷（任何迭代 / 求根 / 求积代码都可能考）**
- 缺 `max_iter` 上限 → 死循环；超步数应返回 fail（或最后值并给出次数）；
- 浮点比较写 `==` → 应 `abs(a−b) < tol`；
- 除法前未判除数近零 / 为零；
- 不返回迭代次数、不区分 success / fail；
- 用魔法数字，变量名与 tol / err / max_iter 不对应。

**二分法 `bisection(f, a, b, tol)`**
- 入口应先校验 `f(a)*f(b) < 0`，否则抛"端点需异号"；缺此校验是缺陷；
- 区间更新方向：`f(a)*f(c) < 0` 根在左半 → `b = c`，否则 `a = c`；写反即缺陷；
- 中点 `c=(a+b)/2`、区间长度 `(b−a)/2` 用浮点除法 `/`，不能用整除 `//`；
- 停机判据用区间长度 `(b−a)/2 < tol`，不能用 `|f(c)|` 很小代替；
- 需配最大迭代次数。

**不动点迭代 `fixed_point(x0, TOL, Nmax)`**
- 先算 `x = φ(x0)`，判 `|x−x0| < TOL`（或相对误差 `|x−x0|/|x|`），再 `x0 = x` 进入下一轮；更新顺序不能乱；
- 超 `Nmax` 应返回 `None, i, "fail"`，不能静默返回最后值；
- 代码不收敛多因迭代函数 φ 不满足 `|φ′(x*)| < 1`（构造问题，不是循环写法问题）。

**高斯消去 `gauss_elimination(A, b)`**
- 增广矩阵 `aug = hstack([A, b.reshape(-1,1)])` 并转 float；
- 消元：因子 `f = aug[r,c]/aug[c,c]`，整行 `aug[r] −= f·aug[c]`；
- 回代必须自下而上 `range(n−1, −1, −1)`；
- 无选主元版直接用 `aug[c,c]` 作除数、未判主元近零——小主元放大误差，这正是要配列主元的原因。

**列主元消去 `column_pivot_gauss(A, b)`**
- 每列先 `max_row = k + argmax(|Ab[k:,k]|)`，换行 `Ab[[k,max_row]] = Ab[[max_row,k]]`，再消元；漏掉选主元 / 换行即缺陷；
- 消元只更新 k 列右侧元素；回代顺序同无主元版。

**Jacobi 迭代**
- 全程用**旧值** x：`x_new[i] = (b[i] − Σ A[i,j]·x[j]) / A[i,i]`，求和取 `x[:i]`、`x[i+1:]`；
- `x_new` 先整体建好，整轮结束后再 `x = x_new`，不能边算边覆盖旧值；
- 若求和时误用本步新值 `x_new[:i]`，就变成了 GS（方法混淆缺陷）；
- 除 `A[i,i]` 前应判对角元近零；收敛判据 `‖x_new−x‖∞ < tol`。

**Gauss-Seidel 迭代**
- 前半段用**本步新值** `x_new[:i]`，后半段仍用旧值 `x[i+1:]`；起步 `x_new = x.copy()`；
- 若全程都用旧 x，就退化成 Jacobi（方法混淆缺陷）；
- 判据、更新顺序、次数返回同 Jacobi。

**Jacobi 与 GS 的唯一区别**：求和时取本步新值还是上一轮旧值；其余结构完全相同。

**改进欧拉法（计算题，代码角度备查）**
- 先预测 `ȳ_{n+1} = y_n + h·f(x_n, y_n)`；
- 校正 `y_{n+1} = y_n + h/2·[f(x_n,y_n) + f(x_{n+1}, ȳ_{n+1})]`，校正右端用的是**预测值 ȳ**，不是 y_{n+1}；
- 每步调用 f 两次，按步长 h 逐步推进。

## 四、综合辨析题场景范式（判断"算法选择/结论是否恰当"并说明理由）

> 答题三段式：**判断恰当/不恰当 → 指出原理（收敛/精度/稳定性/光滑性）→ 给出正确做法**。

### 场景 1：含噪声的大量监测点，用高次拉格朗日插值逐点通过
- **结论：不恰当。**
- 理由：节点多、次数高的等距插值会出现**龙格现象**，边缘剧烈振荡，且会**放大观测噪声**；插值要求严格过点，不适合含噪声数据。
- 正确做法：改用**分段低次插值 / 三次样条**，或对趋势做**最小二乘拟合**（不要求过点，只使残差平方和最小）。

### 场景 2：同一刚度（系数）矩阵、上百种工况反复求解不同右端向量
- **结论：恰当。**
- 理由：A 不变而右端 b 有多组时，先做一次 **LU 分解**，之后每组右端只做一次前代与回代，运算量由 n³ 降为 n²，效率最高。
- 辨析点：不要每次都重新消元或先求逆。

### 场景 3：被积函数光滑、只能取到离散测值，用复化辛普森近似计算定积分
- **结论：恰当。**
- 理由：函数光滑、有等距离散节点时，复化辛普森 O(h⁴) 精度高、系数全正、数值稳定，是缺省首选；注意须偶数等分（2n+1 节点）。

### 场景 4：对刚性常微分方程，为节省时间采用大步长显式欧拉
- **结论：不恰当。**
- 理由：刚性方程含极快衰减分量，显式方法稳定域很小，大步长会失稳；刚性步长由稳定性而非精度决定。
- 正确做法：改用 **A 稳定 / L 稳定的隐式方法**（后退欧拉、梯形法、Gear 法）。

### 场景 5：认为"节点越多插值越精确""提高插值次数就能提高精度"
- **结论：不恰当。**
- 理由：高次等距插值不稳定（龙格现象）；应化整为零，用分段低次插值或样条；必须整体高次时选切比雪夫节点。

### 场景 6：用残差很小判断病态方程组已经解准
- **结论：不恰当。**
- 理由：病态矩阵中 r = Ae，残差小不代表误差小；误差放大倍数由 cond(A) 决定。应结合条件数、主元情况判断，必要时提高精度或改写问题。

### 场景 7：大型稀疏方程组用直接法（LU 分解）求解
- **结论：一般不恰当。**
- 理由：直接法破坏稀疏性、内存开销大；大型稀疏方程组应选**迭代法**（Jacobi/GS/SOR），保持稀疏性、省内存。中小规模或病态问题才用直接法。

## 六、五个计算题方法公式要点速查（备查）

> 本部分仅列格式、步骤与结论；计算过程按练习题例题手算演练。

### 1. 牛顿迭代法（一元非线性方程 f(x)=0）
- **迭代格式**：x_{k+1} = x_k − f(x_k)/f′(x_k)。
- **步骤**：选初值 x₀ → 计算 f(x_k)、f′(x_k) → 代入格式得 x_{k+1} → 检查 \|f(x_k)\| 或 \|x_{k+1}−x_k\| 是否达精度 → 否则继续。
- **结论**：单根、f′(x*)≠0、初值在邻域内时局部平方收敛；重根退化为线性（因子 1−1/m）。
- **提醒**：f′(x) 接近 0 时先判断近零再除；设最大步数；初值避开 f′≈0 处。

### 2. LU（Doolittle）分解法（解线性方程组 Ax=b）
- **分解**：A = LU，L 为单位下三角（l_ii=1），U 为上三角；按"先 U 后 L、逐层交替"计算。
- **求解两步**：前代 Ly = b 求 y；回代 Ux = y 求 x。
- **存在条件**：A 各阶顺序主子式均不为零。
- **提醒**：实际不解 A⁻¹；A 不变多右端时分解一次、多次前代回代。

### 3. 牛顿插值法（差商构造插值多项式）
- **差商递推**：f[x_i,x_j] = (f(x_j)−f(x_i))/(x_j−x_i)；高阶由低阶递推。
- **公式**：p_n(x) = f[x₀] + f[x₀,x₁](x−x₀) + … + f[x₀,…,x_n](x−x₀)…(x−x_{n−1})。
- **步骤**：造差商表 → 取对角线元素作系数 → 写出多项式 → 代入所求点。
- **结论**：增节点只追加一项；余项与拉格朗日同形；差商与节点次序无关。

### 4. 复化辛普森方法（数值积分）
- **格式**：把 [a,b] 分成偶数等份（共 2n+1 节点），h=(b−a)/(2n)；
  S_n = h/3·[f(a) + 4Σf(x_{2k−1}) + 2Σf(x_{2k}) + f(b)]。
- **余项**：−(b−a)/180·h⁴ f⁽⁴⁾(ξ)，误差阶 O(h⁴)；步长减半误差约降为 1/16。
- **提醒**：必须偶数等分；奇数点系数 4、偶数点系数 2 不要写反；系数是 h/3。

### 5. 改进欧拉法（预测-校正，解初值问题 y′=f(x,y)）
- **预测**：ȳ_{n+1} = y_n + h·f(x_n, y_n)（显式欧拉预估）。
- **校正**：y_{n+1} = y_n + h/2·[f(x_n,y_n) + f(x_{n+1}, ȳ_{n+1})]。
- **结论**：二阶显式方法，局部 O(h³)、整体 O(h²)；每步调用 f 两次。
- **提醒**：校正用的是预测值 ȳ_{n+1}，不是 y_{n+1} 本身；按步长 h 逐步推进到目标点。
