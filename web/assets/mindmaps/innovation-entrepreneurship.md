# 《创新与创业》课程思维导图

> 考核：平时 30 / 小论文 50 / 小组案例分析 20。小论文 5000 字，查重红线 ≤15%。
> 星级 = 考点热度：★★★ 必背 / ★★ 高频 / ★ 了解。

## 一、核心概念 ★★

### 创新与创业的关系
- 创新：把要素重新组合（熊彼特）
- 创业：创新的市场化实现过程
- 二者互为条件

### 死亡之谷 ★★★
- 定义：政府资助在可行性研究后退场，风险投资在市场验证前不进场
- 大量成果止步于论文、样机、专利

## 二、案例主线：辰安科技（300523）★★★

### 三个必要条件（缺一不可）
- 立项锚定真实需求——成果第一属性是需求而非技术
- 真实场景持续喂养——城市级部署让产品在数据中迭代
- 组织与资本安排——研究院缓冲 + 资本接力

### 时间轴
- 2005：清华公共安全团队成果转化设立
- 2015-17：合肥城市生命线试点，2017 监测中心运行
- 2016：创业板上市（募资 4.38 亿）
- 2025：定增后合肥国资 28.85% 控股

### 合肥模式
- 政府买单 → 城市级部署 → 数据回流 → 产品迭代
- 累计预警 6000+ 起；管网事故率降 60%

### 三个机制 → 研讨问题
- 政府订单是台阶还是拐杖？——代偿前两条，代偿不了第三条

## 三、小论文选题 ★★★

### 推荐方向 ⭐
- 应急行业企业研发人员成长环境研究（与案例分析一鱼两吃）

### 四维分析框架
- 产学研转化通道 / 真实场景数据供给 / 激励与治理结构 / 组织文化与学习机制

### 要求
- 5000 字、按学报格式、查重 ≤15%、文件名"学号_姓名"

## 四、小组案例分析报告 ★★★

### 结构
- 研究问题 → 时间轴 → 死亡之谷 → 三机制 → 结论 → 研讨

## 五、对研究生的启示 ★★
