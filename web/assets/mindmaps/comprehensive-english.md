# 《研究生综合英语》期末复习思维导图

> 考点优先级 + 技能清单。U1–U6 覆盖。
> 星级 = 考点热度：★★★ 必背 / ★★ 高频 / ★ 了解。

## 一、考点优先级 ★★★

### 高频优先
- U1–U6 词汇总表（选词填空高频）
- 阅读技能（段落匹配题）
- 翻译与写作框架

### 基础必保
- 每单元 Text A 主旨与长难句
- 课文内的固定搭配

## 二、词汇 ★★★

### 词汇总表
- U1–U6 每单元核心词 + 派生词
- 近义辨析组（考试常设干扰项）

### 记忆策略
- 按单元滚动 + 考前合并自测
- 高频搭配优先于生僻词

## 三、阅读技能 ★★★

### 段落匹配
- 先读题干关键词，再扫读定位
- 同义替换是核心出题手法

### 常规阅读
- 先看题干再读文（带着问题读）
- 首尾句与转折词定位

## 四、段落匹配与完形 ★★

### 段落匹配三步
- 通读首句抓段落大意
- 关键词（数字、专名、大写词）定位
- 排除已用段落

## 五、翻译 ★★

### 汉译英框架
- 先定句型主干，再挂修饰
- 中国特色表达记固定译法

### 英译汉
- 长难句切分：主句 + 从句 + 修饰
- 按中文习惯重组语序

## 六、写作 ★★★

### 框架
- 三段式：观点引入 → 论证（2~3 点）→ 结论重申
- 万能开头/结尾模板各 2 套

### 加分项
- 连接词分档使用（首先/其次/然而/综上所述）
- 避免中式直译，背 3~5 个高级句型
