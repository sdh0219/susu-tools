# 《岩矿鉴定》考试复习思维导图

> 27 条简答论述 + 4 个名词解释 + 2 张读图题，共 33 条知识条目。
> 星级 = 考点热度：★★★ 必背 / ★★ 高频 / ★ 了解。

## 一、矿物学基础 ★★★

### 摩氏硬度计（10 矿物）
- 1 滑石 → 2 石膏 → 3 方解石 → 4 萤石 → 5 磷灰石 → 6 长石 → 7 石英 → 8 黄玉 → 9 刚玉 → 10 金刚石
- 辅助硬度：指甲 2.5｜铜币 3｜小刀 5.5｜钢锉 6.5

### 晶体六性质
- 自限性 / 均一性 / 异向性 / 对称性 / 最小内能性 / 稳定性
- 易错：内能与稳定性因果一体，答题分两条写

### 晶体定义
- 核心 = 格子构造（周期性重复），不是规则外形

### 解理五等级
- 极完全（云母）→ 完全（方解石）→ 中等（辉石 87°）→ 不完全（磷灰石）→ 极不完全（石英贝壳断口）

### 矿物五大分类
- 自然元素 / 硫化物 / 氧化物氢氧化物 / 含氧盐（硅酸盐占造岩 90%）/ 卤化物

## 二、关键概念辨析 ★★★

### 类质同象 vs 同质多象
- 类质同象：结构同、成分不同（斜长石 Ab-An）
- 同质多象：成分同、结构不同（金刚石 vs 石墨）
- 方向相反，答题写清"什么相同、什么不同"

### 矿物鉴定三对高频
- 方解石 vs 石英：滴酸起泡 + 硬度 3 vs 7
- 角闪石 vs 辉石：解理夹角 124° vs 87°
- 钾长石 vs 斜长石：卡氏双晶 vs 聚片双晶

### 四种硫化物区分（三步法）
- 黄铁矿 6~6.5 无解理｜黄铜矿 3.5~4 锖色｜方铅矿 2.5 三组解理密度 7.5｜闪锌矿六组解理树脂光泽

## 三、硅酸盐体系 ★★★

### 硅氧骨干五类型
- 岛状 1:4 → 单链 1:3 → 双链 4:11 → 层状 2:5 → 架状 1:2
- 规律：连接越高 Si:O 越小；硬度密度下降

### 层状硅酸盐结构
- T 层（四面体片）+ O 层（八面体片）
- 1:1 型高岭石 / 2:1 型云母蒙脱石 / 2:1:1 型绿泥石

## 四、岩浆岩与沉积岩 ★★★

### 岩浆岩化学分类
- 超基性 <45%（橄榄岩/苦橄岩）→ 基性 45~52%（辉长岩/玄武岩）→ 中性 52~66%（闪长岩/安山岩）→ 酸性 >66%（花岗岩/流纹岩）

### QAP 图解命名
- 先看 Q 定区 → 再看 A/(A+P) 定名 → 暗色 >5% 加前缀

### 接触关系三种
- 侵入接触（变质晕、冷凝边、捕虏体、切层）
- 沉积接触（古风化壳、底砾岩）
- 断层接触（破碎带，先后不明）

### 岩浆产生三条件
- 温度升高 / 压力降低（最主要）/ 挥发分加入

## 五、野外工作 ★★

### 三种风化
- 物理（只改粒度）/ 化学（成分改变，水解最主要）/ 生物（双重性质）

### 岩浆岩 vs 沉积岩（野外四步）
- 产状层理 → 结构分选 → 矿物组合 → 围岩接触
- 两步以上吻合可定论；只看颜色最不可靠

### 层面构造
- 波痕（古流向）/ 泥裂（示顶底）/ 雨痕 / 冲刷面（沉积间断）/ 叠层石

## 六、读图题 ★★

### A 侵入体产状
- 岩基 >100km² / 岩株 / 岩床顺层 / 岩墙切层 / 岩盖 / 岩盆

### B 鲍文反应系列
- 不连续系列（暗色：橄榄石→辉石→角闪石→黑云母，改结构）
- 连续系列（斜长石：钙长石→钠长石，改成分）
- 残余熔体：钾长石→白云母→石英
