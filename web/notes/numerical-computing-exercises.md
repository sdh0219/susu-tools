# 练习题（一）

## 一、选择题

### 第 1 题（有效数字）

**题目**：若分别用 3.1416 和 3.141 作为 π≈3.1415926… 的近似值，根据有效数字判定规则，下列说法正确的是（ ）

- A. 3.1416 有 4 位，3.141 有 3 位
- B. 3.1416 有 5 位，3.141 有 4 位
- C. 3.1416 有 5 位，3.141 有 3 位
- D. 3.1416 有 4 位，3.141 有 4 位

**答案：C**

**解析**：
有效数字判定：近似值第一位非零数字在个位（即 10⁰ 位，记 m=1），若绝对误差满足 |x−x*| ≤ 0.5×10^(m−n)，则有 n 位有效数字。

- 3.1416：误差 |3.1416−3.14159265| ≈ 7.35×10⁻⁶。判 n=5：阈值 0.5×10^(1−5)=5×10⁻⁵，7.35×10⁻⁶ ≤ 5×10⁻⁵，成立 → **5 位**。
- 3.141：误差 |3.141−3.14159265| ≈ 5.93×10⁻⁴。判 n=3：阈值 0.5×10^(1−3)=5×10⁻³，成立；判 n=4：阈值 5×10⁻⁴，5.93×10⁻⁴ > 5×10⁻⁴，不成立 → **3 位**。

**知识点**：有效数字位数由"误差限所在数位"决定，不是看写出了几个数字；3.1416 虽写 5 位，但能否算 5 位有效数字要由误差是否落在第 5 位的半个单位内来定。

### 第 2 题（Jacobi 迭代收敛条件）

**题目**：求解线性方程组 Ax=b 时，Jacobi 迭代法收敛的一个充分条件是（ ）

- A. A 为对称正定矩阵　B. A 严格对角占优　C. A 的行列式不为零　D. A 为三对角矩阵

**答案：B**

**解析**：系数矩阵**严格对角占优**时，Jacobi 与 Gauss-Seidel 迭代都收敛，这是最常用的充分条件。
- A 错：对称正定只保证 **Gauss-Seidel** 收敛，**不保证 Jacobi 收敛**，二者不要混；
- C 错：行列式非零只说明方程组有唯一解，与迭代是否收敛无关；
- D 错：三对角矩阵本身不保证收敛。

**知识点**：迭代收敛判据分两类——充分条件（严格对角占优、对称正定对 GS）与充要条件（迭代矩阵谱半径 ρ(M)<1）。

### 第 3 题（Newton 法收敛阶）

**题目**：关于 Newton 迭代法求单根，下列说法正确的是（ ）

- A. 局部线性收敛　B. 局部至少平方收敛　C. 全局收敛且与初值无关　D. 每次迭代只需计算一次函数值

**答案：B**

**解析**：单根附近 Newton 法**局部至少平方收敛**（二阶）。
- A 错：不是线性收敛；
- C 错：Newton 法是**局部**收敛，对初值有要求，初值离根太远可能发散；
- D 错：每步要算 **f(x) 和 f′(x) 两个量**，不是只算一次函数值。

**知识点**：单根 → Newton 平方收敛；重根 → 退化为线性收敛（需改用带重数的修正格式）。

### 第 4 题（Runge 现象）

**题目**：Runge 现象说明（ ）

- A. 节点越多插值越精确
- B. 高次等距节点插值可能出现剧烈振荡，宜采用分段低次插值
- C. 样条插值不可靠
- D. 插值多项式次数越高误差越小

**答案：B**

**解析**：等距节点加密时，高次多项式在区间两端会剧烈振荡（Runge 现象），误差反而增大。因此工程上多用**分段低次插值**或样条插值，而不是一味升高次数。A、D 与事实相反，C 无依据。

**知识点**：高次插值≠高精度；噪声数据更不能靠高次多项式去"逐点穿过"。

### 第 5 题（复化梯形误差阶）

**题目**：复化梯形公式的步长减半后，其截断误差约为原来的（ ）

- A. 1/2　B. 1/4　C. 1/8　D. 1/16

**答案：B**

**解析**：复化梯形误差阶 **O(h²)**。步长 h 减半后，误差按 h² 缩小，约为原来的 (1/2)² = **1/4**。
对比：复化辛普森 O(h⁴)，步长减半误差约降为 **1/16**。

**知识点**：梯形 O(h²)→1/4；辛普森 O(h⁴)→1/16，两组倍数要记牢。

### 第 6 题（改进欧拉法精度）

**题目**：改进 Euler 法（预估-校正格式）求解初值问题 y′=f(x,y)，其整体截断误差为（ ）

- A. O(h)　B. O(h²)　C. O(h³)　D. O(h⁴)

**答案：B**

**解析**：改进欧拉（预估-校正）是**二阶**方法，整体截断误差 **O(h²)**。
- 显式欧拉是一阶 O(h)；
- 经典四阶龙格-库塔 RK4 是四阶 O(h⁴)。

**知识点**：方法阶数 → 整体误差阶；改进欧拉每步调用右端函数 2 次（预估一次、校正一次）。

## 二、判断题

### 第 1 题
**题目**：在数值计算中，两个相近的数相减会损失有效数字，应尽量避免。（ ）

**答案：√**

**解析**：两个相近数相减，有效数字大量抵消（"吃尾数"），是数值不稳定的典型来源。实际中应改用等价变换（如有理化、换公式）避免相近数相减。

**知识点**：数值稳定技巧——避免相近数相减、避免除以绝对值很小的数、防止大数吃小数。

---

### 第 2 题
**题目**：若条件数 cond(A) 很小，则称方程组 Ax=b 是病态的。（ ）

**答案：×**

**解析**：说反了。**条件数很大**才是病态（输入微小扰动会被放大）；cond(A) 很小是**良态**。条件数越接近 1 越好。

**知识点**：cond(A)=‖A‖·‖A⁻¹‖，越大病态越重；病态方程组对舍入误差敏感。

---

### 第 3 题
**题目**：若迭代函数 g(x) 在不动点附近满足 |g′(x)| ≤ L < 1，则不动点迭代 x_{k+1}=g(x_k) 局部收敛。（ ）

**答案：√**

**解析**：压缩映射条件 |g′(x)| ≤ L < 1（L 为李普希茨常数）是不动点迭代**局部收敛**的充分条件；L 越小收敛越快。

**知识点**：不动点迭代收敛条件；先验估计（用初值差）与事后估计（用相邻两次差）判断精度。

---

### 第 4 题
**题目**：Gauss 消去法只要行列式不为零就可以不作任何处理地顺利执行完毕，误差一定很小。（ ）

**答案：×**

**解析**：行列式非零只保证有唯一解，**不保证数值过程稳定**。若出现小主元，不作选主元处理会使舍入误差被放大；实际需用**列主元 Gauss 消去**。"误差一定很小"也不成立。

**知识点**：高斯消去 vs 列主元消去；选主元是为避免小主元放大误差，不是为减少运算量。

---

### 第 5 题
**题目**：拉格朗日插值基函数满足 l_i(x_j)=δ_ij（节点处取 1，其余节点取 0）。（ ）

**答案：√**

**解析**：这是拉格朗日基函数的定义性质：第 i 个基函数在 x_i 处为 1，在其他节点 x_j（j≠i）处为 0。克罗内克符号 δ_ij：i=j 取 1，否则取 0。

**知识点**：拉格朗日插值多项式由基函数线性组合而成；基函数只与节点有关。

---

### 第 6 题
**题目**：n 次代数精度的求积公式，对一切次数不超过 n 的多项式都能精确成立。（ ）

**答案：√**

**解析**：这是代数精度的定义：公式对所有次数 ≤ m 的多项式精确成立、对 m+1 次不精确，则代数精度为 m。题干表述正是定义的核心部分。

**知识点**：代数精度判定——依次取 1, x, x², … 逐项检验，第一次不精确的幂次减一即为精度。

---

### 第 7 题
**题目**：对任何被积函数，复化 Simpson 公式的结果一定比相同步长的复化梯形公式精确。（ ）

**答案：×**

**解析**：不能一概而论。辛普森精度阶更高（O(h⁴) vs O(h²)），但实际精度还依赖**函数光滑性**；被积函数不够光滑或高阶导数不存在时，结论不成立。

**知识点**：方法的理论误差阶 ≠ 对任意函数都更准；选方法要看函数条件。

---

### 第 8 题
**题目**：显式欧拉格式是无条件稳定的，可以取任意大步长计算刚性微分方程。（ ）

**答案：×**

**解析**：显式欧拉是**条件稳定**的，步长受稳定域限制；解刚性方程时若步长过大，数值解会发散。刚性问题应选隐式格式（如隐式欧拉，A-稳定）。

**知识点**：显式 vs 隐式；A-稳定（隐式欧拉、梯形法）对刚性方程稳定性好。

---

### 第 9 题
**题目**：二分法要求 f(x) 在 [a,b] 上连续且 f(a)f(b)<0，其误差以 (b−a)/2^(n+1) 的速度减小。（ ）

**答案：√**

**解析**：二分法每迭代一次含根区间长度减半；n 次后区间长度（误差界）按 (b−a)/2^n 量级压缩，教材常写成 (b−a)/2^(n+1)。前提是 f 连续、端点异号。

**知识点**：二分法只要求连续 + 异号，收敛稳妥但速度慢（线性），不能求复根/偶重根。

---

### 第 10 题
**题目**：弦截法（割线法）在单根附近是二阶收敛的方法。（ ）

**答案：×**

**解析**：弦截法（割线法）在单根附近收敛阶约为 **1.618**（黄金分割比），不是二阶；二阶是 **Newton 法**（单根）。弦截法用差商代替导数，免去求导。

**知识点**：收敛阶对比——二分 1 阶（线性）、弦截 1.618、牛顿 2 阶（单根）。

## 三、计算题

### 第 1 题（Newton 迭代法）

**题目**：求 f(x)=x³−4x+1=0 在 [1,2] 内的根。取初值 x₀=2，用 Newton 迭代法求两次迭代 x₁、x₂（保留 4 位小数），并估计近似根的有效数字位数。

**迭代格式**：

$$x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)},\quad f'(x)=3x^2-4$$

**第 1 次迭代**（x₀=2）：

- f(2)=2³−4×2+1=1
- f′(2)=3×2²−4=8
- x₁ = 2 − 1/8 = **1.8750**

**第 2 次迭代**（x₁=1.875）：

- f(1.875)=1.875³−4×1.875+1≈0.0917969
- f′(1.875)=3×1.875²−4≈6.546875
- x₂ = 1.875 − 0.0917969/6.546875 ≈ **1.8610**

**有效数字估计**：区间内真实根 ≈ 1.860806，误差 |x₂−根| ≈ 1.73×10⁻⁴。
- 判 4 位：阈值 0.5×10^(1−4)=5×10⁻⁴，1.73×10⁻⁴ ≤ 5×10⁻⁴，成立；
- 判 5 位：阈值 5×10⁻⁵，不成立。

**答案**：x₁≈1.8750，x₂≈1.8610，近似根有 **4 位有效数字**。

**知识点**：Newton 法每步算 f 与 f′；先判导数近零再做除法；单根局部平方收敛；有效数字按误差限所在数位判定。

### 第 2 题（Doolittle 分解法）

**题目**：解刚度方程

```
2x1 +  x2 +  x3 = 5
2x1 + 4x2 + 3x3 = 13
4x1 −  x2 + 4x3 = 6
```

用 Doolittle 分解法求 A=LU 并解出 x₁, x₂, x₃。

**系数矩阵**：

```
A = [ 2  1  1 ]
    [ 2  4  3 ]
    [ 4 −1  4 ],  b = [5, 13, 6]ᵀ
```

**第一步：A=LU 分解**（L 为单位下三角，U 为上三角）

- U 第一行 = A 第一行：u₁₁=2, u₁₂=1, u₁₃=1
- l₂₁=a₂₁/u₁₁=2/2=1；l₃₁=a₃₁/u₁₁=4/2=2
- u₂₂=a₂₂−l₂₁u₁₂=4−1×1=3；u₂₃=a₂₃−l₂₁u₁₃=3−1×1=2
- l₃₂=(a₃₂−l₃₁u₁₂)/u₂₂=(−1−2×1)/3=−1
- u₃₃=a₃₃−l₃₁u₁₃−l₃₂u₂₃=4−2×1−(−1)×2=4

```
L = [ 1  0  0 ]        U = [ 2  1  1 ]
    [ 1  1  0 ]            [ 0  3  2 ]
    [ 2 −1  1 ]            [ 0  0  4 ]
```

**第二步：Ly=b 前代求 y**

- y₁=5
- y₂=13−l₂₁y₁=13−1×5=8
- y₃=6−l₃₁y₁−l₃₂y₂=6−2×5−(−1)×8=4

**第三步：Ux=y 回代**

- 4x₃=4 → x₃=1
- 3x₂+2x₃=8 → 3x₂=6 → x₂=2
- 2x₁+x₂+x₃=5 → 2x₁+2+1=5 → x₁=1

**答案**：**x₁=1，x₂=2，x₃=1**。

**核验**：代入原方程 2+2+1=5 ✓；2+8+3=13 ✓；4−2+4=6 ✓。

**知识点**：Doolittle 分解 L 单位下三角、U 上三角；分解一次后可对多个右端向量反复前代回代；分解可行的充分条件是各阶顺序主子式非零。

### 第 3 题（牛顿差商插值）

**题目**：沉降监测数据

| t（月） | 0 | 1 | 2 |
|---|---|---|---|
| w（mm） | 3 | 5 | 9 |

（1）用 Newton 差商公式构造过三点的二次插值多项式；（2）求 t=1.5 月时沉降量近似值。

**第一步：构造差商表**

| t | w | 一阶差商 | 二阶差商 |
|---|---|---|---|
| 0 | 3 | | |
| | | (5−3)/(1−0)=2 | |
| 1 | 5 | | (4−2)/(2−0)=1 |
| | | (9−5)/(2−1)=4 | |
| 2 | 9 | | |

**第二步：Newton 二次插值多项式**

$$
N_2(t)=w_0+w[0,1](t-0)+w[0,1,2](t-0)(t-1)
$$

$$
N_2(t)=3+2t+t(t-1)=t^2+t+3
$$

**第三步：代入 t=1.5**

$$
N_2(1.5)=1.5^2+1.5+3=2.25+1.5+3=\mathbf{6.75}
$$

**答案**：插值多项式 **N₂(t)=t²+t+3**；t=1.5 时沉降量近似 **6.75 mm**。

**核验**：N₂(0)=3 ✓，N₂(1)=5 ✓，N₂(2)=9 ✓。

**知识点**：差商具有对称性；Newton 插值新增节点时只需在末尾加一项，便于递推；等距节点可改用向前/向后差分。

### 第 4 题（复化辛普森公式）

**题目**：计算 I=∫₀¹ 1/(1+x²) dx。将区间 [0,1] 四等分（2 个 Simpson 单元），用复化 Simpson 公式计算近似值（保留 5 位小数），并与精确值 π/4 比较绝对误差。

**第一步：步长与节点**

4 等分为偶数份，共 5 个节点；h=(1−0)/4=0.25。

| x | 0 | 0.25 | 0.5 | 0.75 | 1 |
|---|---|---|---|---|---|
| f(x)=1/(1+x²) | 1 | 0.94117647 | 0.8 | 0.64 | 0.5 |

**第二步：按系数加权**（端点 1、奇数点 4、偶数点 2）

$$
\begin{aligned}
S&=\frac{h}{3}\big[f_0+f_4+4(f_1+f_3)+2f_2\big]\\
&=\frac{0.25}{3}\big[1+0.5+4(0.94117647+0.64)+2\times0.8\big]\\
&\approx 0.78539216
\end{aligned}
$$

**第三步：与精确值比较**

- 近似值（保留 5 位）：**0.78539**
- 精确值 π/4≈0.78539816
- 绝对误差 |S−π/4| ≈ **6.0×10⁻⁶**

**答案**：I≈**0.78539**，绝对误差约 6.0×10⁻⁶。

**知识点**：必须偶数等分（2n+1 节点）；奇数点系数 4、偶数点系数 2；整体乘 h/3；误差阶 O(h⁴)，步长减半误差约降为 1/16。

### 第 5 题（改进欧拉法）

**题目**：炉温满足 dT/dt=−0.5(T−25)，T(0)=100。取步长 h=0.1，用改进欧拉法计算 T(0.2) 的近似值（保留 4 位小数），并与精确解 T(t)=25+75e^(−0.5t) 比较。

**预估-校正格式**：

```
预估：T̂_{n+1}=T_n + h·f(t_n, T_n)
校正：T_{n+1}=T_n + h/2·[f(t_n,T_n)+f(t_{n+1},T̂_{n+1})]
```

其中 f(t,T)=−0.5(T−25)。

**第 1 步**（t₀=0，T₀=100）：

- f₀=−0.5(100−25)=−37.5
- 预估 T̂₁=100+0.1×(−37.5)=96.25
- f(T̂₁)=−0.5(96.25−25)=−35.625
- 校正 T₁=100+0.05×(−37.5−35.625)=**96.34375**

**第 2 步**（t₁=0.1，T₁=96.34375）：

- f₁=−0.5(96.34375−25)=−35.671875
- 预估 T̂₂=96.34375+0.1×(−35.671875)=92.7765625
- f(T̂₂)=−0.5(92.7765625−25)=−33.88828125
- 校正 T₂=96.34375+0.05×(−35.671875−33.88828125)=**92.8657**

**与精确解比较**：

- T(0.2)=25+75e^(−0.1)≈**92.8628**
- 绝对误差 |92.8657−92.8628| ≈ **2.94×10⁻³**

**答案**：T(0.2)≈**92.8657 ℃**；精确值 92.8628 ℃，误差约 2.94×10⁻³。

**知识点**：改进欧拉 = 预估（显式欧拉）+ 校正（梯形思想），二阶 O(h²)；每步 2 次右端函数计算；先算预估再代入校正。

## 四、综合辨析题

### 第 1 题
**场景**：岩土工程有 21 个含噪声的监测点，为"精确通过每个点"，采用 21 次 Lagrange 多项式插值。

**结论：不恰当。**

**理由**：监测点含随机噪声，高次插值会把噪声也当成信号逐点拟合，引发 Runge 振荡，误差反而增大。应采用**分段低次插值 / 样条插值**，或做曲线拟合（最小二乘）只逼近趋势，不要求逐点穿过。

**知识点**：高次插值≠高精度；含噪声数据宜拟合不宜插值。

---

### 第 2 题
**场景**：结构抗震分析需对同一刚度矩阵、上百种工况反复求解不同载荷向量，宜先做 LU 分解再多次前代回代。

**结论：恰当。**

**理由**：系数矩阵 A 不变、右端 b 有上百个。先一次性完成 A=LU 分解，之后每个工况只需做前代（Ly=b）+ 回代（Ux=y），避免每次重新消元，显著节省计算量。

**知识点**：LU 分解的最大优势就是"分解一次、回代多次"，适合多右端向量问题。

---

### 第 3 题
**场景**：已知被积函数光滑但只能取到离散测值，用复化 Simpson 公式近似计算其定积分。

**结论：恰当。**

**理由**：函数光滑、节点等距时，复化辛普森 O(h⁴) 精度高、求积系数全正、数值稳定，是缺省首选。前提是偶数等分；若函数有奇点或高阶导数不存在，则应改用变步长、分段处理或高斯求积。

**知识点**：方法选用——光滑离散测值用复化辛普森；高精度且光滑用龙贝格；函数求值昂贵用高斯求积。

## 五、算法纠错题（Newton–Raphson）

**题目**：下面 Python 代码意图实现 Newton 迭代法求 f(x)=0 的实根，含三处缺陷，标出缺陷行号、说明原因并改正。

```python
1  def newton(f, df, x0, tol, max_iter = 30):
2      x = x0
3      for k in range(max_iter):
4          fx = f(x)
5          dfx = df(x)
6          if abs(fx) < tol:
7              break
8          x = x - fx / dfx
9          if abs(dfx) < 1e-12:
10             continue
11     return x
12     # End of Newton iteration
```

### 缺陷 1：近零判断位置颠倒（第 8、9 行）

- **原因**：第 8 行先做了 `fx/dfx` 除法，第 9 行才判断 `|dfx|` 是否近零。若导数近零，除法早已触发除零/溢出。
- **改正**：**先判断导数是否近零，近零则终止或报错，再做除法**。

### 缺陷 2：近零时 `continue` 空转（第 10 行）

- **原因**：导数近零时用 `continue` 跳过本次循环，x 不更新，会一直空转到 `max_iter`，既不收敛也不报错。
- **改正**：近零应**终止迭代并提示**（抛出异常或返回失败状态），不能 `continue`。

### 缺陷 3：收敛判据与健壮性不足（第 6 行）

- **原因**：只以 `|fx|<tol` 判收敛，缺少**相邻迭代值之差** `|x_new−x|<tol` 这一常用判据；也没有超步数保护、未返回迭代次数与成功/失败状态。
- **改正**：记录上一步 x，用残差 + 步长双判据；达到 `max_iter` 应给出失败标记。

### 参考修正代码

```python
def newton(f, df, x0, tol, max_iter=30):
    x = x0
    for k in range(max_iter):
        fx = f(x)
        dfx = df(x)
        if abs(dfx) < 1e-12:                 # 先判除零，再除法
            raise ZeroDivisionError("导数近零，迭代终止")
        x_new = x - fx / dfx
        if abs(x_new - x) < tol:             # 相邻迭代差判据
            return x_new, k + 1
        x = x_new
    return x, max_iter                       # 超步数保护并返回次数
```

**知识点**：迭代类代码通用检查项——除法前先判除数近零；设最大步数上限；浮点比较用 `abs(a−b)<tol`；返回迭代次数与收敛状态。

## 一、选择题

### 第 1 题（有效数字）

**题目**：若分别用 0.6931 和 0.693 作为 ln2≈0.693147180… 的近似值，根据有效数字判定规则，下列说法正确的是（ ）

- A. 0.6931 有 3 位，0.693 有 3 位
- B. 0.6931 有 4 位，0.693 有 3 位
- C. 0.6931 有 4 位，0.693 有 4 位
- D. 0.6931 有 5 位，0.693 有 4 位

**答案：B**

**解析**：首位非零数字在十分位（m=0）。

- 0.6931：误差 |0.6931−0.69314718|≈4.72×10⁻⁵。判 n=4：阈值 0.5×10^(0−4)=5×10⁻⁵，成立；判 n=5：阈值 5×10⁻⁶，不成立 → **4 位**。
- 0.693：误差 |0.693−0.69314718|≈1.47×10⁻⁴。判 n=3：阈值 5×10⁻⁴，成立；判 n=4：阈值 5×10⁻⁵，不成立 → **3 位**。

**知识点**：纯小数有效数字从第一个非零数字算起；判定仍以误差限为准。

### 第 2 题（Doolittle 分解条件）

**题目**：矩阵能进行 Doolittle 分解 A=LU（不选主元）的一个充分条件是（ ）

**答案：A**

**解析**：不选主元的 Doolittle 分解可行的充分条件是**各阶顺序主子式均非零**。对称、元素全正都不保证分解可行；单位矩阵倍数是特殊情形，不是一般条件。

**知识点**：顺序主子式非零 ↔ 顺序 Gauss 消元不出现零主元 ↔ 可做不选主元 LU 分解。

**知识点**：收敛阶：二分 1 < 弦截 1.618 < 牛顿 2。

### 第 4 题（列主元目的）

**题目**：用 Gauss 消去法解线性方程组时选取列主元，其主要目的是（ ）

- A. 减少乘除法运算次数　B. 避免小主元导致误差放大
- C. 使系数矩阵变为对称　D. 提高系数矩阵的条件数

**答案：B**

**解析**：列主元消去通过选取当前列绝对值最大的元素作主元，**避免小主元把舍入误差放大**。
- A 错：选主元不减少（反而略增）运算量；
- C 错：不会改变矩阵的对称性；
- D 错：条件数由矩阵本身决定，选主元不能提高条件数。

**知识点**：选主元是数值稳定措施，不是效率或矩阵结构改造手段。

### 第 5 题（Simpson 代数精度）

**题目**：Simpson 求积公式 [f(a)+4f((a+b)/2)+f(b)]·(b−a)/6 的代数精度为（ ）

- A. 1 次　B. 2 次　C. 3 次　D. 4 次

**答案：C**

**解析**：辛普森公式用 3 个点，却对**不超过 3 次**的多项式精确成立，代数精度为 **3**。对称公式的精度常为奇数（高一次误差项自动抵消）。对比：梯形精度 1，柯特斯精度 5。

**知识点**：Newton-Cotes 精度——梯形 n=1→1；辛普森 n=2→3；柯特斯 n=4→5。

### 第 6 题（改进欧拉调用次数）

**题目**：用改进 Euler 法（预估-校正）每推进一个步长，需要调用右端函数 f(x,y) 的次数为（ ）

- A. 1 次　B. 2 次　C. 3 次　D. 4 次

**答案：B**

**解析**：预估步算一次 f，校正步再算一次 f（在预估值处），共 **2 次**。对比：经典 RK4 每步 4 次。

### 第 2 题（Doolittle 分解法）

**题目**：解刚度方程

```
 t1 + 2t2 + 3t3 = 14
2t1 + 5t2 + 2t3 = 18
3t1 +  t2 + 6t3 = 23
```

用 Doolittle 分解法对系数矩阵做 A=LU 分解并解出 t₁, t₂, t₃。

**系数矩阵**：

```
A = [1 2 3]      b = [14, 18, 23]ᵀ
    [2 5 2]
    [3 1 6]
```

- U 第一行：u₁₁=1, u₁₂=2, u₁₃=3
- l₂₁=2/1=2；l₃₁=3/1=3
- u₂₂=5−2×2=1；u₂₃=2−2×3=−4
- l₃₂=(1−3×2)/1=−5

L = [1  0  0]        U = [1  2   3]
    [2  1  0]            [0  1  −4]

- y₁=14

- t₂−4t₃=−10 → t₂−12=−10 → t₂=2
- t₁+2t₂+3t₃=14 → t₁+4+9=14 → t₁=1

### 第 5 题（改进欧拉法）

**题目**：产物浓度满足 dV/dt=0.5−0.25V，V(0)=0。取步长 h=0.1，用改进欧拉法计算 V(0.2)（保留 4 位小数），并与精确解 V(t)=2(1−e^(−0.25t)) 比较。

f(t,V)=0.5−0.25V。

**第 1 步**（V₀=0）：

- f₀=0.5−0=0.5
- 预估 V̂₁=0+0.1×0.5=0.05
- f(V̂₁)=0.5−0.25×0.05=0.4875
- 校正 V₁=0+0.05×(0.5+0.4875)=**0.049375**

**第 2 步**（V₁=0.049375）：

- f₁=0.5−0.25×0.049375=0.48765625
- 预估 V̂₂=0.049375+0.1×0.48765625=0.098140625
- f(V̂₂)=0.5−0.25×0.098140625=0.47546484
- 校正 V₂=0.049375+0.05×(0.48765625+0.47546484)=**0.0975**

**与精确解比较**：

- V(0.2)=2(1−e^(−0.05))≈**0.09754**
- 绝对误差 |0.0975−0.09754| ≈ **1.01×10⁻⁵**

**答案**：V(0.2)≈**0.0975 mol/L**；精确值 0.09754，误差约 1.01×10⁻⁵。

**知识点**：自治方程 f 不显含 t；改进欧拉预估-校正两步；本题精度与二阶方法吻合。

## 四、综合辨析题

### 第 1 题
**场景**：某边坡监测有 50 个含随机噪声的数据点，工程上要求拟合趋势曲线，采用 49 次 Lagrange 插值精确通过每个点。

**结论：不恰当。**

**理由**：含噪声的 50 个点做 49 次插值，会把随机噪声全部拟合进去，高次多项式剧烈振荡，趋势反而失真。应采用最小二乘拟合或分段低次/样条插值，追求整体逼近而非逐点穿过。

**知识点**：插值 vs 拟合——数据无误差且要过点用插值；含噪声要趋势用拟合。

---

### 第 2 题
**场景**：水力计算需对同一管网系数矩阵反复求解多个工况的右端向量，先做 LU 分解再多次前代回代。

**结论：恰当。**

**理由**：矩阵不变、右端多变，LU 分解一次完成，后续每个工况只需前代回代，避免重复消元，计算效率高。

**知识点**：LU 分解适配多右端向量场景。

### 第 3 题
**场景**：对刚性常微分方程，为节省计算时间采用大步长的显式 Euler 法。

**结论：不恰当。**

**理由**：显式 Euler 条件稳定，刚性方程固有快衰减分量，大步长会越过稳定域导致数值解发散。刚性问题应选隐式、A-稳定格式；不能为省时间盲目放大显式方法步长。

**知识点**：刚性方程 → 隐式/A-稳定方法；显式大步长是常见错误。

## 五、算法纠错题（复化 Simpson）

**题目**：下面 Python 代码意图实现复化 Simpson 求积公式，参数 m 为 Simpson 单元个数，每个单元含两个等距子区间。代码存在恰好三处关键逻辑缺陷，标出缺陷行号、说明原因并写出修正语句。

```python
1  def composite_simpson(f, a, b, m):
2      h = (b - a) / (2 * m)
3      s = f(a)
4      for k in range(1, 2 * m + 1):
5          xk = a + k * h
6          if k % 2 == 0:
7              s += 4 * f(xk)
8          else:
9              s += 2 * f(xk)
10     s += f(b)
11     res = s * h / 6
12     return res
```

### 缺陷 1：奇偶系数写反（第 6–9 行）

- **原因**：内部**奇数号**点系数应为 **4**，**偶数号**点系数应为 **2**；代码把偶数点给 4、奇数点给 2，正好相反。
- **改正**：`k%2==1`（奇数点）加 4，`else`（偶数点）加 2。

### 缺陷 2：求和范围混入端点（第 4 行）

- **原因**：循环 `range(1, 2*m+1)` 包含 k=2m（即 x=b），而第 10 行又单独 `s += f(b)`，**端点 f(b) 被重复计入**。
- **改正**：内部点循环应到 2m−1，即 `range(1, 2*m)`。

### 缺陷 3：求积系数错误（第 11 行）

- **原因**：总和应乘 **h/3**，代码写成 h/6（h/6 是单段辛普森系数，复化后应为 h/3）。
- **改正**：`res = s * h / 3`。

### 参考修正代码

```python
def composite_simpson(f, a, b, m):
    h = (b - a) / (2 * m)
    s = f(a)
    for k in range(1, 2 * m):        # 内部点到 2m-1，不含端点 b
        xk = a + k * h
        if k % 2 == 1:               # 奇数点系数 4
            s += 4 * f(xk)
        else:                        # 偶数点系数 2
            s += 2 * f(xk)
    s += f(b)
    return s * h / 3                 # 整体乘 h/3
```

**知识点**：复化辛普森三要点——偶数等分（2m 子区间、2m+1 节点）、奇 4 偶 2、系数 h/3；端点单独计入，不进内部求和循环。
