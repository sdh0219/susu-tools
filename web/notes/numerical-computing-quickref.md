## 一、两类方法各自关注什么

| 大类                      | 核心问题                 | 主要看什么                |
| ----------------------- | -------------------- | -------------------- |
| **求解方程**（求根、解方程组、解 ODE） | 迭代**收不收敛**？收敛**多快**？ | 收敛判据 + 收敛阶 p         |
| **逼近函数**（插值、拟合、积分）      | 近似结果**离真值多近**？       | 余项、误差阶 $O(h^p)$、代数精度 |
|                         |                      |                      |

五个必考计算题的归属：

| 计算题方法  | 归属大类            | 该关注什么                  |
| ------ | --------------- | ---------------------- |
| 牛顿迭代法  | 求解方程 · 非线性求根    | 收敛（f′≠0 + 初值靠近根）、收敛阶 2 |
| LU 分解法 | 求解方程 · 线性方程组直接法 | 不谈迭代收敛；看数值稳定与条件数       |
| 牛顿插值法  | 逼近函数 · 插值       | 余项、误差随节点加密的变化          |
| 复化辛普森法 | 逼近函数 · 数值积分     | 代数精度 3、误差阶 $O(h^4)$    |
| 改进欧拉法  | 求解方程 · 常微分方程    | 相容 + 稳定 ⇒ 收敛，方法阶 p=2   |

## 二、求解方程类：收敛判据 + 收敛阶

### 表 A-1　非线性方程求根

| 方法                  | 怎么判断收敛                                                                                | 收敛阶 p                                      | 关键条件 / 备注                                                 |
| ------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------- |
| 二分法                 | f 连续且 **$f(a)f(b)<0$** ⇒ 必定收敛                                                         | **1**（线性）                                  | 区间长度 $(b-a)/2^n$，取中点的误差界 $(b-a)/2^{n+1}$；慢，但最稳妥，不能求复根、偶重根 |
| 不动点迭代               | 局部：**$\lvert\varphi'(x^*)\rvert<1$**；全局：压缩映射（连续可导、$\lvert\varphi'\rvert\le L<1$、映入自身） | **1**（线性），收敛因子 $\lvert\varphi'(x^*)\rvert$ | 若 $\varphi'(x^*)=0$ 且二阶导非零 → **$p=2$**                    |
| 牛顿法                 | 单根 **f′(x*)≠0**，初值落在根的邻域内 ⇒ 局部收敛                                                      | **2**（平方）；重根退化为 **1**                      | 需算导数、初值敏感；重根要按重数 m 修正                                     |
| 弦截法（割线）             | 两个较好初值                                                                                | **≈1.618**（超线性）                            | 用差商代替导数，免求 f′                                             |
| Aitken / Steffensen | 原序列线性收敛即可加速                                                                           | 加速后可达 **2**                                | 提速明显，受舍入误差影响                                              |

### 表 A-2　线性方程组迭代法

| 方法           | 收敛判据（充要）                | 充分条件                        | 备注                        |
| ------------ | ----------------------- | --------------------------- | ------------------------- |
| Jacobi       | **$\rho(B_J)<1$**，与初值无关 | A 严格对角占优 ⇒ 收敛               | 全程用旧值，可并行；对称正定**不保证**它收敛  |
| Gauss-Seidel | **$\rho(B_{GS})<1$**    | 严格对角占优；**对称正定** ⇒ 收敛        | 用本步新值，串行，通常更快（有反例）        |
| SOR 超松弛      | **$\rho(B_\omega)<1$**  | 对称正定且 **$0<\omega<2$** ⇒ 收敛 | ω=1 即 GS；最优 ω 需试算，选好可大幅加速 |

> 直接法（高斯消元、LU 分解）**不谈迭代收敛**：不计舍入误差时有限步得精确解；它关注的是**数值稳定**（是否选主元）和**条件数**（是否病态）。

### 表 A-3　常微分方程数值解

| 方法 | 收敛判据 | 方法阶 p（整体误差） | 稳定性 |
|---|---|---|---|
| 显式欧拉 | 相容 + 稳定 ⇒ 收敛 | **1**，整体 O(h) | 稳定域很小 |
| 后退欧拉（隐式） | 相容 + 稳定 ⇒ 收敛 | **1**，整体 O(h) | **A 稳定**，刚性可用 |
| 梯形法 | 相容 + 稳定 ⇒ 收敛 | **2**，整体 $O(h^2)$ | A 稳定 |
| 改进欧拉 | 相容 + 稳定 ⇒ 收敛 | **2**，整体 $O(h^2)$ | 稳定域较小 |
| RK4 | 相容 + 稳定 ⇒ 收敛 | **4**，整体 $O(h^4)$ | 稳定域中等，通用首选 |

> ODE 不看"迭代是否收敛到根"，而是看**格式是否相容 + 数值是否稳定**，两者兼备才收敛；再用方法阶 p 衡量精度。

### 收敛阶 p 怎么求

**定义式**：设第 k 步误差 $e_k=x_k-x^*$，若相邻误差满足

$$
\frac{\lvert e_{k+1}\rvert}{\lvert e_k\rvert^{p}}\longrightarrow C\quad(0<C<\infty)
$$

则称该方法为 p 阶收敛。

- **p=1**：线性收敛，相邻误差之比趋于一个常数（每次按固定比例缩小）；
- **1<p<2**：超线性（如弦截 1.618）；
- **p=2**：平方收敛，误差大致按平方缩小，有效数字位数约每轮翻倍。

**实操判断**：

- 不动点：看根处导数 |φ′(x*)| —— 小于 1 线性；等于 0 且二阶导非零 → 平方；
- 牛顿：单根平方、重根线性；
- 实际做题可用相邻两次误差之比估算阶数；
- 线性方程组迭代法的快慢由**谱半径 ρ(B)** 决定：ρ<1 收敛，ρ 越小收敛越快。

### 误差与精度怎么了解（通用口径）

**1. 两类误差先分清**

- **截断误差（方法误差）**：用有限过程代替无限过程产生的，由方法本身决定；
- **舍入误差**：计算机字长有限、四舍五入产生的。

**2. 插值看余项**：误差 = 高阶导数项 × 节点基函数项；既依赖 f 的光滑性，也依赖节点分布。

**3. 积分看两个指标**

- **代数精度**：对几次以内的多项式精确成立（梯形 1、辛普森 3、柯特斯 5、高斯 2n−1）；
- **误差阶 $O(h^p)$**：步长减半，误差约降为 $1/2^p$（梯形 1/4、辛普森 1/16）。

**4. ODE 分清局部与整体截断误差**（最易混）

- **局部误差**：假定上一步精确，这一步公式产生的误差；
- **整体误差**：从初值累积到当前步的总误差；
- 关系：局部 $O(h^{p+1})$ ⇒ 方法为 **p 阶**，整体误差 **$O(h^p)$**，比局部低一阶。

**5. 病态提醒**：方程组误差会被条件数 cond(A) 放大；病态时残差很小不代表误差很小，这是矩阵本性，算法无法消除。

## 四、五个计算题的做题模板 + 真题演练

### 0. 考场通用答题规范

| 环节  | 要求                                     |
| --- | -------------------------------------- |
| 抄已知 | 先把 f(x)、初值、步长、等分数、保留位数写在卷面上，后面算错也能拿步骤分 |

### 1. 牛顿迭代法（Newton）

**题型长相**：给出 f(x)=0 和初值 x₀，要求「求 x₁、x₂」「迭代两次」，或再加一问「判近似根有几位有效数字」。

**做题模板（6 步）**

1. **抄已知**：f(x)、x₀、迭代次数 k、保留位数。
2. **先求导**：写出 f′(x) 的表达式（漏这一步后面全废）。
3. **写迭代格式**：

$$
x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}
$$

4. **每轮固定三行**（照这个格式写，不会乱）：

    - $f(x_k)=\cdots$
    - $f'(x_k)=\cdots$
    - $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}=\cdots$

5. **中间多留 2 位**，最后一轮才修约。
6. **收尾**：写答句；若问有效数字，用误差限判：

$$
|x-x^*| \le 0.5\times10^{m-n}
$$

其中 m 是近似值第一位非零数字所在的数位（如 1.875 的 m=1，即个位）。

**扣分点**

- 忘了先写 f′，直接套 x−f/f′；
- $f'(x_k)$ 接近 0 还硬做除数（重根要改用 m 重公式）；
- 中间值提前四舍五入，导致 x₂ 偏一两位；
- 题目只要求两次迭代，却多算好几轮（不扣分但浪费时间）；
- 有效数字判成「写出了几位数字」。

**真题演练（练习题一 · 计算第 1 题）**

题目：求 f(x)=x³−4x+1=0 在 [1,2] 内的根。取 x₀=2，用 Newton 法求两次迭代 x₁、x₂（保留 4 位小数），并估计近似根的有效数字位数。

f′(x)=3x²−4。

**第 1 轮**（x₀=2）

- f(2)=8−8+1=1
- f′(2)=3×4−4=8
- x₁=2−1/8=**1.8750**

**第 2 轮**（x₁=1.875）

- f(1.875)=1.875³−4×1.875+1≈6.5918−7.5+1=0.0917969
- f′(1.875)=3×1.875²−4≈10.5469−4=6.546875
- x₂=1.875−0.0917969/6.546875≈**1.8610**

**有效数字判定**

- 区间内真实根 ≈1.860806，误差 |1.8610−1.860806|≈1.94×10⁻⁴（按未修约值算约 1.73×10⁻⁴）
- 判 4 位：阈值 $0.5\times10^{1-4}=5\times10^{-4}$，误差 ≤ 阈值，成立
- 判 5 位：阈值 5×10⁻⁵，不成立

**答**：x₁≈1.8750，x₂≈1.8610，近似根有 **4 位有效数字**。

**同型真题（练习题二 · 计算第 1 题）**

题目：f(x)=x³−6x²+11x−6=0，[3,4] 内有根，取 x₀=4，迭代两次求 x₁、x₂。f′(x)=3x²−12x+11。

- 第 1 轮：f(4)=64−96+44−6=6，f′(4)=48−48+11=11，x₁=4−6/11≈**3.4545**
- 第 2 轮：f(3.4545)≈1.6228，f′(3.4545)≈5.3471，x₂≈**3.1510**

该方程三个根为 1、2、3，区间内根是 3，两次迭代后仍在向 3 收敛。

### 2. LU（Doolittle）分解法

**题型长相**：给 3×3 方程组 Ax=b，要求「用 Doolittle 分解求 A=LU 并解出 x₁、x₂、x₃」。

**做题模板（5 步）**

1. **抄 A 和 b**，写成矩阵块，标清行号。
2. **分解 A=LU**：L 是单位下三角（对角全 1），U 是上三角。按下面顺序交替推进，不要跳步：

| 轮次 | 算什么 | 公式 |
|---|---|---|
| ① | U 第 1 行 | u₁ⱼ = a₁ⱼ |
| ② | L 第 1 列 | lᵢ₁ = aᵢ₁/u₁₁ |
| ③ | U 第 2 行 | u₂ⱼ = a₂ⱼ − l₂₁u₁ⱼ |
| ④ | L 第 2 列 | lᵢ₂ = (aᵢ₂ − lᵢ₁u₁₂)/u₂₂ |
| ⑤ | u₃₃ | u₃₃ = a₃₃ − l₃₁u₁₃ − l₃₂u₂₃ |

通式：

$$
u_{ij}=a_{ij}-\sum_{k=1}^{i-1}l_{ik}u_{kj}\ (i\le j),\qquad
l_{ij}=\frac{a_{ij}-\sum_{k=1}^{j-1}l_{ik}u_{kj}}{u_{jj}}\ (i>j)
$$

3. **解 Ly=b**（前代，从上往下）：

$$
y_1=b_1,\quad y_i=b_i-\sum_{k=1}^{i-1}l_{ik}y_k
$$

4. **解 Ux=y**（回代，从下往上）：

$$
x_n=\frac{y_n}{u_{nn}},\quad x_i=\frac{y_i-\sum_{k=i+1}^{n}u_{ik}x_k}{u_{ii}}
$$

5. **代回原方程核验**，写答句。

**扣分点**

- L 的对角不是 1（那是 Crout 分解的写法，Doolittle 必须为 1）；
- 前代与回代顺序搞反（L 从上往下、U 从下往上）；
- 分解顺序乱跳，导致 u₂₂ 还没算就求 l₃₂；
- 主元为负以为算错（负主元不影响分解正确性，只说明顺序主子式可非零）；
- 分解条件没数：各阶顺序主子式非零才保证 Doolittle 可做。

**真题演练（练习题一 · 计算第 2 题）**

题目：解方程组（刚度方程）

$$
\begin{cases}2x_1+x_2+x_3=5\\2x_1+4x_2+3x_3=13\\4x_1-x_2+4x_3=6\end{cases}
$$

用 Doolittle 分解求 A=LU 并解出 x₁、x₂、x₃。

A = [[2,1,1],[2,4,3],[4,−1,4]]，b=[5,13,6]。

**第一步：分解**

- U 第 1 行：u₁₁=2，u₁₂=1，u₁₃=1
- L 第 1 列：l₂₁=2/2=1，l₃₁=4/2=2
- U 第 2 行：u₂₂=4−1×1=3，u₂₃=3−1×1=2
- L 第 2 列：l₃₂=(−1−2×1)/3=−1
- u₃₃=4−2×1−(−1)×2=4

$$
L=\begin{bmatrix}1&0&0\\1&1&0\\2&-1&1\end{bmatrix},\qquad
U=\begin{bmatrix}2&1&1\\0&3&2\\0&0&4\end{bmatrix}
$$

**第二步：Ly=b 前代**

- y₁=5
- y₂=13−1×5=8
- y₃=6−2×5−(−1)×8=4

**第三步：Ux=y 回代**

- 4x₃=4 → x₃=1
- 3x₂+2×1=8 → x₂=2
- 2x₁+2+1=5 → x₁=1

**答**：x₁=**1**，x₂=**2**，x₃=**1**。

核验：2+2+1=5 ✓；2+8+3=13 ✓；4−2+4=6 ✓。

**同型真题（练习题二 · 计算第 2 题）**

题目：t₁+2t₂+3t₃=14；2t₁+5t₂+2t₃=18；3t₁+t₂+6t₃=23，用 Doolittle 分解求解。

- 分解：u₁₁=1,u₁₂=2,u₁₃=3；l₂₁=2,l₃₁=3；u₂₂=5−4=1，u₂₃=2−6=−4；l₃₂=(1−6)/1=−5；u₃₃=6−9−20=−23
- L=[[1,0,0],[2,1,0],[3,−5,1]]，U=[[1,2,3],[0,1,−4],[0,0,−23]]
- 前代：y₁=14，y₂=18−28=−10，y₃=23−42−50=−69
- 回代：t₃=−69/−23=3，t₂=−10+12=2，t₁=14−4−9=1

答：t₁=**1**，t₂=**2**，t₃=**3**。

> 注：本题 u₃₃=−23 是负主元，分解照样成立，不必怀疑算错。

### 3. 牛顿插值法（差商）

**题型长相**：给 3 个（或 n+1 个）节点和函数值，要求「用 Newton 差商公式构造插值多项式，并求某点处的近似值」。

**做题模板（5 步）**

1. **列节点表**，按 x 从小到大排序（没排序就先排，否则差商全错）。
2. **造差商表**（上三角，只在有值处填）：

| $x_i$ | $f(x_i)$ | 一阶差商 | 二阶差商 |
|---|---|---|---|
| x₀ | y₀ | | |
| x₁ | y₁ | f[x₀,x₁]=(y₁−y₀)/(x₁−x₀) | |
| x₂ | y₂ | f[x₁,x₂]=(y₂−y₁)/(x₂−x₁) | f[x₀,x₁,x₂]=(f[x₁,x₂]−f[x₀,x₁])/(x₂−x₀) |

3. **取系数**：取差商表「最上一行」那条斜线，即 f[x₀]、f[x₀,x₁]、f[x₀,x₁,x₂]。
4. **写多项式**（逐项乘上前面所有因子）：

$$
N_n(x)=f[x_0]+f[x_0,x_1](x-x_0)+f[x_0,x_1,x_2](x-x_0)(x-x_1)+\cdots
$$

5. **代值 + 核验**：代入所求点算数值；把已知节点代回，必须等于原函数值。

**扣分点**

- 二阶差商分母写成 (x₂−x₁) 或 1（必须跨两个区间，用 **x₂−x₀**）；
- 系数取错：取了表中间某个差商，而不是最上层斜线；
- 第三项漏乘 (x−x₀)，写成 (x−x₁)(x−x₂)；
- 节点没排序就直接套公式；
- 不核验，最后不知道自己错在哪。

**真题演练（练习题一 · 计算第 3 题）**

题目：沉降监测数据 t（月）=0、1、2，w（mm）=3、5、9。（1）用 Newton 差商公式构造二次插值多项式；（2）求 t=1.5 时的沉降量。

**第一步：差商表**

| t | w | 一阶差商 | 二阶差商 |
|---|---|---|---|
| 0 | 3 | | |
| 1 | 5 | (5−3)/(1−0)=2 | |
| 2 | 9 | (9−5)/(2−1)=4 | (4−2)/(2−0)=1 |

系数：f[0]=3，f[0,1]=2，f[0,1,2]=1。

**第二步：写多项式**

$$
N_2(t)=3+2t+1\cdot t(t-1)=t^2+t+3
$$

**第三步：代 t=1.5**

$$
N_2(1.5)=2.25+1.5+3=\mathbf{6.75}
$$

**答**：N₂(t)=**t²+t+3**，t=1.5 时沉降量约 **6.75 mm**。

核验：N₂(0)=3 ✓，N₂(1)=5 ✓，N₂(2)=9 ✓。

**同型真题（练习题二 · 计算第 3 题）**

题目：x=0、1、2，y=2、4、8，构造二次 Newton 插值并求 x=1.5 处值。

- 差商：一阶 2、4；二阶 (4−2)/(2−0)=1
- 系数 2、2、1 → N₂(x)=2+2x+x(x−1)=**x²+x+2**
- N₂(1.5)=2.25+1.5+2=**5.75**

> 两套卷的插值题结构完全同型（都是 y=x²+x+c），只是常数不同，说明命题就按这个套路走。

**补充：节点变多怎么算（4 个点、5 个点）**

点一变多，很多人卡在两件事上：不知道算到哪一阶、不知道分母除以几。先记三条规则。

**三条铁规则**

1. **k 个点 → 最高只到 k−1 阶差商**，插值多项式次数也是 k−1。3 点算到二阶、4 点算到三阶、5 点算到四阶，别多算也别少算。
2. **分母是「跨距」，不是相邻间距**：某列的差商 = 上一列两个相邻值相减，除以这两个值**起点与终点的 x 之差**。等距节点 h 时：一阶除以 h，二阶除以 2h，三阶除以 3h。**这一条错得最多**——很多人二阶也除以 h。
3. **系数只取每列最上面那一个**：f[x₀]、f[x₀,x₁]、f[x₀,x₁,x₂]、f[x₀,x₁,x₂,x₃]…… 表里其余格子都是中间量，不用写进多项式。

**n+1 个点的通用表骨架**

| $x_i$ | $f(x_i)$ | 一阶 | 二阶 | 三阶 | 四阶 |
|---|---|---|---|---|---|
| x₀ | f₀ | | | | |
| x₁ | f₁ | f[x₀,x₁] | | | |
| x₂ | f₂ | f[x₁,x₂] | f[x₀,x₁,x₂] | | |
| x₃ | f₃ | f[x₂,x₃] | f[x₁,x₂,x₃] | f[x₀,x₁,x₂,x₃] | |
| x₄ | f₄ | f[x₃,x₄] | f[x₂,x₃,x₄] | f[x₁,x₂,x₃,x₄] | f[x₀,x₁,x₂,x₃,x₄] |

> 看表就知道：**每往右一列，分母就多跨一格**。二阶那列的分母是 x₂−x₀，三阶是 x₃−x₀，四阶是 x₄−x₀。

**4 个点完整演算（三阶）**

数据：x=0、1、2、3，y=2、4、8、16。

| $x_i$ | $f(x_i)$ | 一阶 | 二阶 | 三阶 |
|---|---|---|---|---|
| 0 | 2 | | | |
| 1 | 4 | (4−2)/1=2 | | |
| 2 | 8 | (8−4)/1=4 | (4−2)/(2−0)=1 | |
| 3 | 16 | (16−8)/1=8 | (8−4)/(3−1)=2 | (2−1)/(3−0)=1/3 |

逐格看分母：一阶全是 1（跨一格）；二阶是 2（跨两格 x₂−x₀）；三阶是 3（跨三格 x₃−x₀）。

系数取最上层斜线：2、2、1、1/3。

$$
N_3(x)=2+2x+1\cdot x(x-1)+\frac{1}{3}x(x-1)(x-2)
$$

展开合并：

$$
N_3(x)=\frac{x^3}{3}+\frac{5}{3}x+2
$$

求 x=1.5：

$$
N_3(1.5)=2+3+0.75-0.125=\mathbf{5.625}
$$

核验四个节点：N₃(0)=2 ✓，N₃(1)=4 ✓，N₃(2)=8 ✓，N₃(3)=16 ✓（展开式代入 3 得 16）。

**再加第 5 个点：只往右补一列**

接着加 x₄=4，y₄=32。原有格子一个都不用重算，只新增右侧斜边：

- 一阶：f[3,4]=(32−16)/1=16
- 二阶：f[2,3,4]=(16−8)/(4−2)=4
- 三阶：f[1,2,3,4]=(4−2)/(4−1)=2/3
- 四阶：f[0,1,2,3,4]=((2/3)−(1/3))/(4−0)=1/12

新多项式 = 原多项式 + 新系数乘一串因子：

$$
N_4(x)=\frac{x^3}{3}+\frac{5}{3}x+2+\frac{1}{12}x(x-1)(x-2)(x-3)
$$

**这就是牛顿插值比拉格朗日好用的地方**：加节点不用重算，原来那四项系数（2、2、1、1/3）原样保留，只在末尾添一项。核验 N₄(4)=30+2=32 ✓。

**点更多时的操作节奏**

1. 先把 x 从小到大排好，列成表；
2. 从左到右一列一列填，每填一格只做「相减 + 除以跨距」两步；
3. 填完看最上层斜线的 k 个数，直接抄成多项式；
4. 代所求点求值，再拿原来 k 个节点回代核验——只要有一个不相等，就是表填错了。

### 4. 复化辛普森法

**题型长相**：给积分区间 [a,b] 和等分数（常给「四等分」「2 个 Simpson 单元」），要求用复化 Simpson 算近似值，并与精确值比较误差。

**做题模板（5 步）**

1. **确认偶数等分**：n 必须为偶数（n=2m，共 2m+1 个节点）；算 h=(b−a)/n。
2. **列表算节点与函数值**：$x_i=a+ih$，逐点算 $f_i$，保留 6 位以上。
3. **套公式**：

$$
S=\frac{h}{3}\Big[f_0+f_n+4\sum_{i\ 奇}f_i+2\sum_{i\ 偶}f_i\Big]
$$

   口诀：**端点 1，奇数点 4，偶数点 2，整体乘 h/3**。5 个节点时系数序列就是「1 4 2 4 1」。

4. **先算括号内**：加权和算完再乘 h/3，中途不修约。
5. **比误差 + 说阶**：与精确值相减得绝对误差；若问误差阶，说明 O(h⁴)，步长减半误差约降为 1/16。

**扣分点**

- n 取成奇数（辛普森必须偶数等分，否则最后一个小区间没法配对）；
- 端点也乘 4（端点系数是 1）；
- 系数写错成 h/6、h/2（复化辛普森是 h/3）；
- 把「4 等分」说成「4 个 Simpson 单元」（实为 2 个单元，每单元 2 个小区间）；
- 中途修约，误差位对不上。

**真题演练（练习题一 · 计算第 4 题）**

题目：计算 I=∫₀¹ 1/(1+x²) dx，将 [0,1] 四等分（2 个 Simpson 单元），用复化 Simpson 求近似值（保留 5 位小数），与精确值 π/4 比较绝对误差。

**第一步：步长与节点**

h=0.25，节点 0、0.25、0.5、0.75、1。

| x | 0 | 0.25 | 0.5 | 0.75 | 1 |
|---|---|---|---|---|---|
| f=1/(1+x²) | 1 | 0.94117647 | 0.8 | 0.64 | 0.5 |

**第二步：加权**

$$
S=\frac{0.25}{3}\Big[1+0.5+4(0.94117647+0.64)+2\times0.8\Big]
$$

括号内：1+0.5=1.5；4×1.58117647=6.32470588；2×0.8=1.6；合计 9.42470588。
乘 0.25/3=0.0833333 → S≈**0.78539216**。

**第三步：比误差**

- 近似值（5 位）：**0.78539**
- 精确值 π/4≈0.78539816
- 绝对误差 ≈ **6.0×10⁻⁶**

**答**：I≈**0.78539**，绝对误差约 6.0×10⁻⁶（符合 O(h⁴) 量级）。

**同型真题（练习题二 · 计算第 4 题）**

题目：I=∫₀¹ 1/(1+x) dx，四等分，h=0.25，与 l'n2 比误差。

- 节点值：1、0.8、0.66666667、0.57142857、0.5
- 加权括号：1+0.5=1.5；4(0.8+0.57142857)=5.48571428；2×0.66666667=1.33333334；合计 8.31904762
- S=(0.25/3)×8.31904762≈**0.69325397** → 保留 5 位 **0.69325**
- 精确值 ln2≈0.69314718，误差 ≈ **1.07×10⁻⁴**

> 同型题的差别只在被积函数，四等分与 h=0.25 完全一样，可直接照模板套。

### 5. 改进欧拉法（预估-校正）

**题型长相**：给一阶初值问题 y′=f(x,y)、y(x₀)=y₀、步长 h，要求算到某点（多为 2 步到 0.2）的近似值，并与精确解比较误差。

**本质**：显式欧拉做「预估」，再用梯形公式做「校正」，所以是二阶方法、每步算 **2 次**右端函数 f。

**做题模板（5 步）**

1. **认参数**：写出 f(x,y)、y₀、h、目标点；步数 =（目标点−x₀）/h。
2. **写格式**（两行，缺一不可）：

$$
\hat y_{n+1}=y_n+h\,f(x_n,y_n)\qquad\text{（预估）}
$$

$$
y_{n+1}=y_n+\frac{h}{2}\big[f(x_n,y_n)+f(x_{n+1},\hat y_{n+1})\big]\qquad\text{（校正）}
$$

3. **表格化记录**（每步 7 列，照这个填不会漏）：

| 步   | $x_n$ | $y_n$    | $f_n=f(x_n,y_n)$ | 预估 $\hat y_{n+1}=y_n+hf_n$ | $\hat f=f(x_{n+1},\hat y_{n+1})$ | 校正 $y_{n+1}=y_n+\frac{h}{2}(f_n+\hat f)$ |
| --- | ----- | -------- | ---------------- | -------------------------- | -------------------------------- | ---------------------------------------- |
| 0   | x₀    | y₀       |                  |                            |                                  |                                          |
| 1   | x₁    | ↑由上一行投下来 |                  |                            |                                  |                                          |

4. **逐步推进**：上一行的校正值就是下一步的 $y_n$，接着算 $f_n$。
5. **收尾**：给了精确解就算绝对误差；同时说明这是二阶方法、误差阶 O(h²)。

**扣分点**

- 校正时用错 f：必须用 **预估点 $\hat y$ 处的 f**，不能用 $y_{n+1}$ 再算一遍（那是隐式梯形，不能直接算）；
- h/2 写成 h（一下就退化成一阶）；
- 每步 $f(x_n,y_n)$ 前后算得不一致；
- h=0.1、目标 0.2 却只算一步（要两步）；
- 没写「预估—校正」两阶段，直接一步到底。

**真题演练（练习题一 · 计算第 5 题）**

题目：炉温满足 dT/dt=−0.5(T−25)，T(0)=100。取 h=0.1，用改进欧拉法求 T(0.2)（保留 4 位小数），与精确解 $T(t)=25+75e^{-0.5t}$ 比较。

f(t,T)=−0.5(T−25)。

**第 1 步**（t₀=0，T₀=100）

- f₀=−0.5(100−25)=**−37.5**
- 预估 T̂₁=100+0.1×(−37.5)=**96.25**
- f̂=−0.5(96.25−25)=**−35.625**
- 校正 T₁=100+0.05×(−37.5−35.625)=100−3.65625=**96.34375**

**第 2 步**（t₁=0.1，T₁=96.34375）

- f₁=−0.5(96.34375−25)=**−35.671875**
- 预估 T̂₂=96.34375+0.1×(−35.671875)=**92.7765625**
- f̂=−0.5(92.7765625−25)=**−33.88828125**
- 校正 T₂=96.34375+0.05×(−35.671875−33.88828125)=96.34375−3.4780078=**92.8657**

**比误差**

- 精确值 $T(0.2)=25+75e^{-0.1}\approx$**92.8628**
- 绝对误差 ≈ **2.94×10⁻³**

**答**：T(0.2)≈**92.8657 ℃**，精确值 92.8628 ℃，误差约 2.94×10⁻³。

**同型真题（练习题二 · 计算第 5 题）**

题目：dV/dt=0.5−0.25V，V(0)=0，h=0.1，求 V(0.2)，与精确解 $V(t)=2(1-e^{-0.25t})$ 比较。

- 第 1 步：f₀=0.5；V̂₁=0.05；f̂=0.4875；V₁=0.05×(0.5+0.4875)=**0.049375**
- 第 2 步：f₁=0.5−0.25×0.049375=0.48765625；V̂₂=0.098140625；f̂=0.47546484；V₂=0.049375+0.05×(0.48765625+0.47546484)=**0.0975**
- 精确值 $V(0.2)=2(1-e^{-0.05})\approx0.09754$，误差 ≈ **1.01×10⁻⁵**

> 本题右端 f 不显含 t（自治方程），算出 f 值后直接代入即可，公式不变。

### 3. 综合辨析题（6 题，两套高度同型）

| 场景                            | 卷   | 判定  | 依据 / 正确做法                              |

##### 4.4.1 一改就错（数值层面）

| 算法           | 课件原写法                                            | 被改坏后                                    | 后果                                                                |
| ------------ | ------------------------------------------------ | --------------------------------------- | ----------------------------------------------------------------- |
| 二分           | `while (b - a) / 2 > tol`                        | `while b - a > tol`                     | 漏掉 `/2`：判据**严了一倍**（误差界由 tol 收紧到 tol/2），同样 tol 会**多**迭代一轮，结果数值略有不同 |
| 二分           | `if f(a)*f(c) < 0: b = c else: a = c`            | `if f(a)*f(c) > 0: b = c`               | 区间收到不含根的一侧，越算越偏                                                   |
| 高斯消去         | `f = aug[r,c] / aug[c,c]`                        | `f = aug[c,c] / aug[r,c]`               | 消元因子取成倒数，整行消元失效                                                   |
| 高斯消去         | `aug[r] -= f * aug[c]`                           | `aug[r,c] -= f * aug[c,c]`              | 只改了主元位置一个数，其余元素没消                                                 |
| 高斯消去回代       | `(aug[i,-1] - aug[i,i+1:] @ x[i+1:]) / aug[i,i]` | `(aug[i,-1] - aug[i,:] @ x) / aug[i,i]` | 对角项被重复计入，回代值偏小                                                    |
| 列主元          | `max_row = k + np.argmax(np.abs(Ab[k:, k]))`     | 漏掉 `k +`                                | 索引落在切片内，交换到错误的行                                                   |
| 列主元          | `Ab[[k, max_row]] = Ab[[max_row, k]]`            | `Ab[k] = Ab[max_row]`                   | 这是覆盖不是交换，第 k 行被冲掉                                                 |
| Jacobi       | `s` 的两段都用旧 `x`                                   | 前半段换成 `x_new[:i]`                       | 用了新值，退化成 Gauss-Seidel                                             |
| Jacobi       | `x_new[i] = (b[i]-s) / A[i,i]`                   | `x[i] = (b[i]-s) / A[i,i]`              | 原地更新，后面的 i 读到已改的新值                                                |
| Gauss-Seidel | `x_new = x.copy()`                               | `np.zeros_like(x)`                      | `x[i+1:]` 全变 0，旧值信息丢失                                             |
| Gauss-Seidel | `s` = 新的前半段 + 旧的后半段                              | 两段都用 `x`                                | 新值没用上，退化为 Jacobi                                                  |
| Newton       | `x_new = x - f(x) / f_prime(x)`                  | `x - f_prime(x) / f(x)`                 | 公式颠倒，迭代直接发散                                                       |

##### 4.4.2 课件本身就不健壮（考卷可能让你补上）

| 算法          | 课件缺什么                          | 补法                                        |
| ----------- | ------------------------------ | ----------------------------------------- |
| 二分          | 没有 `max_iter` 上限，只有 `while` 循环 | 加迭代计数或 `for _ in range(max_iter)`         |

##### 4.4.3 三句话记住

1. **数值错只出在三处**：方向（新旧值用反）、下标（起止差一）、系数（乘除颠倒或倍数错）。
2. **健壮性只缺三样**：零除数没判、步数没上限、状态没返回。
3. 答题顺序仍是 6.4 的四查：系数 → 边界 → 判零 → 保护；只是现在有了课件原写法可直接对照，不用靠猜。

#### 4.5 六条清单的实例对照（错法会算成什么样）

> 4.3 说「查什么」，4.4 说「错法长什么样」。这一节补最后一块：**每种错法算出来的数字坏成什么级别**。下面每个数字都是照被改坏的写法真跑出来的，症状可以直接背，考场对号入座。

**例 1（对清单 2 · 循环边界漏端点）** 复化梯形算 $\int_0^1 x^2\,dx$，$n=4$，真值 $1/3=0.333333$。

| 写法 | 结果 | 后果 |
|---|---|---|
| 正确：中段 `range(1, n)`，两端各给 0.5 权重 | **0.34375** | 正常截断误差 $1.0\times10^{-2}$ |
| 错：中段写成 `range(1, n)` 却漏了 $f(x_n)$ | **0.21875** | 少算 **36.4%** |
| 错：右端点被当中段算（权重 1 而非 0.5） | **0.46875** | 多算 **36.4%** |

端点权重只有 0.5，所以漏端点或端点加错，误差就固定在「一截」上——**结果比正确值小三成左右，先怀疑端点**。

**例 2（对清单 1 · 除法前不判零）** 解方程组 $10^{-16}x+y=1$、$x+y=2$，真解 $(1,\ 1)$。

| 写法 | 解出 | 后果 |
|---|---|---|
| 不选主元，直接消元 | **$(2.220446,\ 1.0)$** | 完全错 |
| 部分选主元（换行） | **$(1.0,\ 1.0)$** | 正确 |

机制：消元因子 $f=1/10^{-16}=10^{16}$。浮点里 $10^{16}\cdot10^{-16}$ 并不精确等于 1，而是 $1+2\times10^{-16}$，这点残差除以 $10^{-16}$ 后放大成 $2.22$。**小数当除数，舍入误差被放大 $10^{16}$ 倍**——这就是「不判零、不选主元」的真实代价。

**例 3（对清单 3 · 系数与公式不对应）** 复化辛普森算 $\int_0^1 x^3\,dx$，$n=4$，真值 $0.25$。

| 权重序列 | 结果 | 后果 |
|---|---|---|
| 正确 1-4-2-4-1 | **0.25** | 精确（三次以内辛普森无误差） |
| 错成 1-2-4-2-1 | **0.197917** | 相对误差 20.8% |
| 错成全 4 | **0.520833** | 相对误差 108% |

这一条有个硬判据：**辛普森对三次以内多项式本应精确**。所以题目若给的是三次函数、结果却有百分级偏差，不用推，直接认定权重或倍数写错。

**例 4（对清单 4 · 整体倍数）** 同一梯形公式，真值 0.333333。

| 写法 | 结果 | 后果 |

| $h/2$（正确） | 0.34375 | 正常 |

**例 5（对清单 5、6 · 判据单一 + 无步数保护）** 牛顿法求 $\arctan x=0$，$x_0=2$：

##### 4.6.1 课件原版（考试对照基准，务必逐行记住）

```python
1  def bisection(f, a, b, tol=1e-6):
2      if f(a) * f(b) >= 0:
3          raise ValueError("端点需异号")
4      while (b - a) / 2 > tol:
5          c = (a + b) / 2
6          if f(a) * f(c) < 0:
7              b = c
8          else:
9              a = c
10     return (a + b) / 2
```

每行对应的公式：

| 行 | 对应 |
|---|---|
| 2–3 | 前提：连续 + 端点异号 $f(a)f(b)<0$，不满足直接报错（教材写 `>= 0` 才严谨） |
| 4 | 停机判据用**中点误差界** $\frac{b-a}{2}$，与理论界 $\lvert x_n-x^*\rvert\le\frac{b-a}{2^{n+1}}$ 一致 |
| 5 | Step 1：取中点 |
| 6–7 | Step 3：$f(a)f(c)<0$ ⇒ 根在 $[a,c]$ ⇒ **$b=c$** |
| 8–9 | Step 4：否则根在 $[c,b]$ ⇒ **$a=c$** |
| 10 | 返回**中点**，误差界才是上面那个 $2^{n+1}$ |

**课件这版的短板**：只有 `while`、没有 `max_iter`，也不返回迭代次数与收敛状态 → 属 4.4.2 的「缺失型」。

##### 4.6.2 模拟题 A（6 分，仿卷一：逻辑与健壮型）

> 下面 Python 代码意图实现二分法求 $f(x)=0$ 的实根，含三处缺陷，覆盖收敛判据、区间更新逻辑与前提检查。请标出缺陷行号、说明原因并写出修正语句。

```python
1  def bisection(f, a, b, tol=1e-6):
2      if f(a) * f(b) > 0:
3          raise ValueError("端点需异号")
4      while b - a > tol:
5          c = (a + b) / 2
6          if f(a) * f(c) > 0:
7              b = c
8          else:
9              a = c
10     return (a + b) / 2
```

**标准答案**

| 行号 | 错误 | 原因 | 修正语句 |
|---|---|---|---|
| 2 | `>` 应为 `>=` | 前提是「必须严格异号」。写成 `>` 时，端点恰为根（$f(a)f(b)=0$）不报错，程序仍在根已被排除的区间里二分 | `if f(a) * f(b) >= 0:` |
| 4 | 漏 `/ 2` | 判据原本判的是**中点误差**；改成区间长度后判据严一倍，误差界由 $tol$ 收到 $tol/2$，同样 $tol$ 会多迭代一轮 | `while (b - a) / 2 > tol:` |
| 6 | `< 0` 写成 `> 0` | $f(a)f(c)>0$ 表示两端同号、根**不在** $[a,c]$，此时令 $b=c$ 就把含根的一半丢掉了，越算越偏 | `if f(a) * f(c) < 0:` |

**实测后果**（$f=x-\cos x$、$[0,1]$、$tol=10^{-6}$、真根 0.7390851332）：正确版 19 轮得 0.7390852；此题版本 **20 轮**返回 **0.0000004768**，误差 $7.4\times10^{-1}$——「正常退出、结果错到底」，是这类题最典型的陷阱。

##### 4.6.3 模拟题 B（6 分，仿卷二：系数/边界型）

> 下面 Python 代码意图实现二分法，含恰好三处关键缺陷。请标出所在行号，说明错误原因并写出修正语句。

```python
1  def bisection(f, a, b, tol=1e-6):
2      if f(a) * f(b) >= 0:
3          raise ValueError("端点需异号")
4      while (b - a) / 2 > tol:
5          c = a + b / 2
6          if f(a) * f(c) < 0:
7              b = c
8          else:
9              a = c
10     return a + b
```

**标准答案**

| 行号 | 错误 | 原因 | 修正语句 |
|---|---|---|---|
| 5 | 运算符优先级：`a + b / 2` | 先算 `b/2` 再与 `a` 相加；$a\neq0$ 后中点会落到区间外（如 $[0.5,1]$ 时 $c=1$），区间不再收窄 → **死循环** | `c = (a + b) / 2` |
| 10 | 返回 `a + b` | 忘除 2，返回值约为根的 2 倍（端点误差被放大），且不再是中点 | `return (a + b) / 2` |
| 4 | 只有区间判据、无步数上限（缺失型） | 第 5 行一旦写错就无限循环，程序既不退出也不报错，无法发现 | 改 `for _ in range(max_iter):`，并返回 `(root, k, converged)` |

**关键提醒**：这三处会互相掩盖——第 5 行导致卡死，第 10 行的「两倍」根本跑不到，第 4 行让程序永远不会告诉你出事了。**考场若给了运行结果“程序不结束”，就是这条链。**

##### 4.6.4 二分专属症状反查

| 看到的症状 | 缺陷 |
|---|---|
| 结果 ≈ 左端点 $a$ 或 ≈ 右端点 $b$（如 0.0000005、0.9999990） | 第 6 行符号方向反 / 两支互换 / 只更新一支 |
| 结果正好是正确值的 2 倍 | 第 10 行 `return` 忘除 2 |
| 迭代次数比手算多一轮 | 第 4 行判据漏 `/2` |
| 程序卡死、区间长度不再变小 | 第 5 行中点写错（`a+b/2`）、只更新一支、无 `max_iter` |
| 一调用就 `ValueError` | 第 2 行被改成 `> 0`（正常异号区间误报） |

##### 4.6.5 若题目问「至少二分多少次」

教材公式（梳理册第 7 页）：

$$n \ge \log_2\frac{b-a}{\varepsilon} - 1$$

由 $\lvert x_n-x^*\rvert\le\dfrac{b-a}{2^{n+1}}\le\varepsilon$ 反解而来，**向上取整**。

校验：课件《总结-复习》例题 $f(x)=x^3-x-1$、$[1,2]$、要求 $\lvert\cdot\rvert<10^{-4}$：

$$n \ge \log_2\frac{1}{10^{-4}}-1 = 13.29-1 = 12.29 \Rightarrow n = 13$$

与课件写的「继续二分到 $k=13$，得 $x^*\approx1.3247$（误差 $<10^{-4}$）」完全一致——**这条公式可以直接背，考场问次数就套它**。

### 6. 四类题型的通用打法（前 5 节怎么用）

> 前 5 小节是知识归并，这一节是答题流程。四类题共用一条底层逻辑：**先认题型，再走固定流程**。

#### 6.1 选择题：四步排除

1. **先看问什么**：条件型（充分/必要/充要）、阶数型、目的型、现象型——四类问法各有固定答案集，认出来就不用推；
2. **扫绝对化词**：「一定」「必须」「所有」「无条件」「只需」→ 先假定它错；
3. **做同类互换**：把一个方法的条件挪到另一个上试（对称正定 → Jacobi、严格对角占优 → GS），挪过去不成立，说明原选项在偷换适用对象；
4. **二选一时取弱命题**：数学里弱命题更容易为真——「局部」比「全局」稳、「至少」比「恰好」稳、「某些情形」比「任何情形」稳。

**干扰项四大设计套路**（认出来可直接排除）：

| 套路 | 卷内实例 | 识别方法 |
|---|---|---|
| 偷换适用对象 | 「A 对称正定 ⇒ Jacobi 收敛」（卷一选 2 的 A 项） | 条件只对某一方法成立，被挪到另一个方法上 |
| 相邻阶数错位 | 弦截填 2 阶（卷二选 3 的 C 项）、梯形填代数精度 2（卷二判 5） | 把 p 与 p±1、方法与本该更高的方法互换 |
| 混淆措施目的 | 列主元「减少运算次数」（卷二选 4 的 A 项） | 稳定性措施被说成效率措施或结构改造 |
| 方向反转 | cond 小 ⇒ 病态（卷一判 2） | 大小、正反、进退颠倒 |

#### 6.2 判断题：三步判定

1. **拆主语与条件**：说的是谁对谁，前提是什么（「对任何函数」「只要…就」「不管…都」重点盯）；
2. **找钩子词**：一定 / 必然 / 无条件 / 所有 / 都 / 任何 —— 出现就按 × 起判；
3. **举反例**：30 秒内能想到一个反例 → ×；想不到且表述保守（「通常」「在…条件下」）→ √。

**换词自检**：把命题里的「是 / 可以 / 一定能」换成「不一定」，若换完读起来更顺、更合理，原命题大概率是 ×。

#### 6.3 辨析题：三段式 + 三把分叉

答题骨架：**判定（恰当/不恰当）→ 依据（这个方法的前提条件）→ 正确做法（该换用什么）**，三句缺一扣分。

三把分叉，场景一出现就按这个判：

| 场景特征 | 判定 | 依据一句话 | 正确做法 |
|---|---|---|---|
| 数据含噪声 + 要求精确通过每个点 | 不恰当 | 噪声被当信号，高次插值振荡 | 分段低次 / 样条 / 最小二乘拟合 |
| 同一矩阵 + 多组右端反复求解 | 恰当 | 分解一次、回代多次 | 保留 LU，别每次重新消元 |
| 刚性方程 + 放大步长省时间 | 不恰当 | 显式格式条件稳定，越出稳定域发散 | 隐式 / A-稳定格式 |

判「恰当」的题不能只写「合适」，必须写出它**省了什么**（省掉每次重新消元）或**买到了什么**（$O(h^4)$ 精度、系数全正稳定）。

#### 6.4 纠错题：四查顺序

按「会算错 → 不会算错」排序，先抓致命错：

| 顺序 | 查什么 | 卷内实例 |
|---|---|---|
| ① 系数 | 奇偶系数、整体倍数 | 辛普森偶数点给了 4、$h/6$ 应为 $h/3$ |
| ② 边界 | 端点是否重复、循环开闭 | `range(1, 2*m)` 已含 $b$，又单独加 $f(b)$ |
| ③ 判零 / 定义域 | 除法、开方、对数 | 先算 $f/f'$ 再判导数近零，除零已发生 |
| ④ 保护与返回 | 判据数量、步数上限、状态 | `continue` 空转、只判残差不判步长 |

答法三件套缺一不可：**行号 + 原因 + 改法**；改法最好直接写成可替换的那一行代码，别只写「应改为正确写法」。

#### 6.5 答题时间与给分点

| 题型  | 建议用时      | 关键给分点             |
| --- | --------- | ----------------- |
| 选择  | 每题 ≤ 1 分钟 | 只要结论，别在卷面推导       |
| 判断  | 每题 ≤ 30 秒 | 写 √/× 即可，不必解释     |
| 辨析  | 每题 3–4 分钟 | 判定 + 依据 + 做法，三句齐全 |
| 纠错  | 每题 5–6 分钟 | 行号、原因、改法三件套       |

> 一句话收口：**选择靠认套路，判断靠找钩子，辨析靠三句话，纠错靠四查顺序。**

## 六、一句话速记

- **求解方程**：先判"收不收"（二分看异号、不动点看 φ′、迭代法看 ρ(B)<1、ODE 看相容+稳定），再看"多快"（收敛阶 p）。
- **逼近函数**：不问收敛，只看"多近"——插值看余项、积分看代数精度和 $O(h^p)$、拟合看残差。
- **阶数对照**：二分 / 不动点 / 重根牛顿 = 1；弦截 ≈ 1.618；单根牛顿 = 2；分段线性 / 复化梯形 = $O(h^2)$；分段三次 / 样条 / 复化辛普森 / RK4 = $O(h^4)$。
