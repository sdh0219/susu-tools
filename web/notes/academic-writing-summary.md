# 第 1 讲 绪论

## 1.1 科技论文概述

### 概念（名词解释高频）
- **科技论文（广义）**：报道科学研究和技术开发创新性工作成果的论说文章，通过概念、判断、推理、证明或反驳等逻辑思维手段，分析、表达科学理论和技术开发研究成果。
- **分类**：国家标准 GB/T 7713—1987《科学技术报告、学位论文和学术论文的编写格式》把科技论文分为 **3 类**：
  1. **学位论文**：表明作者从事科学研究取得创造性结果或新见解，作为申请授予相应学位供评审用的学术论文。
  2. **学术论文（狭义科技论文）**：对社会科学或自然科学领域中某一问题进行探讨、分析论证的文章。
  3. **科学技术报告**：描述一项科技研究的结果/进展，或技术研制试验和评价的结果；一般呈送主管机构或科学基金组织，应提供系统的充分信息，可含正反两方面结果。
- **学术论文定义（GB 7713—1987）**：某一学术课题在实验性、理论性或观测性上具有新的科学研究成果或创新见解的知识和科学记录，或是某种已知原理应用于实际中取得新进展的科学总结，用于学术会议宣读交流或在刊物上发表等。
- 关键句：学术论文应提供**新的科技信息**，内容应**有所发现、有所发明、有所创造、有所前进**，而不是重复、模仿、抄袭前人的工作。
- 学术论文是学术研究的**结晶**而非一般"学术体会"；是对科学规律的**提示**而非现象直录、材料罗列、事件描述；是对真理的**探求和发展**而非对他人成果的简单重复。

### 四大特点（简答/论述高频）
1. **学术性**：研究内容具有专门性和系统性；运用专业术语和专业性图表符号，主要写给同行看。**内容是辨别学术论文和一般议论文的最重要标准**。
2. **科学性**：内容准确、思维严密、推理合乎逻辑——是学术论文的**生命和价值所在**。体现在三方面：
   - 研究态度的科学性：实事求是、严肃、严谨、严密；
   - 研究方法的科学性：运用辩证唯物主义和历史唯物主义；王力："撰写论文第一也是最重要的一点就是要运用逻辑思维"；**先有结论再找材料是反科学的研究方法**；
   - 内容的科学性：论点正确、概念明确、论据确凿充分、推理严密、语言准确。
3. **创新性**：由科学发展的需要决定。五种表现：填补空白的新发现/新发明/新理论；继承基础上发展完善创新；众说纷纭中提出独立见解；推翻前人定论；对已有资料进行创造性综合。
4. **理论性**：与科普读物、实践报告、科技情报的最大区别。三方面：思维的理论性、结论的理论性、表达的论证性（对结论展开逻辑的精密论证，达到无懈可击）。

### 科技论文的意义（4 条，简答）
1. 科技论文写作是科技工作者进行科学技术研究的**重要手段**；
2. 发表可促进**学术交流**；
3. 写作与发表有利于**科学积累**；
4. 发表是**发现人才**的重要渠道，是**考核业务成绩**的重要依据。

## 1.2 学位论文概述

### 概念与三级要求（重点）
- **学位论文**：高等学校或研究机构的学生为取得学位，在导师指导下完成的科学研究、科学试验成果的书面报告；是答辩委员会决定是否通过并建议授予学位的重要依据。
- 三级要求对比（常考）：
  | 级别 | 要求 |
  |---|---|
  | 学士 | 对课题有一定心得，反映有从事科学研究的**初步能力** |
  | 硕士 | 对课题有**新的见解**，反映有**独立**从事科学研究的能力 |
  | 博士 | 做出**创造性成果**，反映有渊博的理论知识和相当熟练的科学研究能力 |
- 博士学位论文质量最高；学位论文一般**不在刊物上公开发表**。

### 中国学位制度时间线（填空考点）
- **隋炀帝大业三年（607 年）** 正式设进士科——科举取士的开始；武则天时期有殿试；明代殿试前三名 = 状元、榜眼、探花。
- **1935 年 4 月** 颁布"学位授予法"——中国**现代学位制度的开端**（旧中国未认真施行，1949 年前仅 232 人获硕士学位）。
- **1950 年** 新中国即招收研究生；1950—1965 年共招收研究生 22700 多人；1966 年后中断 12 年。
- **1978 年** 恢复招收培养研究生制度；**1979 年** 恢复实行学位制度。
- **1980 年 2 月 12 日** 五届人大常委会第十三次会议通过《中华人民共和国学位条例》，**1981 年 1 月 1 日起施行**；1981 年 5 月 20 日国务院批准暂行实施办法，制定学士、硕士、博士三级学位学术标准——**中国学位制度从此建立**。

### 国外考点
- 埃及埃尔-艾扎学校（**970 年**建校）、摩洛哥艾尔-夸拉维因学校（**859 年**建校）曾授予伊斯兰世界任教证明；**1180 年后**法国巴黎大学授予第一批神学博士学位；**学位论文答辩制度由德语国家首创**。
- 《国际学位论文文摘》由美国大学缩微品公司 1938 年起出版，分 **A（人文与社会科学）、B（科学与工程）、C（欧洲学位论文）** 3 辑；1973 年《学位论文综合索引》报道 1861~1972 年 41.7 万篇博士论文。
- 我国博士论文指定收藏单位：**北京图书馆、中国科技情报所、中国社会科学院文献情报中心**。

### 学位论文特点（3 条）
1. 通过大量思维劳动提出学术性见解或结论，具有**独创性**；
2. **参考文献多、全面**，有助于追踪检索；
3. **一般不公开出版**，电子全文需求呈上升趋势。

### 重要性（3 角度）
宗旨上：体现高等教育教学目标要求；管理上：是高校教学质量的检验方式；实践上：是专业学习的总结与必需的学术训练。

## 1.3 文献检索的意义

### 基础概念（名词解释）
- **信息**：通讯系统传输和处理的对象，泛指人类社会传播的一切内容。1948 年**香农**《通讯的数学理论》："信息是用来消除随机不定性的东西"。
- **信息检索**：用户进行信息查询和获取的主要方式，是查找信息的方法和手段。按存储与检索对象分为：**文献检索、数据检索、事实检索**。
- **文献**：1984 年国家标准《文献著录总则》定义——"**记录有知识的一切载体**"。基本要素：有历史价值和研究价值的知识、一定的载体、一定的方法和手段、一定的意义表达和记录体系。
- **文献四等级**（高频考点）：
  | 等级 | 定义 | 例子 |
  |---|---|---|
  | 零次文献 | 未经正式发表或未形成正规载体（未经任何加工的原始文献） | 书信、手稿、笔记、会议记录、实验记录、原始录音 |
  | 一次文献 | 作者以本人研究成果为基本素材创作的文献 | 大部分期刊论文、科技会议论文 |
  | 二次文献 | 对一次文献加工、提炼、压缩后的工具性文献 | 检索工具书、网上搜索引擎 |
  | 三次文献 | 对一次、二次文献广泛深入分析综合概括而成 | 大百科全书、辞典、电子百科 |
- **广义检索**：包括信息存储和检索两个过程；**狭义检索**：依据一定方法从已组织好的大量文献集合中查找并获取特定相关文献的过程。

### 意义（简答要点）
获取知识的捷径、继承借鉴前人成果的必要方法；读书治学的基本功（张之洞《书目答问·略例》："得门而入，事半功倍"）；终身教育的基础；促进信息资源开发利用；科学研究的向导和组成部分、科学决策的先导；科研成果评估与鉴定需要查新。

## 1.4 学术道德规范的意义

### 概念（名词解释）
- **学术规范**：学术共同体根据学术发展规律参与制定的、有关各方共同遵守的、有利于学术积累和创新的各种准则和要求。
- **科学共同体**：1942 年英国科学哲学家**波兰尼**在《科学的自治》中首次使用该概念；**默顿**（美国科学社会学创始人）认为它是为获得科学真理知识而建立的必要且适宜的团队关系；20 世纪 60 年代**库恩**用"范式"解释科学共同体（狭义/广义）。
- **道德**：社会意识形态之一，反映和调整人们现实生活中的利益关系，用善恶标准评价，依靠内心信念、传统习惯和社会舆论维系的价值观念和行为规范的总和。（"道德"一词可追溯到老子《道德经》）
- **道德 vs 伦理**（《科研道德：倡导负责行为》）：道德是"特定的人群内所采纳的有关行为正确与否的规范原则"；伦理是"超越特定人群而被普遍接受的人格原则"。
- **学术道德**：科学共同体成员的学术行为应当遵守的成文和不成文的基本伦理道德规范的综合体。特征：**普遍性、稳定性、他律性**。
- **学术规范的广义/狭义**（易考）：
  - 广义 = **技术规范**（学术引文规范、学术成果规范、学术评价规范等）+ **道德规范**（法律规范、政策规范、政治思想、科学家精神等）；
  - 狭义学术规范与学术道德含义相同。

### 意义（4 条）
提升社会和高校科学研究水平、服务社会人民；推动高等教育"三个面向"、形成持之以恒的科学探索精神；全面贯彻党的教育方针、提高人才培养质量；彰显学术研究价值，使学术活动制度化、研究标准化专业化，促进学术积累和创新。

# 第 2 讲 科技论文写作

## 2.1 选题
- 选题 = 确定论文的主题。"**题好文一半**"——选题是论文写作关键的第一步。
- 如何选题：①选题**适当**（掌握好广度与深度）；②**联系工作实际**（提倡应用性课题）；③**有新意**。
- **选题四技巧**（简答）：①依据**学术方向**选题（解决特定行业特定问题）；②依据**兴趣爱好**选题；③依据**掌握的文献资料**选题；④**从小从专**选题（从小处入手，忌全而不专、大而空洞）。
- 论文选题与标题的关系：标题是选题的高度概括，但选题及写作**不应受标题限制**。

## 2.2 结构要求及撰写方法
科技论文结构十要素：**题名、作者署名、摘要、关键词、引言、正文、结论(建议)、(致谢)、参考文献、(附录)**。

### 2.2.1 题名
- 概念：论文的总纲，能反映论文最重要特定内容的最恰当、最简明的词语的逻辑组合。
- 一般要求：**准确得体、简短精练（一般不宜超过 20 字）、便于检索、容易认读**（避免非共知共用的缩略词、字符、代号）。
- 常见毛病：题名面大而内容面窄（如"新能源的利用研究"实际只讨论沼气）；标题一般化；有意拔高（把"机理/规律"用于只是"一种解释"的内容）。
- 减少字数方法：删多余词、避免同义近义词连用、不易简化时**加副题名**。
- 文字要求：**结构合理**（尽可能不用动宾结构，用名词性偏正词组；中心动词带状语时可用动宾结构）；选词准确（防歧义）；详略得当（"的"不多用不漏用）；语序正确（注意"的"的位置）。

### 2.2.2 署名
- 三大意义（简答）：①**拥有著作权的声明**（《著作权法》1991 年 6 月 1 日起施行，著作权包括署名权）；②荣誉，表示**文责自负**的承诺（对论文负法律责任、政治上科学上的责任）；③**便于读者同作者联系**。
- 署名对象（只限于）：参与选定研究课题和制定研究方案、**直接参加全部或主要部分研究工作并做出主要贡献**、参加论文撰写并能对内容负责、**对论文具有答辩能力**的人员。**贡献很小的人列入"致谢"**。
- 个人成果个人署名，集体成果集体署名（应署作者姓名，不宜只署课题组名称）。

### 2.2.3 摘要（高频考点）
- 概念：对"论文的内容**不加注释和评论**的简短陈述"。
- 作用：让读者尽快了解论文主要内容，补充题名不足；为情报人员和计算机检索提供方便。
- **分类与篇幅**（必背数字）：
  | 类型 | 特点 | 篇幅 |
  |---|---|---|
  | 报道性摘要 | 报道主要研究成果，提供全部创新内容和尽可能多的定量/定性信息；适用于试验研究和专题研究论文，学术性期刊多用 | **200~300 字** |
  | 指示性摘要 | 只简要介绍论题，概括表述研究目的 | **50~100 字** |
  | 报道—指示性摘要 | 价值最高部分用报道性，其余用指示性 | **100~200 字** |
- 内容：研究的目的、方法、结果和结论，**重点是结果和结论**。
- 写作要求：**用第三人称**；简短精练、明确具体；格式规范（用规范术语、不分段、不出现表格）；语言通顺、标点准确。

### 2.2.4 关键词
- 为满足文献标引或检索需要而从论文中选出的词或词组；包括**主题词**（规范化）和**自由词**（未规范化）。
- 列 **3~8 个**，列于摘要之后。

### 2.2.5 引言
- 主要内容：①研究的理由、目的和背景；②理论依据、实验基础和研究方法；③预期的结果及作用和意义。
- 写作要求：言简意赅、突出重点；**开门见山，不绕圈子**；尊重科学、不落俗套（客套话不说、不吹嘘自己不贬低别人）；需要说明或致歉写在文末，实事求是。

### 2.2.6 正文（核心）
- 立意谋篇——主题四要求：**新颖、深刻、集中、鲜明**。
- **材料三种来源**：直接材料（亲自调查/实验所得）、间接材料（文献或他人提供）、发展材料（对直接、间接材料整理分析研究形成）。
- 选材原则：**必要而充分、真实而准确、典型而新颖**。
- **论证方式**（7 种，常考对应关系）：
  | 方式 | 思维形式 |
  |---|---|
  | 举例 | 归纳推理 |
  | 事理引伸 | 演绎推理 |
  | 反证 | 从反面证明（如数学反证法） |
  | 类比 | 类比推理 |
  | 对比 | 鲜明对照证实一方 |
  | 因果互证 | 归纳推理 |
  | 归谬法 | 先假定正确→导出荒谬结论→证明其错；适用于驳论 |
- **论证严密四规则**：①论题清楚确切、**保持同一**（防"证明过多""证明过少"的偷换论题错误）；②论据应当是真实的判断；③**论据的真实性不应依赖论题的真实性**来论证；④从论据应能推出论题（防"论据与论题不相干""论据不足"）。
- 试验研究报告类正文内容：**理论分析 → 实验材料和方法 → 实验结果及其分析 → 结果的讨论**。
- 注意：异常结果**无法解释也不要轻易舍去**，只有找到确凿证据证明错误后才能剔除。

### 2.2.7 结论和建议
- 结论不是研究结果的**简单重复**，而是更深入一步的认识，将研究结果**升华成新的总观点**。
- 内容要点：①结果说明了什么问题、得出什么规律、解决什么理论或实际问题；②对前人看法作了哪些检验、哪些一致哪些修正/补充/发展/否定；③本研究的不足或遗留问题。
- 写作要求：**概括准确、措辞严谨**（一般不用"大概""也许"）；明确具体、简短精练；**不作自我评价**（不用"国际先进水平""国内首创"等语句）；内容多可分条，用文字表达为主，一般不再用图表。
- "建议"可单独成标题，或作为结论最末一条。

### 2.2.8 致谢
现代科技研究常是合作结果，应对他人劳动充分肯定并感谢；可列标题贯序号，也可不列标题空一行置于结论段之后。

### 2.2.9 参考文献（重点）
- 目的与作用：反映科学态度和真实广泛的科学依据；**把作者成果与前人成果区别开**，表明尊重他人劳动、免除抄袭剽窃嫌疑；索引作用；节省篇幅；便于情报研究和文献计量学研究。
- 著录三原则：**只著录最必要、最新的文献；只著录公开发表的文献；采用标准化的著录格式**。
- GB 7714—87 规定两种著录方法：**顺序编码制**（我国期刊普遍采用：按出现先后用阿拉伯数字连续编码，置于方括号内作上角标）和**著者-出版年制**。
- 著录格式与标识码（必背）：
  - 专著：`序号 著者. 书名[M]. 出版地：出版者，出版年.` 例：`1 薛华成. 管理信息系统[M]. 北京：清华大学出版社，1993.`
  - 期刊论文：`序号 作者. 题名[J]. 刊名，年，卷(期)：页码` 例：`5 姚振兴，郑天愉，曹柏如，等. 用P波波形资料测定中强地震震源过程和方法[J]. 地球物理学进展，1991，6(4)：34-36`
  - 学位论文：`[D]`；专利：`专利申请者. 专利题名. 专利国别，专利号. 出版日期`
- **新版 GB/T 7714—2025《信息与文献 参考文献著录规则》**（课件强调的新考点）：2025 年 12 月 2 日发布，**2026 年 7 月 1 日起实施**，替代 2015 版。主要变化：
  1. 新增文献类型：预印本 **[PP]**、数据集 **[DS]**、地图 **[CM]**（预印本需标注出版平台、创建或修改日期、引用日期及获取路径）；
  2. "数字对象唯一标识符"改为"**永久标识符**"；以 **OL** 为载体的电子文献，获取访问路径（URL）升格为**必备**著录项；
  3. 参考文献"应"用**信息资源本身的语种**著录（原中文文献不再补充英文版式）。
- 文献管理工具 AI 功能：**EndNote 2025**（Research Assistant：Key Takeaway 全文总结、AI Summary & Translation、Cite While You Write、Find a Journal 期刊推荐）；**Zotero GPT Plugin**（对话式总结、翻译、润色、综述、引用）。

### 2.2.10 附录
不是必需的，作用是体现材料完整性。写入内容 5 类：更详尽的理论根据/研究方法/技术要点；篇幅过长或不宜入正文的资料；罕见珍贵资料；对同行很有参考价值而一般读者不必读的资料；重要原始数据、数学推导、计算程序、框图、结构图、统计表等。

## 2.3 表达方式及撰写注意事项

### 标准 vs 规范（易混对比，名词解释）
- **标准**：明文规定的准则；我国国家标准由国家质量技术监督局批准发布，是**国家法规**，具有**权威性、标准性、严肃性**。
- **规范**：标准在某一范围内的具体化，或把约定俗成的技术要求整理出来实施的明文规定；不是国家法规，由部门或团体提出，具有**指导性、规范性、导向性**。

### 规范表达要点
- 层次标题：阿拉伯数字连续编码，不同层次数字间用**下圆点（.）**分隔，末位数字后**不加点号**；各层次第一序码左顶格。
- 量名称/量符号/单位：按国家标准《量和单位》选用；只能使用**法定单位**（土地面积不用"亩"，用平方米或公顷）；采用单位**国际通用符号**（μm、kg、N 等）。
- **数字使用规则**（细节题高发）：
  - 用阿拉伯数字：公元世纪/年代/年月日/时刻（**年份不能简写**，1999 年不能写作 99 年）；计量和计数单位前的数字；纯数字（整数、小数、分数、百分数、比例）；产品型号/样品编号/代号序号；文后参考文献中的数字（古籍除外）。
  - 用汉字数字：定型词、词组、成语、惯用语、缩略语及带修辞色彩的词语中作语素的数字（第一、二倍体、三氧化二铝、星期五、"十五"计划）；相邻数字连用概数（一两千米、四百五六十万元）；带"几"的概数（十几、几百）；非公历纪年；含月日简称表示事件/节日的词组（"一二·九"运动、五四运动）。
  - 数值范围：用**浪纹号（～）**，如 120～130 kg；百分数范围前一个百分号**不能省**（52%～55% 不能写成 52～55%）；"万/亿"表示的范围每个数值的"万/亿"**不能省**（20万～30万）；面积/体积用量值相乘时**每个数值的单位都写出**（60 m×40 m，不能写 60×40 m²）。
- **图表**：能用文字说清就不必用图表；每图每表都要有**图序/表序和图名/表名**；**图名放图下方，表名放表上方**；图表中的文字比正文**小一号**。

### 撰写注意事项（8 条，简答）
①选题要新颖、源于实践，深度广度合适；②论点明确，论据充分准确，论证严密合理；③内容丰富、有专业性和科学性，文字简练；④结构完整、条理清楚、逻辑性强、重点突出；⑤表达规范、格式标准；⑥摘要结论聚焦突出主题，有亮点；⑦**注意学术道德规范，不能抄袭或篡改数据**；⑧多征求导师意见，精益求精。

# 第 3 讲 学位论文写作

## 3.1 选题与开题报告

### 选题
- 选题是学位论文写作的关键一步，是对自己以往学习的完整反思。
- 两条路径：**自主选题**（须征求指导老师意见；可结合自身学习专长、家庭或社会背景、就业方向）或**导师指导选题**（结合导师科研项目、根据社会需求）。
- 具有现实意义的论文题目三个来源：①跟踪学科发展和国内外科技创新研究热点；②家乡和工作实践中遇到的理论和现实问题（特别是与生态、环境相关）；③学习、生活或工作实践中提出来的理论和现实问题。
- **"四句诗"（七字诀）——必背**：
  > "**科研论著寻选题，窄小精深新特奇。信达雅畅齐清定，文章传道解惑迷。**"
  - 前两句讲选题："窄小精深新特奇"= 范围窄、角度小、选材精、论证深、内容新、有特色、立意奇；
  - 第三句讲对学位论文的要求：内容真实（信）、独立完成不作弊不抄袭（达？准确为信、平正通达）、文字优雅（雅）、语言流畅（畅）、主辅文图表齐全完整（齐）、稿件清楚优秀（清）、定稿达出版水准（定）；
  - 第四句讲学位论文的宗旨。
- 选题要适当："**忌大、忌广、忌空、忌泛**"，尽可能"**小题大作**"而不要"大题小作"。爱因斯坦认为学位论文选题要"**不厚不薄**"（论文分量、时间都要适合），要选别人没钻过或没钻好、自己在现有条件和时间内能钻好的地方。
- 选题要结合实践：专业（工程）硕士学位论文选题应**直接来源于生产实际**或具有明确的工程背景和应用价值。六个方向：技术攻关/改造/推广与应用；新工艺、新材料、新产品、新设备的研制与开发；引进消化吸收应用国外先进技术；应用基础性研究预研专题；较完整的工程技术/工程管理项目规划或研究；工程设计与实施。

### 开题报告（名词解释 + 内容）
- 概念：开题者对研究课题的文字说明材料，把自己所构思课题的概况向立项申请单位或指导者及专家学者报告陈述，征求意见、建议并评议，确定是否批准该选题；是研究生正规培养的重要环节，也是审查论文完整性、科学性的依据材料。
- **内容 7 部分**：①题名；②选题意义（工程应用背景和应用价值、社会效益和经济效益）；③国内外研究现状（**文献综述**，"知己知彼，百战不殆"）；④主要研究内容与研究方法（技术路线）；⑤创新点；⑥研究计划；⑦参考文献。

## 3.2 组成结构与写作要求
学位论文组成：**封面、承诺书（独创性声明）、摘要、关键词、目录、绪论（前言）、正文、结论、致谢、参考文献、(附录)**。

- **题名与署名**：封面要有题目、学生（作者）与指导教师署名；题目一般不宜超过 **20 字**。署名既表示所有权，更表示对内容负责，**尤其对学术不端问题承担责任**。
- **摘要**：内容一般包括研究的意义、目的、主要内容、方法、结果和结论。
- **关键词**：摘要之后，**3~8 个**，反映主题内容或出现频率较高。
- **目录**：论文的提纲，是论文撰写开始的标志。提纲分**粗纲**（只提示各部分要点）和**细纲**（对材料详略安排及各部分关系都有反映）两种。
- **绪论**：主要内容 = 选题意义、国内外研究现状、主要研究内容、研究方法（技术路线）、创新点、**主要工作量及研究成果**（主要工作量 = 资料收集、实验、数据分析、图形等；研究成果 = 主要成果及认识）。
- **正文**：核心部分。注重**科学性和专业性**，坚持实事求是，实验数据记录完整可靠、整理规范。
- **结论**：对正文核心内容的总结，语言简练、描述准确、体现主要研究成果。
- **致谢**：感谢导师、家人及同学等帮助完成论文的人。
- **参考文献 / 附录**：附录 = 内容的有效补充（重大学术活动、发表的文章、出版的专著）。

## 3.3 表达方式与注意事项
- **规范化四方面**：格式规范、语言文字规范、标点符号规范、图表规范。
  - 格式：论文封面要素（学校代码、学校名称、论文类别、题目、院系、专业、姓名、指导教师、完成日期）；排版统一 Word 格式 A4 纸；正文宋体小 4 号、行距 20 磅。
  - 图表编号用"图 1-1""表 2-2"形式（章-序）；图名下、表名上；图表文字小一号。
- 撰写注意事项（8 条，与科技论文类似 + 两条特色）：选题新颖源于实践；论点明确论证严密；内容丰富文字简练；结构完整逻辑性强；表达规范格式标准；摘要结论聚焦主题、**目录清晰合理**；**注意学术道德规范，不能抄袭或篡改数据**；**时间安排要合理**，多征求导师意见。

# 第 4 讲 文献检索

## 4.1 检索类型

### 文献检索教育发展四阶段（填空）
1. **1949 年以前——目录学教育阶段**（清乾嘉时期目录学一度成"显学"；1920 年东南大学办过图书馆暑期学校）；
2. **1949—1966 年——起步阶段**；
3. **1976—1983 年——生长时期**（1966—1976 停顿；1981 年《人民日报》刊载刘毅夫、潘树广建议开设文献检索课的文章；1983 年筹办理工、医药、农业 3 个师资培训班，10 月召开专题讨论会）；
4. **1984 年以后——新的发展时期**（1984 年教育部下达《关于在高等学校开设文献检索与利用课的意见》；1985 年提出"**逐步实现分层次连续教育**"；1992 年 5 月原国家教委印发《文献检索课教学基本要求》；1996 年成立全国文献检索课教学指导小组；90 年代中期 700 多所高校开课、600 多种教材；1992 年 11 月《国家标准学科分类代码》将文献检索学列为独立三级学科；1988 年教育部规定 218 种专业须掌握文献检索基本方法）。

### 检索类型三维度（易混）
| 划分标准 | 类型 |
|---|---|
| 按手段 | 人工检索 / 非人工检索 |
| 按载体形式 | 印刷型（纸张，便读便流传但存贮密度低、体积笨重）/ 机读型（磁性材料：文档、数据库、光盘；密度高、速度快、可更新但需设备、费用高）/ 声像型（录像带、唱片、录音带等；直观真切、形象生动） |
| 按检出结果 | **书目检索**（得到题名、作者、摘要、出处等线索信息）/ **全文检索**（直接得到全文或句子、章节、段落）/ **引文检索**（检出文献被引用情况，用于分析评价文献质量） |

## 4.2 步骤、方法和途径

### 步骤（4 步，简答）
①明确查找目的与要求 → ②选择检索工具 → ③确定检索途径和方法 → ④根据文献线索，查阅原始文献。

### 方法（3 类，高频）
- **直接法（常用法）**：直接利用检索系统检索。三分法：
  - **顺查法**：按时间由远及近，能收集某课题系统文献，适用于较大课题、已知起始年代要了解发展全过程；
  - **倒查法**：由近及远、从新到旧，**最快获得最新资料**；
  - **抽查法**：选文献最可能出现的时间段重点检索。
- **间接法（追溯法）**：不利用一般检索系统，利用文献后面所列参考文献逐一追查原文，一环扣一环扩大范围，"**像滚雪球一样**"依据引用关系获得更好结果。
- **循环法（分段法/综合法）**：分期分批交替使用直接法和追溯法，取长补短。

### 途径（8 种，简答）
著者途径、题名途径、分类途径（体现学科系统性，"触类旁通"）、主题途径（通过主题词，便于对某一问题作全面系统的专题研究）、引文途径（利用参考文献编制的引文索引，从被引论文检索引用论文）、序号途径（专利号、报告号、标准号、ISBN、刊号——明确、简短、唯一）、代码途径（如分子式索引）、专门项目途径（名词术语、地名、人名、机构名、商品名、生物属名、年代等）。

## 4.3 检索语言和工具

### 检索语言
- 概念：一种**人工语言**，用于检索工具的编制和使用，为检索系统提供统一基准的符号化或语词化专用语言（存储时叫标引语言，索引时叫索引语言，检索时叫检索语言）。
- 按原理分（3 类）：
  - **分类语言**：按学科性质分类排列，用**分类号**表示概念及位置。《中国图书馆图书分类法》按"**五分法**"分为马列毛泽东思想、哲学、社会科学、自然科学、综合性图书**五大部类，22 个大类**；
  - **主题语言**：经过控制的、表达文献信息内容的语词；主题词需规范，**主题词表**是主题语言的体现；
  - **自然语言**：文献中出现的任意词。
- 按语种分：中文、英文、法文、日文、德文、韩文等。

### 检索工具
- 印刷型：图书、期刊、报纸、纸质记录。重点概念：
  - **百科全书——"参考工具书之王"**：概述人类一切门类或某一门类知识的完备工具书，知识的总汇，按条目（词条）字顺编排；
  - **年鉴**：按年度系统汇集重大事件、新进展、新知识、新资料，内容一般以当年为限；
  - **词典**：最常用的工具书，分语言性词典和知识性词典；另有手册、名录、图谱等。
- 机器型：计算机（数据库 + 网络搜索）、手机等。**四大检索工具**（填空高频）：
  | 数据库 | 要点 |
  |---|---|
  | **SCI** | 国际性索引，自然科学、生物、医学、农业、技术和行为科学等，**侧重基础科学**；收录 94 类、40 多个国家、50 多种文字 |
  | **EI** | 创刊于 **1884 年**，美国工程信息公司出版，工程技术类综合性检索工具 |
  | **ISTP** | 创刊于 **1978 年**，美国科学情报研究所编辑出版，收录**会议文献**；工程技术与应用科学类约占 35% |
  | **中国知网** | "国家知识基础设施"概念由**世界银行 1998 年**提出；清华大学、清华同方发起，**始建于 1999 年 6 月** |
  - 另有维普网、万方等。
- 其他工具：竹木类、布皮类、砖瓦类等（古代文献载体）。

# 第 5 讲 学术道德规范

## 5.1 学术道德规范主要内容及相关制度

### 主要内容（5 条，简答）
1. **树立和践行社会主义核心价值观**：坚持为人民服务、为社会主义服务；尊重个人合法权益与承担社会责任相统一；把学术探索融入中华民族伟大复兴的事业。
2. **弘扬科学精神**：勇于捍卫真理、尊重科学规律，"**不唯上，不唯书，只唯实**"；发扬淡泊名利、拼搏进取、自觉奉献、严谨求实的学风；营造团结协作、自由探索、宽容失败、学术民主的环境。
3. **恪守职业道德，维护学术信誉**：反对和抵制投机取巧、弄虚作假、抄袭剽窃等学术不端行为；把社会效益放在首位，尊重他人劳动成果。
4. **自尊自律，塑造人格风范**：自觉模范遵守宪法和法律、国家政策和党的纪律。
5. **其他要求**：遵守学术团体自律准则、宣言、倡议和约定俗成的学术惯例。

### 具体规范（论述素材，重点背）
- **引用规范**：必须尊重知识产权；引用他人成果时**如实注明出处**；**所引用部分不能构成引用人作品的主要部分或实质部分**；从他人作品**转引**第三人成果时，如实注明**转引**出处。
- **署名规范**：合作研究成果发表前须经**所有署名人审阅并签署确认书**；所有署名人对研究成果负责，**合作研究主持人对成果整体负责**；按**贡献大小顺序**署名；仅做过一般性管理或辅助工作者**不享有著作权**。
- **评价规范**：介绍、评价作品遵循**客观、公正、准确**原则，在充分掌握国内外材料、数据基础上全面分析评价。
- **研究伦理**：尊重研究对象；涉及人体的研究必须**保护受试人合法权益和个人隐私，保障知情同意权**；动物实验遵守动物实验伦理。
- **数据规范**：课题申报、项目设计、数据采集分析、公布成果、确认参与人员贡献等环节遵守**诚实客观原则**；保证实验记录和数据的**完整、真实和安全，以备考查**；对已发表成果中的错误失误应**适当方式公开承认**。
- 诚实严谨地与他人合作，耐心诚恳对待学术批评和质疑；**不得利用科研活动谋取不正当利益**。

### 特征（4 个，简答）
**科学性、共识性、多样性、综合性**（多样性：有原则要求也有具体细则，有明文的也有约定俗成的，有强制性也有推荐性；综合性：既调节约束行为——法律、政策、技术标准，又影响思想——精神力量、道德习惯）。

### 基本准则（3 个，必背）
1. **诚实守信**：四个"负责"——对学术研究的真实准确性负责；对文献引证的真实准确性负责；对署名学术成果的真实准确性负责；要信守约定和承诺。（朱熹在《白鹿洞教条》倡导"言忠信""行笃敬"）
2. **公平公正**：权责对等、机会均等、规则公正，一视同仁；维护学术评价的公平公正（评价导向、评价标准、评价程序、评价结果四方面公平公正）。
3. **公开透明**：在保守秘密及个人隐私前提下，将学术活动的内容、结果、程序、规则公之于众；正确处理公开透明与保守秘密的关系。

## 5.2 学术不端行为及其原因

### 定义（名词解释）
- **美国 1989 年定义**（国际上较广泛认同）："在计划、完成或报告科研项目时**捏造、篡改、剽窃**（FFP）或其他严重背离科学界常规的做法。**不包含诚实的错误或者在资料解释或判断上的诚实分歧**。"
- 中国定义含义更广。中国科协 2007 年定义："在科学研究和学术活动中的各种**造假、抄袭、剽窃**和其他违背科学共同体惯例的行为。"

### 主要表现形式（7 种 + 其他，必背）
| 行为 | 要点 |
|---|---|
| **捏造** | 凭主观臆测假造事实：编造杜撰数据或结果；虚假陈述（项目申请、求职提职、学位申请中虚报文章数引文数）；提供虚假证书证明；伪造专家签名 |
| **篡改** | 用作伪手段改动或曲解观点、数据：故意取舍实验数据、改动图片图像使之带误导性欺骗性 |
| **剽窃抄袭** | 窃取别人作品：雇"枪手"；引用未公开成果不作注释；虽标注但引用部分构成自己作品的**主要内容或实质内容**；故意漏引错引 |
| **违反科研伦理** | 医学试验违反知情同意与知情选择，侵犯受试者人格隐私；虐待实验动物 |
| **一稿多投** | 违反再次投送期限，将**同一作品、同一种语言**向两个以上期刊社投稿 |
| **重复发表** | 将**本质上相同的作品改头换面**或分解为多篇再次登载 |
| **不当署名** | 署名与学术贡献不符：将未做实质性贡献者署名；领导、资金提供者挂名 |
| 其他 | 虚报冒领科研经费；故意损坏强占扣压仪器设备数据；拖延审查评价；骗取科研奖励荣誉等 |

### 案例（可能考"举一个学术不端案例"）
1. **不当署名**：上海松江中心医院李岩松——投稿前未获所有作者知情同意 → 撤稿、通报、取消课题申报资格 1 年等。
2. **数据造假 + 不规范署名**：辽宁省肿瘤医院李康（通讯）、武晓彬（第一）→ 撤稿，分别取消申报资格 2/3 年。
3. **抄袭重复发表**：南京大学梁莹——抄袭、重复发表多篇论文，职称申报弄虚作假 → 党内严重警告、行政记过、取消导师资格、调离教学科研岗位、撤销教师资格。
4. 8 人通报批评（天津大学戴路等）：申请书抄袭剽窃、造假、冒名申报、论文抄袭等。
5. **买卖实验数据**：湖南某高校马泓——论文涉及买卖实验数据并写入基金申请书 → 取消 3 年国自然申请资格。
6. **抄袭申请书**：黑龙江某高校孙琪 → 取消当年申请、禁 3 年申报、通报批评。
7. **"本科生狂发 50 篇 SCI"**（2025 年底，温州医科大学）：一年多参与发表约 50 篇（44 篇 SCI），被质疑"灌水"。
8. **"AI 代写论文"**（2025，香港大学一博士生）：论文部分引文系 AI 工具虚构生成 → 撤稿，通讯作者卸任副院长。
- 撤稿数据（论述可用）：2025 年国自然两批通报 36 案（19 个与论文相关，34 名学者被通报）；**2021 年以来涉及中国学者的撤稿已超 17000 篇**；2021—2024 出版机构 **Hindawi 批量撤稿超 8000 篇，中国作者占比超 80%**；2025 年 Nature 首次统计撤稿机构，全球前 10 中 **7 家来自中国的医院或医学院**；撤稿原因前三：图片异常、数据异常、利益冲突或身份存疑。

### 原因（4 条，论述必背）
1. **价值观扭曲**——根本原因（内在因素：目的、动机、观念、意识、价值观；欲望是引发行为的动机和根源；外在：名利诱惑）；
2. **学术规范系统教育不到位**——重要原因（缺乏学术道德系统教育，知识产权保护意识不强）；
3. **学术评价机制不完善**——关联因素（成果评价与职务晋升、经费分配、论文数量直接挂钩）；
4. **行为风险成本低、利益收益大**——直接诱因（处罚较轻；取证甄别难、维权成本高）。

## 5.3 学术道德规范建设途径（6 条，简答必背）
1. **营造良好的社会信用环境**：2008 年《科学技术进步法》明确建立**学术诚信档案**，把学术不端行为与学术信用记录挂钩；
2. **建立完善监管体制机制和办法**：学风建设工作机构、联动监管工作机制、完善科技计划管理办法；
3. **注重学术规范教育引导**：开展科学道德和学风建设宣讲教育（"全覆盖、制度化、重实效"）；
4. **加强学术行为自律性**：制定完善学术道德规约（中科院院士科学道德自律准则等）；
5. **搭建知识信息资源共享平台**：科研基础设施与大型仪器、自然科技资源、科学数据、科技文献、知识产权信息服务平台；
6. **严厉查处学术不端**：科技部、教育部、中国科协、国自然基金委等发布系列文件，使其**有法可依、有章可循**。

# 附：考前速记

## A. 名词解释速查（10 个最高频）
1. **科技论文**：报道科学研究和技术开发创新性工作成果的论说文章。
2. **学位论文**：学生为取得学位，在导师指导下完成的科研、科学试验成果的书面报告，供学位评审用。
3. **摘要**：对论文内容不加注释和评论的简短陈述。
4. **关键词**：为满足文献标引或检索需要，从论文中选取的词或词组（含主题词和自由词）。
5. **文献**：记录有知识的一切载体（GB《文献著录总则》1984）。
6. **文献检索**：以文献为对象的收集、整理、排序和按要求查找与识别的过程。
7. **学术规范**：学术共同体根据学术发展规律参与制定的，各方共同遵守的、有利于学术积累和创新的准则和要求。
8. **学术道德**：科学共同体成员的学术行为应当遵守的成文和不成文的基本伦理道德规范的综合体（普遍性、稳定性、他律性）。
9. **学术不端（美国 1989 定义）**：计划、完成或报告科研项目时的捏造、篡改、剽窃及其他严重背离科学界常规的做法（不含诚实错误和诚实分歧）。
10. **开题报告**：开题者对研究课题的文字说明材料，向立项单位/导师及专家陈述课题概况，征求意见并评议是否批准选题。

## D. 易混对比
| 对比 | 区别要点 |
|---|---|
| 学术论文 vs 一般议论文 | 内容的专业性、系统性（内容是辨别最重要标准） |
| 标准 vs 规范 | 标准 = 国家法规（权威性、标准性、严肃性）；规范 = 部门团体规定建议（指导性、规范性、导向性） |
| 道德 vs 伦理 | 道德 = 特定人群内的行为规范原则；伦理 = 超越特定人群被普遍接受的人格原则 |
| 一次 vs 二次 vs 三次文献 | 一次 = 原创成果；二次 = 加工成的检索工具；三次 = 分析综合的参考工具（百科、辞典） |
| 书目 vs 全文 vs 引文检索 | 结果分别是：线索信息 / 全文内容 / 被引用情况 |
| 顺查 vs 倒查 | 顺查 = 由远及近（系统全面）；倒查 = 由近及远（最快获得最新资料） |
| 直接法 vs 间接法 | 直接 = 用检索系统；间接（追溯）= 顺参考文献滚雪球 |
| 主题词 vs 自由词 | 主题词规范化，自由词未规范化 |
| 图名 vs 表名 | 图名在下，表名在上；图表文字比正文小一号 |
| 捏造 vs 篡改 | 捏造 = 无中生有编造；篡改 = 改动曲解已有数据观点 |
| 一稿多投 vs 重复发表 | 一稿多投 = 同一作品投多家；重复发表 = 改头换面或拆分再发表 |
| 学术规范（广义）vs（狭义） | 广义 = 技术规范 + 道德规范；狭义 ≈ 学术道德 |
