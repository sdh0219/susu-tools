《创新与创业》第1课 创新与创业导论 · 笔记

依据第 1 课课件整理：课程考核、报告与小论文要求（⭐ 作业相关）、核心概念（创新 / 创业 / 蒂蒙斯模型）、死亡之谷与经典案例。 整理日期：2026-11-15

一、课程考核与结构 ⭐

  • 期末成绩构成：课堂成绩 30% + 个人学习成果 50% + 团队学习成绩 20%——个人学习成果占一半，主观题作业务必认真完成
  • 课程内容 7 大模块：① 创新与创业导论 → ② 创新思维与创新方法 → ③ 创新管理 → ④ 创新创业与公司创立 → ⑤ 创新创业风险与伦理 → ⑥ 安全应急创新创业 ⭐（与本方向直接相关）→ ⑦ 创新创业与团队
  • 学习目标关键词：TRIZ、Design Thinking（设计思维）、创业计划书撰写、中国国际创新大赛、科技创业流程、创新创业风险应对
  • 课堂主观题（各 10 分）："关于创新创业，我最想了解的问题"；"创新创业与自己人生发展的关系，为什么？请列举 3 条理由"

二、小组报告与小论文要求 ⭐（详见《小组报告与小论文指南》）

报告规则补充

  • 下课后根据课堂讨论修改完善，24 小时内交给学委（容易漏的一条！）
  • 其余：从第 2 次课开始 / 每次课 3 组 / 每组 1 名代表 PPT 汇报 / 报告 5 分钟 + 研讨 5 分钟 / 课前 10 分钟拷贝 PPT

小论文硬性要求

  • 正文不少于 5000 字，word 文档按《华北科技学院学报》格式
  • 以 "学号_姓名" 命名，最后 1 次课前交电子版与打印版
  • 学术规范：复制比不得超过 15%

小论文要避免的三种"跑偏" ⭐

  1. 写成技术研发项目报告（例：全角度瓦斯断电稳定性动态监测装置与方法）——那是毕业设计不是论文
  2. 写成科学现象的科学/工程理论研究（例：通风除尘过程高浓度粉尘沉积特性）
  3. 写成具体设备与市场调研报告（例：***镀膜技术趋势与市场前瞻性调研）

小论文"创业"方向候选题

  • 我能用导师的技术创业吗？——研究生与导师合作创业的模式研究
  • 那位成果很丰富的老师为什么不创业？——教师群体创业的动机机制与环境影响分析
  • 很喜欢硕士论文的题目，关于前提能不能先做 BP 分析一下？——××项目商业计划书（有条件使用）

三、核心概念：创新

  • 定义：全新的变化；实验变革；在既有秩序中引入新事物。"创"表明"新"的实现需要开拓性过程；"新"指结构、功能、原理、方法等方面第一次的、显著的变化
  • 熊彼特五种形式：引入新产品（产品创新）、新生产工艺（工艺创新）、开辟新市场（市场创新）、获得新供应来源（材料创新）、新的组织形式（组织创新）
  • 广义 vs 狭义：广义 = 制度/文化/知识创新；狭义 = 技术创新（产品/服务/工艺）+ 非技术创新（市场/材料/组织/管理）
  • 创新的内涵：创新 = 设想（理论概念）+ 发明（技术可行性论证）+ 商业开发（企业通过产品从市场获得收益）——三阶段层层递进、缺一不可
  • 创新过程：
  • 程序论四阶段：准备 → 酝酿 → 豁朗 → 验证
  • 顿悟论：问题解决具有突发性
  • 七步论（甘华鸣）：提出问题 → 寻找资料 → 弄清问题 → 生成思路 → 选择思路 → 执行计划 → 回顾总结
  • 顿悟的三种说法：长期积累偶然得之（相对论、2/3/4G）；进入状态悠然得之（镭、电灯）；留心意外歪打正着（牛顿第二定律）

四、创新研究与"死亡之谷" ⭐

  • 创新链条：基础研究 → 应用研究 → 技术开发 → 商业应用（基础研究周期长且不确定由研究者主导；应用研究解决商业管理问题、有时限约束）
  • 死亡之谷（The Valley of Death）：从"可行性研究"到"市场测试"之间，政府资助与 VC 投入双低谷——大量创新死在这一段
  • 案例：日产 VC-Turbo 可变压缩比发动机（1998 立项 → 2019 量产，二十余年）；5G 容量提升 ×225、单载波容量 ×22000（"Polar Code 之父" Erdal Arıkan 2008 年提出信道极化）
  • 拜杜法案（Bayh-Dole Act）：美国科研成果转化率 5%→80% 的转折。四条根本性准则：①政府资助成果的权利默认归大学 ②大学享有独占性许可 ③发明人分享许可收入 ④收入全部用于科研——"挤出来的生产力"
  • 中国科技战略五个里程碑：向科学进军（1956）→ 科学的春天（1978）→ 科教兴国（1995）→ 建设创新型国家（2006）→ 加快建设科技强国（2012，二十大："创新是第一动力……强化企业科技创新主体地位"）

五、核心概念：创业

  • Timmons 定义：不拘泥于当前资源约束、寻找机会、通过创办企业进行价值创造的行为过程。广义 = 开创事业；狭义 = 创办企业
  • 蒂蒙斯模型：机会 + 资源 + 团队 三角平衡，靠"沟通"匹配商业计划与差距；受外生因素、领导能力、资源再生能力影响
  • 创业五特点：把握机会、超前行动、创造性整合资源、创新与变革、创造价值
  • 创新与创业的关系：科学发现 ∩ 发明创造 ∩ 开办企业；创新不一定创业，创业必有创新；创业是市场经济的源动力
  • 创业精神：特质论 → 认知论，可以培养（Sarasvathy 效果逻辑：调查 52 家营收 <2.65 亿美元的企业；Kaufmann《解剖创业家》：52% 的企业家其实受"家族里创业的第一人"影响）

六、案例：大疆创新 ⭐（源于本科毕业设计的世界级企业）

  • 李泽湘：1992 年在香港科技大学创办自动化技术研究中心；1999 年创办固高科技（运动控制）；"学生创业军团"：逸动科技（电动船外机）等——FROM LAB TO STARTUP
  • 汪滔时间轴：2006 读研期间创立 → 2012 世界首款航拍一体机"大疆精灵 1" → 2013 营收 1.3 亿美元、员工 200+ → 2017 营收 175.7 亿元（+123.2%）→ 2022 营收 301.4 亿美元、70% 全球 → 2023 年出货 20 万台
  • 汪滔语录："工作以后发现，不靠谱的人和事太多了，这个社会原来是这么愚蠢……""比任何一家互联网公司都强十倍，也比苹果强"——他只服谁？（课件留的开放问题）
  • ⭐ 与报告选题呼应：如果小组选"创新与创业的关系"类题目，大疆是"源于毕业设计的世界级企业"最佳案例；与"学生创业军团"概念也可组合

七、Part 4 创新创业与人生发展（课堂互动）

  • 投票：硕士毕业后首选就业去向（A 公务员 / B 事业单位教师 / C 央企、外企 / D 民营企业 / E 创业 / F 其他）
  • 投票：创新创业跟自己人生发展的关系（极大 / 有较大关系 / 一般 / 没多大关系 / 完全没有可能）
  • 主观题：上述选择 + 列举 3 条理由（10 分）——记得完成
  • 寓言故事《管道的故事》读后思考
  • Case：企业家（创业者）的选择与生活——"别让 CEO 一个人散步""无限的创意与意志的胜利（上/下）"
  • Badow 名言：强大的高等教育才格外重要，因为要让学生具备批判性思考、创新和领导的能力，"而不是把自己锻造成真理和智慧的源泉"

八、学习资料片单

  • 国内纪录片：创新之路、大国崛起、公司的力量、华尔街、互联网时代、货币、激荡 1978-2008、创业时代、与全世界做生意
  • 国际纪录片：大而不倒（Too Big to Fail）、监守自盗（Inside Job）、服装过量：下一场金融危机（Overdose: The Next Financial Crisis）、孟山都公司眼中的世界（A World According to Monsanto）、安然事件：房间里最聪明的人们（Enron, The Smartest Guys In The Room）
