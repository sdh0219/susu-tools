用法(每天固定三步,约 60-90 分钟)

  1. 背诵自查(10-15 分钟):闭卷口答/默写 A 组自查题 → 对答案 → 错的标记;
  2. 论述提纲(30-40 分钟):闭卷裸写 B 组论述题提纲(只列条目名)→ 对照得分点框架,数覆盖率;
  3. 补背(15 分钟):只背"没写出来的那几条",明天自查题里重测。
  4. 第二天开始前,把前一天标错的题先重测一遍再学新内容(滚动复习)。

进度安排:D1 专题一 → D2 专题二三 → D3 专题四五 → D4 专题六七 → D5 专题八+全书串题 → D6 抽 4 道论述全真手写模拟 → D7 重测全部错题。

专题一 中国式现代化道路(导论+第一、二章)

A. 背诵自查题(闭卷口答)

  1. 习思想科学体系的四大板块及各自定位?

    十个明确(主体内容、"四梁八柱")/ 十四个坚持(基本方略)/ 十三个方面成就 / 六个必须坚持(世界观方法论)——内在贯通、有机统一

  2. "六个必须坚持"是哪六个?

    人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下

  3. "三个意味着"分别意味着什么?

    ①中华民族迎来了从站起来、富起来到强起来的伟大飞跃;②科学社会主义在21世纪的中国焕发出强大生机活力;③拓展了发展中国家走向现代化的途径,为解决人类问题贡献了中国智慧和中国方案

  4. 我国社会主要矛盾是什么?哪"两个没有变"?

    人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾;初级阶段基本国情没有变、世界最大发展中国家地位没有变

  5. 中国式现代化的五个中国特色?(含各自的定位词)

    ①人口规模巨大(显著特征)②全体人民共同富裕(本质特征)③物质文明和精神文明相协调 ④人与自然和谐共生(鲜明特点)⑤走和平发展道路(突出特征)

  6. 默写九条本质要求。

    坚持中国共产党领导、坚持中国特色社会主义、实现高质量发展、发展全过程人民民主、丰富人民精神世界、实现全体人民共同富裕、促进人与自然和谐共生、推动构建人类命运共同体、创造人类文明新形态

  7. 五个重大原则?

    ①坚持和加强党的全面领导 ②坚持中国特色社会主义道路 ③坚持以人民为中心的发展思想 ④坚持深化改革开放 ⑤坚持发扬斗争精神

  8. 六个重大关系?

    顶层设计与实践探索、战略与策略、守正与创新、效率与公平、活力与秩序、自立自强与对外开放

  9. 全面建成社会主义现代化强国"两步走"?

    2020→2035 基本实现社会主义现代化;2035→本世纪中叶建成社会主义现代化强国

  10. "两个大局"催生的三大时代课题?

    ①坚持和发展什么样的中国特色社会主义、怎样坚持和发展;
    ②建设什么样的社会主义现代化强国、怎样建设;
    ③建设什么样的长期执政的马克思主义政党、怎样建设

B. 论述题(闭卷写提纲→对框架)

1. 试论述中国式现代化的中国特色与本质要求,并说明为什么中国式现代化走得通、行得稳。

⚠️参考框架:总起(党的中心任务+"以中国式现代化全面推进民族复兴")→ 五个中国特色逐条(带定位词)→ 九条本质要求 → 为什么走得通:党的领导保证方向+立足国情(打破"现代化=西方化"迷思)+创造人类文明新形态(超越西方以资本为中心、两极分化、对外扩张)→ 金句收尾("绝不是轻轻松松、敲锣打鼓就能实现的")

2. 论述推进中国式现代化必须把握的重大原则、正确处理的重大关系。

⚠️参考框架:总起 → 五个重大原则逐条(第一条"管总、管根本";第二条引"是社会主义现代化,而不是别的什么现代化")→ 六个重大关系 → "既把蛋糕做大做好,又把蛋糕切好分好"收尾

3. 结合"三个意味着"和新时代内涵,论述中国特色社会主义进入新时代的依据与意义。

⚠️参考框架:新时代五个"是" → 进入新时代的三重依据(主要矛盾新变化/历史性成就与变革/历史方位新坐标)→ 三个意味着 → 主要矛盾"变"与"两个没有变" → 升华

专题二 经济建设(第三章)

A. 背诵自查题

  1. 三项基本经济制度?

    公有制为主体多种所有制共同发展 / 按劳分配为主体多种分配方式并存 / 社会主义市场经济体制(坚持"两个毫不动摇")

  2. 新发展理念五条及各自定位?

    创新(第一动力)、协调(内在要求)、绿色(必要条件)、开放(必由之路)、共享(本质要求)

  3. 新发展格局的定义?

    以国内大循环为主体、国内国际双循环相互促进

  4. 为什么说实体经济是着力点?(三个定位)

    立身之本、财富创造的根本源泉、国家强盛的重要支柱;制造业"立国之本、兴国之器、强国之基"

  5. 教育、科技、人才的定位关系?

    教育是根本(国之大计党之大计)、科技是关键(新型举国体制)、人才是基础(党管人才)——基础性、战略性支撑

  6. 新质生产力的定义?

    创新起主导作用,高科技、高效能、高质量,以全要素生产率大幅提升为核心标志;特点是创新,关键在质优,本质是先进生产力

B. 论述题

1. 论述如何构建新发展格局,牢牢掌握发展主导权。

⚠️参考框架:定义 → 为什么(大国经济内需主导/超大规模市场优势/应对外部冲击;"先手棋,不是被迫之举和权宜之计")→ 怎么建(扩大内需战略基点+经济循环畅通无阻+供给侧改革与扩大需求协同)→ 支撑:实体经济+新质生产力 → 收尾扣"高质量发展"

2. 如何理解高质量发展是全面建设社会主义现代化国家的首要任务?如何把发展经济的着力点放在实体经济上?

⚠️参考框架:高质量发展的定义(体现新发展理念、从"有没有"到"好不好")→ 依据(主要矛盾变化)→ 实体经济三定位 → 路径(制造强国/数字经济/两个毫不动摇)→ 教育、科技、人才三位一体支撑 → 金句收尾

3.(备选)论述教育、科技、人才一体化推进的重大战略意义。

⚠️参考框架:二十大首次三位一体部署 → 三者定位(根本/关键/基础)→ 服务高水平科技自立自强、破解"卡脖子" → 支撑中国式现代化 → "第一生产力/第一资源/第一动力"

专题三 政治建设(第四章)

A. 背诵自查题

  1. 党的领导、人民当家作主、依法治国三者的定位?

    党的领导=根本保证;人民当家作主=本质特征;依法治国=基本方式——有机统一,最根本的是坚持党的领导

  2. 全过程人民民主贯通哪五个环节?

    民主选举、民主协商、民主决策、民主管理、民主监督

  3. 我国根本政治制度与三项基本政治制度?

    根本:人民代表大会制度;基本:多党合作和政治协商、民族区域自治、基层群众自治

  4. 全面依法治国十六字方针及各自定位?

    科学立法(前提)、严格执法(关键)、公正司法(最后一道防线)、全民守法(社会基础)

  5. 说出至少 4 种协商渠道。

    政党协商、人大协商、政府协商、政协协商、人民团体协商、基层协商、社会组织协商

B. 论述题

1. 论述党的领导、人民当家作主、依法治国的有机统一。

⚠️参考框架:三者定位逐条 → 内在统一逻辑(统一于社会主义民主政治实践,割裂对立都不符合)→ 制度载体(人大制度+基本政治制度)→ "最本质特征"金句 → 反对照西方模式

2. 为什么说全过程人民民主是最广泛、最真实、最管用的民主?

⚠️参考框架:内涵(本质属性+全链条全方位全覆盖+五个环节+四个统一)→ 三重论证(经济基础上人民真正当家作主/完整制度程序+参与实践/解决实际问题)→ 对照西方"金钱民主""选举时漫天许诺、选举后无人过问" → "民主不是装饰品"收尾

专题四 文化建设(第五章)

A. 背诵自查题

  1. "两个结合"是什么?关于"第二个结合"的关键论断?

    同中国具体实际相结合、同中华优秀传统文化相结合;第二个结合是"又一次的思想解放";"中国特色的关键就在于'两个结合'";魂脉与根脉

  2. 中华文明五个突出特性?

    连续性、创新性、统一性、包容性、和平性

  3. 文化自信的定位与三大来源?

    更基础、更广泛、更深厚,更基本、更深沉、更持久的力量;来源=中华优秀传统文化+革命文化和社会主义先进文化+中国特色社会主义伟大实践

  4. 默写社会主义核心价值观 24 字(三层面)。

    国家:富强、民主、文明、和谐;社会:自由、平等、公正、法治;个人:爱国、敬业、诚信、友善

  5. 培育践行核心价值观的三条路径?

    教育引导(重要基础)、实践养成(重要途径,落细落小落实)、制度保障(重要保障,融入法治建设)

  6. 新的文化使命是什么?

    继续推动文化繁荣、建设文化强国、建设中华民族现代文明

B. 论述题

1. 论述为什么要坚持、以及如何坚持马克思主义在意识形态领域的指导地位。

⚠️参考框架:为什么(极端重要的工作,关乎旗帜道路国家安全/是根本制度/马克思主义是科学的、人民的、实践的理论)→ 怎么办(凝心铸魂第一位/落实意识形态工作责任制、党管宣传媒体互联网/把最大变量变最大增量)→ 收尾扣文化强国

2. 结合"第二个结合",论述如何坚定文化自信、建设中华民族现代文明。

⚠️参考框架:两个结合内容 → "不是拼盘,而是深刻的化学反应"+又一次思想解放 → 五个突出特性 → 文化自信三来源 → 培育践行核心价值观 → 新文化使命收尾("人民有信仰,国家有力量,民族有希望")

专题五 社会与生态文明建设(第六、七章)

A. 背诵自查题

  1. 民生"七有"?

    幼有所育、学有所教、劳有所得、病有所医、老有所养、住有所居、弱有所扶

  2. 共同富裕的内涵要点(三个"是/不是")?

    物质生活和精神生活都富裕;是全体人民的富裕,不是少数人的富裕,也不是整齐划一的平均主义;"是社会主义的本质要求,是中国式现代化的重要特征"

  3. 三次分配各自靠什么?

    初次分配(按劳分配为主体)/再分配(税收、社保、转移支付)/第三次分配(慈善公益)

  4. "两山"理念的三阶段认识?

    用绿水青山换金山银山 → 既要金山银山也要保住绿水青山 → 绿水青山就是金山银山

  5. 双碳目标及关键论断?

    2030 年前碳达峰、2060 年前碳中和;"不是别人让我们做,而是中国的主动选择";"一场广泛而深刻的经济社会系统性变革";先立后破

  6. 社会治理格局与"枫桥经验"要点?

    共建共治共享(共建是基础、共治是关键、共享是目标);"小事不出村、大事不出镇、矛盾不上交"

B. 论述题

1. 论述如何在发展中保障和改善民生、扎实推进共同富裕。

⚠️参考框架:增进民生福祉是发展的根本目的 → 民生工作思路(坚守底线、突出重点、完善制度、引导预期)+"七有"重点领域 → 共同富裕内涵(三个"是/不是")→ 路径(高质量发展做大蛋糕+三次分配+城乡区域统筹)→ "尽力而为、量力而行,等不得也急不得"收尾

2. 论述"绿水青山就是金山银山"的科学内涵与美丽中国建设路径。

⚠️参考框架:两山辩证关系(保护生态环境就是保护生产力)→ 生态文明"十个坚持"挑 5 条展开 → 四条路径(绿色转型/深入治污/生态系统/双碳)→ 双碳"主动选择+系统性变革" → 共谋全球生态文明建设收尾

专题六 重要保障(第八章)

A. 背诵自查题

  1. 总体国家安全观五大要素?

    以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托

  2. "五个统筹"?

    外部与内部、国土与国民、传统与非传统、自身与共同、维护与塑造

  3. 统筹发展和安全的关键表述?

    "一体之两翼、驱动之双轮";安全是发展的前提,发展是安全的保障;以新安全格局保障新发展格局

  4. 底线思维要防什么?

    "黑天鹅""灰犀牛";重点防控可能迟滞或中断民族复兴进程的全局性风险

B. 论述题

1. 论述总体国家安全观的丰富内涵,以及为什么要统筹发展和安全。

⚠️参考框架:为什么(国家安全是民族复兴的根基/头等大事)→ 五大要素+五个统筹(大安全理念)→ 统筹发展和安全(两翼双轮)→ 实践要求(底线思维、防范黑天鹅灰犀牛、新安全格局保障新发展格局)→ 收尾

2.(备选)结合社会治理,论述如何建设更高水平的平安中国。

⚠️参考框架:社会治理体系七要素 → 共建共治共享 → 枫桥经验、浦江经验 → 三个转变(被动维稳→主动维稳等)→ 食品安全"四个最严"收尾

专题七 大国外交与人类命运共同体(第九章)

A. 背诵自查题

  1. 新型国际关系的 12 字?

    相互尊重、公平正义、合作共赢(对话而不对抗、结伴而不结盟)

  2. 人类命运共同体"五个世界"?

    持久和平、普遍安全、共同繁荣、开放包容、清洁美丽(对应对话协商/共建共享/合作共赢/交流互鉴/绿色低碳)

  3. "一带一路"原则与"五通"?

    共商共建共享;政策沟通、设施联通、贸易畅通、资金融通、民心相通

  4. 全人类共同价值?

    和平、发展、公平、正义、民主、自由

  5. 三大全球倡议?

    全球发展倡议、全球安全倡议、全球文明倡议(国际公共产品)

B. 论述题

1. 论述推动构建人类命运共同体的丰富内涵与时代意义。

⚠️参考框架:背景(世界之变时代之变历史之变+四大赤字)→ 五维展开 → 全人类共同价值 → "不是以一种制度代替另一种制度……最大公约数" → 意义(回答"世界怎么了、我们怎么办";超越西方中心论)

2. 为什么说"一带一路"是推动构建人类命运共同体的国际合作新平台?

⚠️参考框架:定位(实践平台)→ 共商共建共享+五通 → 从"大写意"到"工笔画"、高质量共建 → "是经济合作倡议,不是地缘政治联盟" → 带出三大全球倡议与全球治理观(共商共建共享、真正的多边主义)收尾

专题八 党的全面领导与全面从严治党(第十章)

A. 背诵自查题

  1. 默写"最本质特征"完整原句。

    "中国共产党领导是中国特色社会主义最本质的特征,是中国特色社会主义制度的最大优势,是党和国家的根本所在、命脉所在,是全国各族人民的利益所系、命运所系"

  2. "两个确立""两个维护"分别是什么?

    确立习近平同志党中央的核心、全党的核心地位,确立习近平新时代中国特色社会主义思想的指导地位;坚决维护核心地位、维护党中央权威和集中统一领导

  3. 党的建设总要求中的"一条主线、一个统领、一个根基"?

    主线=长期执政能力建设、先进性和纯洁性建设;统领=政治建设;根基=坚定理想信念宗旨

  4. 跳出历史周期率的"两个答案"?

    第一个=人民监督政府(1945 窑洞对);第二个=党的自我革命;外靠人民监督、内靠自我革命,都源于党的初心使命

  5. "九个以"至少说出 5 条。

    以党中央集中统一领导为根本保证/以引领伟大社会革命为根本目的/以习思想为根本遵循/以跳出历史周期率为战略目标/以解决大党独有难题为主攻方向/以健全全面从严治党体系为有效途径/以锻造坚强组织、过硬队伍为着力点/以正风肃纪反腐为重要抓手/以自我监督和人民监督相结合为强大动力

  6. "三个务必"?

    务必不忘初心、牢记使命,务必谦虚谨慎、艰苦奋斗,务必敢于斗争、善于斗争
