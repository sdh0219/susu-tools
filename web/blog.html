01

工具的第一美德是可预测

2026-09-23阅读约 1 分钟 来自 knowledge-publisher

做 Knowledge Publisher 的时候，我面对过一个选择：知乎文章里的 LaTeX 公式，是让大模型转换成平台能认的写法，还是用 matplotlib 把它渲染成图片？前者聪明，后者笨。

我选了笨的那种。因为问过自己一个问题：如果某天生成的公式错了，我在一百篇文稿里能信任哪一种？模型的答案每次都可能不一样，图片永远一样。

「确定性」这个词在技术文档里很无聊，放进工具里就是信任本身：同样的输入，永远同样的输出。

02

改别人的东西，要进得去、退得回

2026-09-23阅读约 1 分钟 来自 bg-skin

bg-skin 是给 VS Code 换背景的扩展。VS Code 没有官方背景 API，唯一的路是改它的核心样式文件——听起来像破坏行为。

所以我给自己立了三条规矩：动手前先备份原文件；改完把校验和一并修正，不让编辑器弹「安装似乎已损坏」；卸载时把一切还原。后来 VS Code 升级覆盖了补丁，扩展启动时检测到注入标记丢失，又自动补了回去。

这件事让我对好工具多了一个判断标准：它对别人东西做的每一个改动，都得留一条回家的路。

03

浏览器记得你，这件事突然值钱了

2026-09-23阅读约 1 分钟 来自 Tabbit 试用

试用美团那个 AI 浏览器 Tabbit 的时候，我想明白了一件事：你的浏览器里存着你的 Cookie——微博、淘宝、公司后台，它记得你是谁。

以前这只意味着不用重复登录。Agent 浏览器出现之后，这意味着 AI 可以带着你的登录态直接干活：填表、抓数据、跑流程，不需要任何 API 接入和配置。

对比一下就很明显：让命令行 Agent 帮你填一张表，你要配环境、写脚本、折腾授权；让 AI 浏览器填，你只需要「以前登录过」。工具进化最打动人的方向，是把你已经拥有的东西，直接变成能力。

04

收藏夹里的 34 个工具，每天打开的不超过 5 个

2026-09-23阅读约 1 分钟 来自运营这个站

我维护这个工具目录，收录的都是亲测好用的东西。但诚实地说，我自己每天打开的不到五个。

这让我重新理解了目录站的价值：它不是让你用上更多工具，而是在某个具体需求出现的那一刻，帮你想起正确的那一个。图片要压缩了才打开 Squoosh，视频要转笔记了才想起 BiliNote。

工具检索说到底是场景检索。所以目录按「你现在想干什么」分类，不按哪个更酷排序。

05

vibe coding 之后，稀缺的不再是实现

2026-09-23阅读约 1 分钟 来自五个项目的复盘

一年里我用 AI 做了五个工具，最快的一个从想法到能跑只花了一个周末。放在三年前，我得先把框架文档啃完。

但写代码不再是瓶颈之后，瓶颈一个没少，只是换了个位置：PPT医生的第一版想给所有人用，改到后来发现只服务医生才成立；千瞳想做「视频转 3D」的全家桶，砍掉一半功能才勉强能看。

AI 能把你想要的任何东西做出来，问题只剩一个：你到底想要什么。做工具，越来越考品味了。
