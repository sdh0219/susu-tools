# PPT医生 - 医生一键生成PPT工具

## 项目简介

PPT医生是一款专为医生设计的AI辅助PPT生成工具，帮助医生快速生成专业的医学演示文稿。

### 核心功能

- **一键生成**: 输入一句话主题，AI自动生成完整PPT大纲
- **对照编辑**: 左侧大纲编辑器 + 右侧实时PPT预览
- **智能大纲**: AI生成专业医学内容大纲，支持自定义编辑
- **多种布局**: 支持封面页、内容页、章节页、结尾页等布局
- **专业模板**: 内置医学专业蓝配色主题
- **本地运行**: 所有AI模型本地部署，数据安全隐私

## 技术架构

- **框架**: Electron + React 18 + TypeScript
- **AI模型**: Ollama + Qwen2.5-7B 中文模型
- **PPT生成**: PptxGenJS
- **状态管理**: Zustand

## 系统要求

- Windows 10/11 (64位)
- 至少8GB内存（建议16GB以上）
- 至少10GB可用磁盘空间（用于存放AI模型）

## 首次使用

### 1. 启动应用

运行 PPT医生 应用程序，首次启动会进入配置向导：

#### 步骤1: 安装Ollama

点击「自动安装Ollama」按钮，系统会自动下载并安装Ollama AI引擎。

#### 步骤2: 启动Ollama服务

安装完成后，点击「启动Ollama服务」按钮启动本地AI服务。

#### 步骤3: 下载AI模型

点击「下载Qwen2.5-7B模型」按钮，下载约4.7GB的中文AI模型。

> **注意**: 模型下载需要一定时间，请保持网络连接稳定。

## 使用指南

### 生成PPT大纲

1. 在顶部搜索框输入主题，例如：
   - "高血压的诊断与治疗"
   - "糖尿病患者的饮食管理"
   - "新型冠状病毒肺炎诊疗指南"

2. 点击「生成」按钮或按回车键

3. AI会自动生成完整的PPT大纲，包括：
   - 封面页
   - 目录页
   - 多个内容页
   - 结尾页

### 编辑大纲

在左侧大纲编辑器中，您可以：

1. **修改标题**: 点击标题输入框直接编辑
2. **添加幻灯片**: 点击「+ 添加」按钮
3. **删除幻灯片**: 点击×按钮，确认删除
4. **调整顺序**: 点击↑↓按钮调整幻灯片顺序
5. **修改布局**: 通过下拉菜单选择布局类型
6. **添加要点**: 点击「+ 添加要点」按钮
7. **添加备注**: 在备注框中输入演讲备注

### 预览PPT

右侧预览区域会实时显示PPT效果：

- 点击任意幻灯片缩略图可切换查看
- 选中的幻灯片会高亮显示
- 修改大纲时预览会自动更新

### 导出PPT

1. 点击顶部工具栏的「导出PPT」按钮
2. 选择保存路径和文件名
3. 点击「保存」生成.pptx文件

## 布局类型说明

| 布局类型 | 用途 | 特点 |
|---------|------|------|
| 封面 | 演示文稿首页 | 大标题+副标题+日期 |
| 内容 | 主要内容页 | 标题+要点列表 |
| 章节 | 章节分隔页 | 章节标题，全屏背景 |
| 结尾 | 结束页 | 感谢语，简洁设计 |

|-------|------|

| Ctrl+S | 导出PPT |

## 常见问题

### Q: 首次启动提示Ollama未安装？

A: 首次使用需要通过配置向导安装Ollama引擎和AI模型。请按照向导步骤完成配置。

### Q: 生成大纲速度慢？

A: AI模型在本地运行，首次生成可能需要几秒到十几秒。如果速度过慢，请检查：
- 电脑配置是否满足要求
- 是否有其他程序占用大量内存

### Q: 导出的PPT无法打开？

A: 请确保使用Microsoft PowerPoint 2016或更高版本打开。

### Q: 如何更新AI模型？

A: 在命令行中运行 `ollama pull qwen2.5:7b` 即可更新模型。

## 数据安全

- 所有AI处理均在本地完成，不会上传任何数据到云端
- 生成的PPT文件保存在您指定的位置
- Ollama模型数据存储在用户目录下的.ollama文件夹
