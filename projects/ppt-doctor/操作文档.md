# PPT医生 - 软件操作文档

## 一、软件简介

PPT医生是一款面向医疗工作者的AI辅助PPT生成工具。用户只需输入一个主题，AI即可自动生成专业的医学PPT大纲，并在右侧实时预览PPT效果。支持对大纲进行自由编辑，最终一键导出为标准 `.pptx` 文件。

**核心特性：**
- 基于云端大模型AI生成，无需本地部署
- 左侧大纲编辑 + 右侧实时PPT预览的对照模式
- 支持多种AI模型供应商（DeepSeek、通义千问、OpenAI、智谱AI、月之暗面等）
- 用户可自行配置API Key，灵活切换模型
- 一键导出标准PowerPoint文件

---

## 二、安装与启动

### 2.1 安装

双击安装包 `PPT医生 Setup x.x.x.exe`，按照安装向导完成安装即可。安装完成后桌面会生成快捷方式。

### 2.2 启动

双击桌面快捷方式或从开始菜单启动「PPT医生」。

启动后将看到主界面，包含三个区域：
- **顶部工具栏**：主题输入框、模型状态、设置按钮、操作按钮
- **左侧面板**：大纲编辑区（占40%宽度）
- **右侧面板**：PPT实时预览区（占60%宽度）

---

## 三、首次使用：配置AI模型

首次使用时，状态栏会显示「● 未配置模型」，需要先配置AI模型供应商。

### 3.1 打开设置

点击顶部工具栏的 **⚙️ 设置** 按钮，打开模型设置面板。

### 3.2 设置面板说明

设置面板分为两部分：

| 区域 | 说明 |
|------|------|
| **左侧 - 供应商列表** | 显示所有已配置的AI模型供应商，点击可编辑 |
| **右侧 - 配置表单** | 编辑或新增供应商的详细配置 |

系统内置了5个常用供应商预设（无需手动填写API地址）：

| 供应商 | API地址 | 默认模型 |
|--------|---------|----------|
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| OpenAI | https://api.openai.com/v1 | gpt-4o-mini |
| 智谱AI | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
| 月之暗面 | https://api.moonshot.cn/v1 | moonshot-v1-8k |

### 3.3 配置步骤

1. 在左侧列表中点击一个供应商（如 DeepSeek）
2. 在右侧表单中填入 **API Key**（在对应供应商官网注册获取）
3. 确认 **API 地址** 和 **模型名称** 是否正确（预设供应商已自动填好）
4. 点击 **🔗 测试连通性** 验证配置是否正确
   - 显示 ✅ 连接成功：配置正确
   - 显示 ❌ 连接失败：请检查API Key和地址
5. 勾选 **设为默认供应商**
6. 勾选 **启用此供应商**
7. 点击 **保存修改**

### 3.4 配置字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 供应商名称 | 自定义名称，方便识别 | DeepSeek |
| API Key | 供应商提供的API密钥 | sk-xxxxxxxxxxxxxxxx |
| API 地址 | 供应商的API接口地址 | https://api.deepseek.com/v1 |
| 模型名称 | 要使用的具体模型 | deepseek-chat |
| 启用此供应商 | 是否启用该供应商 | ✅ |
| 设为默认供应商 | 设为默认使用的供应商 | ✅ |

### 3.5 获取模型列表

编辑供应商时，如果已填入API Key和API地址，可以点击 **🔄 获取模型列表** 按钮，系统会自动从供应商获取可用模型列表，在下拉框中选择即可。

### 3.6 添加自定义供应商

如需使用不在预设列表中的供应商，点击左侧 **+ 添加供应商** 按钮，手动填写所有配置信息。要求供应商的API接口兼容 OpenAI SDK 格式。

### 3.7 删除供应商

在左侧列表中点击要删除的供应商，进入编辑模式后，暂不支持直接删除按钮（需通过其他方式管理）。如需删除，可在编辑后保存或联系技术支持。

### 3.8 关闭设置

点击右上角 **✕ 关闭** 按钮关闭设置面板，返回主界面。

配置完成后，状态栏将显示当前使用的供应商和模型名称，如：`● DeepSeek · deepseek-chat`。

## 四、生成PPT大纲

### 4.1 输入主题

在顶部工具栏的输入框中输入PPT主题，例如：

```
高血压的诊断与治疗
```

### 4.2 生成大纲

点击 **📤 生成** 按钮，或按 **Enter** 键，AI将根据主题自动生成PPT大纲。

生成过程中按钮显示「⏳ 生成中...」，请耐心等待（通常需要10-30秒，取决于模型响应速度）。

### 4.3 生成结果

生成完成后：
- 左侧大纲编辑区将显示完整的大纲结构
- 右侧PPT预览区将实时渲染PPT效果
- 自动选中第一张幻灯片

AI生成的大纲通常包含8-12页幻灯片，结构如下：
- 第1页：封面页（layout: title）
- 中间页：内容页（layout: content）或章节页（layout: section）
- 最后一页：结尾页（layout: ending）

### 4.4 未配置模型时的提示

如果尚未配置AI模型，点击生成按钮时会弹出提示「请先在设置中配置AI模型供应商」，并自动打开设置面板。

## 五、编辑大纲

左侧大纲编辑区支持对生成的PPT大纲进行全面编辑，所有修改都会实时反映到右侧PPT预览中。

### 5.1 编辑标题和副标题

大纲顶部可编辑PPT的主标题和副标题：
- **主标题**：点击即可修改，字体较大加粗
- **副标题**：点击即可修改，下方灰色文字

### 5.2 幻灯片卡片

每张幻灯片以卡片形式展示，包含以下信息：

| 元素 | 说明 |
|------|------|
| 页码标签 | 显示「序号 / 布局类型」，如「1 / 封面」 |
| 布局选择 | 下拉框切换布局类型 |
| 排序按钮 | ↑↓ 上移/下移幻灯片 |
| 删除按钮 | × 删除当前幻灯片（需二次确认） |
| 标题输入 | 幻灯片标题 |
| 要点列表 | 每个要点一行，可增删 |
| 演讲备注 | 底部文本框，可添加演讲者备注 |

### 5.3 切换幻灯片布局

点击幻灯片卡片左上角的下拉框，可选择4种布局类型：

| 布局 | 效果 | 适用场景 |
|------|------|----------|
| 封面（title） | 深色渐变背景，居中大标题 | PPT首页 |
| 内容（content） | 白色背景，标题+要点列表 | 正文内容页 |
| 章节页（section） | 深色渐变背景，居中章节标题 | 章节分隔页 |
| 结尾（ending） | 深色渐变背景，居中结束语 | PPT末页 |

### 5.4 编辑要点

每张幻灯片的要点列表支持以下操作：

- **修改要点**：直接点击要点文本进行编辑
- **添加要点**：点击要点列表下方的 **+ 添加要点** 按钮
- **删除要点**：点击要点右侧的 **×** 按钮

### 5.5 添加幻灯片

点击大纲顶部的 **+ 添加** 按钮，将在末尾添加一张新的内容页幻灯片，默认标题为「新幻灯片」。

### 5.6 删除幻灯片

点击幻灯片卡片右上角的 **×** 按钮，系统会要求二次确认：
- 点击 **确认** 删除该幻灯片
- 点击 **取消** 取消删除

### 5.7 调整幻灯片顺序

使用幻灯片卡片右上角的 **↑** 和 **↓** 按钮调整顺序：
- ↑：上移一位（第一页时禁用）
- ↓：下移一位（最后一页时禁用）

### 5.8 添加演讲备注

每张幻灯片底部有一个文本框，可输入演讲者备注。备注不会显示在PPT预览中，但会包含在导出的PPT文件中供演讲者参考。

## 六、PPT预览

右侧预览区实时展示PPT效果，与左侧大纲编辑同步更新。

### 6.1 预览布局

预览区分为两部分：

| 区域 | 说明 |
|------|------|
| 上方大图 | 当前选中幻灯片的大尺寸预览 |
| 下方缩略图 | 所有幻灯片的缩略图网格 |

### 6.2 选中幻灯片

- 在左侧大纲编辑区点击幻灯片卡片
- 或在右侧预览区点击缩略图

选中的幻灯片会显示蓝色边框，并在上方大图区域展示。

### 6.3 预览样式说明

| 布局类型 | 预览效果 |
|----------|----------|
| 封面页 | 深蓝色渐变背景，白色居中标题，下方副标题 |
| 内容页 | 白色背景，深蓝色标题+蓝色下划线，蓝色圆点要点列表 |
| 章节页 | 蓝色渐变背景，白色居中章节标题 |
| 结尾页 | 深蓝色渐变背景，白色居中结束语 |

每页右下角显示页码。

## 七、工具栏操作

顶部工具栏右侧提供以下操作按钮：

### 7.1 🔄 重新生成

基于当前PPT主标题，重新调用AI生成全新大纲。**注意：此操作会覆盖当前大纲，请确认是否需要保存当前内容。**

### 7.2 💾 导出PPT

将当前大纲导出为标准 `.pptx` 文件。点击后：
1. 系统弹出文件保存对话框
2. 选择保存位置和文件名
3. 点击保存，生成PPT文件
4. 导出成功后弹出提示，显示文件保存路径

导出的PPT文件包含：
- 所有幻灯片内容（标题、要点）
- 演讲者备注
- 基础样式（颜色、字体、布局）

### 7.3 ⚙️ 设置

打开模型供应商设置面板，详见第三章。

## 八、完整操作流程示例

以下是一个从零开始生成PPT的完整流程：

### 步骤1：配置模型

1. 启动PPT医生
2. 点击 **⚙️ 设置**
3. 点击左侧 **DeepSeek**
4. 填入API Key
5. 点击 **🔗 测试连通性** → 显示 ✅ 连接成功
6. 勾选 **设为默认供应商** 和 **启用此供应商**
7. 点击 **保存修改**
8. 关闭设置面板

### 步骤2：生成大纲

1. 在输入框中输入：`2型糖尿病的综合管理`
2. 点击 **📤 生成** 或按 Enter
3. 等待AI生成（约10-30秒）

### 步骤3：编辑大纲

1. 查看左侧生成的大纲，右侧同步预览
2. 点击第3张幻灯片，修改标题为更准确的表述
3. 删除不需要的要点，添加遗漏的要点
4. 将某张幻灯片的布局从「内容」改为「章节页」
5. 用 ↑↓ 按钮调整幻灯片顺序
6. 为关键幻灯片添加演讲备注

### 步骤4：导出PPT

1. 确认大纲和预览效果满意
2. 点击 **💾 导出PPT**
3. 选择保存位置，如桌面
4. 命名为 `2型糖尿病的综合管理.pptx`
5. 点击保存
6. 导出成功后，用PowerPoint打开查看

## 九、常见问题

### Q1：状态栏显示「未配置模型」怎么办？

点击 **⚙️ 设置**，按照第三章的步骤配置AI模型供应商的API Key。

### Q2：测试连通性失败怎么办？

请检查以下几点：
1. API Key是否正确（注意前后不要有空格）
2. API地址是否正确（需要包含 `/v1` 后缀）
3. 网络是否能访问对应API地址
4. API Key是否有余额/额度

### Q3：生成大纲失败怎么办？

可能的原因：
1. 未配置模型或API Key无效 → 重新配置
2. 网络连接问题 → 检查网络
3. 模型返回格式异常 → 点击「重新生成」重试
4. API额度不足 → 检查供应商账户余额

### Q4：如何切换使用的AI模型？

1. 打开 **⚙️ 设置**
2. 配置新的供应商或修改现有供应商的模型名称
3. 设为默认供应商
4. 保存修改

### Q5：如何使用自定义的AI供应商？

1. 打开 **⚙️ 设置**
2. 点击 **+ 添加供应商**
3. 填写供应商名称、API Key、API地址、模型名称
4. 要求：API接口必须兼容 OpenAI SDK 格式
5. 测试连通性通过后保存

### Q6：导出的PPT可以在哪里打开？

导出的 `.pptx` 文件可以使用以下软件打开：
- Microsoft PowerPoint（推荐）
- WPS演示
- LibreOffice Impress
- Google Slides（需上传）

### Q7：API Key安全吗？

API Key保存在本地配置文件中，不会上传到任何服务器。但请注意：
- 不要将API Key分享给他人
- 不要将配置文件发送给他人
- 定期更换API Key以提高安全性
