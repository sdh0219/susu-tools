仓库治理规则：
- 单一事实源：自研工具只在 susu-tools 开发；已迁移归档的原独立仓库不再回改。
- 新工具默认进 projects/（kebab-case），孵化-毕业模式：
  需要独立身份时迁出（git filter-repo 保留历史）。
- 发版：<project>-v<semver> tag + GitHub Release（如 bg-skin-v0.5.1）。
- 不做泛工具目录：第三方工具只安利二次元相关精品，且以随笔形式承载。
- 安全红线：密钥 / cookie / 运行时 / 模型权重不入库；提交前跑 scripts/secrets_scan.py。
