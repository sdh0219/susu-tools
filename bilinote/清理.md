# BiliNote localStorage 清理指南（Edge 浏览器专用）

## 一、什么时候需要清理

当 BiliNote 网页出现以下提示时，说明需要清理：

```
Failed to execute 'setItem' on 'Storage': Setting the value of 'task-storage' exceeded the quota
```

或者网页显示"生成失败"，但后端日志显示笔记实际已生成成功。

**原因**：浏览器 localStorage 配额上限约 5MB，BiliNote 每生成一条笔记会存入约 80KB 数据，累计约 60 条后可能撑满。

---

## 二、清理影响范围

| 项目 | 是否受影响 |
|------|-----------|
| localhost:8000 的历史任务记录 | 会被清除 |
| 其他网站（B站、百度等）的数据 | 不受影响 |
| 浏览器收藏夹、密码、设置 | 不受影响 |
| BiliNote 后端生成的笔记文件 | 不受影响（存在项目 note_results 目录） |
| BiliNote 的 cookies.txt 和配置 | 不受影响 |

**结论：清理操作完全安全，只会删除 localhost:8000 网页上的历史任务记录，不影响任何其他内容。**

---

## 三、详细清理步骤

### 步骤 1：打开 BiliNote 网页

在 Edge 浏览器地址栏输入：

```
http://localhost:8000
```

按回车进入 BiliNote 主页。

---

### 步骤 2：打开开发者工具

有以下三种方式，任选其一：

**方式 A（快捷键，推荐）：**

在键盘上同时按下 `F12` 键。

**方式 B：**

在键盘上同时按下 `Ctrl + Shift + I`（三个键一起按）。

**方式 C（菜单操作）：**

1. 在网页任意空白处点击鼠标右键
2. 在弹出的菜单中点击"检查"（或"Inspect"）

操作后，浏览器右侧或下方会弹出一个开发者工具面板。

---

### 步骤 3：切换到 Console（控制台）标签

1. 在开发者工具面板顶部，找到一排标签：`Elements | Console | Sources | Network | ...`
2. 点击 `Console`（控制台）标签

现在你会看到一个可以输入文字的命令行区域，前面带有一个 `>` 符号。

---

### 步骤 4：输入清理命令

在 `>` 符号后面的输入框中，完整复制粘贴以下内容：

```javascript
localStorage.clear()
```

然后按回车键（Enter）。

**注意：**
- 输入完成后按回车，如果没报错就说明清理成功了
- 正常情况下不会有任何输出，没输出就是成功
- 如果出现红色错误文字，检查是否拼写正确，括号是否是英文括号

---

### 步骤 5：刷新页面

1. 关闭开发者工具面板（再按一次 F12 即可关闭）
2. 刷新页面，有以下三种方式：
   - 按键盘 `F5` 键
   - 按键盘 `Ctrl + R`
   - 点击 Edge 地址栏左侧的刷新按钮（圆形箭头图标）

---

### 步骤 6：验证清理成功

刷新后页面正常加载，历史任务列表为空，说明清理成功。可以重新提交视频链接生成笔记了。

---

## 四、如何判断是否需要清理（提前预防）

### 方法 1：看网页表现

- 提交视频后进度一直正常，最后突然显示"生成失败"
- 但后端控制台日志显示笔记已成功生成（看到"GPT总结并缓存成功"或"笔记生成成功"）

这种情况基本就是 localStorage 超限。

### 方法 2：查看 localStorage 使用量

1. 按 F12 打开开发者工具
2. 切换到 `Application`（应用程序）标签
3. 左侧栏找到 `Storage` → `Local Storage` → 点击 `http://localhost:8000`
4. 右侧会显示所有存储的键值对，底部会显示总占用大小
5. 如果接近 5000KB（5MB），就需要清理了

## 五、定期清理建议

| 使用频率 | 建议清理周期 |
|---------|------------|
| 每天用 1-2 次 | 每月清一次 |
| 每天用 5-10 次 | 每两周清一次 |
| 大批量处理视频 | 每处理 50 个视频清一次 |

清理方法重复上面"步骤 2 ~ 步骤 5"即可。

## 六、常见问题

### Q1：清理后之前生成的笔记会丢吗？

不会。笔记文件保存在项目的 `note_results` 文件夹里，localStorage 只是前端的任务记录缓存。清理后只是网页上看不到历史任务列表了，但笔记文件还在。

### Q2：清理后能恢复历史任务记录吗？

不能。localStorage 清除后无法恢复。但你可以重新提交视频链接，后端有缓存机制（音频缓存、转写缓存、总结缓存），如果之前生成过，会直接读缓存，几秒就能重新出结果。

### Q3：为什么不用 cookies.txt 的方式，而要用 localStorage？

这是两个完全不同的东西：
- cookies.txt：用于 B站下载视频时的身份认证，跟浏览器无关
- localStorage：前端网页存储任务结果的地方，跟下载无关

### Q4：能不能不清理，让它自动管理？

目前 BiliNote 前端没有自动清理旧任务的机制，所以需要手动清理。未来如果项目更新了前端代码，可能会解决这个问题。

---

## 七、一键清理（高级用法）

如果你觉得每次手动操作太麻烦，可以提前把清理命令存为浏览器书签：

1. 在 Edge 中按 `Ctrl + D` 添加书签
2. 名称填：`清理BiliNote缓存`
3. URL 填以下内容（全部复制）：

```javascript
javascript:void(localStorage.clear())
```

4. 保存书签

以后只需要在 BiliNote 页面上点击这个书签，就能一键清理，然后按 F5 刷新即可。
